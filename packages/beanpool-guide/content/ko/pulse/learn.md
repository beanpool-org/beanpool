## 포함된 내용

휴대폰에서 **동향**을 열고 **배움**을 탭하세요. 웹 앱에서는 동향을 열고 상단의 **이용 방법**을 탭하세요. 다음 내용이 포함되어 있어요:

- BeanPool 작동 원리에 관한 BeanPool 공식 영상;
- 매일 아침 바뀌는 짧은 생각인 **오늘의 생각**. 탭하면 오늘의 생각을 열어볼 수 있어요.

멤버들도 채널을 추가할 때 주제로 **이용 방법**을 선택하여 배움에 자체 설명 채널을 추가할 수 있어요. 이러한 영상은 BeanPool 공식 영상이 아니라 멤버 개인의 영상이에요: 조언을 따르기 전에 누가 게시한 영상인지 확인하세요.

## 보충 자료로서의 영상

필요한 모든 내용은 이 가이드에 글로 적혀 있어요. 글보다 영상이 편한 분들을 위해 영상이 제공돼요.

휴대폰의 배움 레인에서 영상 그림을 탭하면 카드 안에서 바로 재생돼요. 탭하기 전까지는 YouTube에서 아무것도 불러오지 않아요. 웹 앱에서는 영상을 탭하면 새 탭에서 YouTube로 열려요. "동향 둘러보기"를 참조하세요.

BeanPool이 가이드 페이지용으로 제작한 영상이 있고 커뮤니티의 배움 레인에 포함되어 있다면, 해당 페이지 상단에 **시청:**과 영상 제목이 표시돼요. 탭하면 YouTube에서 영상이 열려요. 해당 페이지에 영상이 없거나 오프라인 상태라면 링크가 아예 나타나지 않아요.

가이드 페이지에는 BeanPool 자체 영상만 표시돼요. 멤버가 배움에 추가한 영상은 제목이 무엇이든 가이드 페이지에 표시되지 않아요.

## 영상이 보이지 않는 이유

- 휴대폰이 오프라인 상태이거나 커뮤니티 서버에 연결할 수 없어요.
- 새로운 BeanPool 영상은 커뮤니티 서버가 업데이트된 후에 가이드 페이지에 나타나요.
- 해당 페이지용 영상이 아직 제작되지 않았어요.
