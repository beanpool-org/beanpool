Eine Gemeinschaft gründen

Jede Gemeinschaft läuft auf ihrem eigenen Server: ein kleiner Rechner, der die Mitglieder, Beiträge und das Buch verwaltet. Jemand vor Ort betreibt ihn. Wenn deine Stadt oder dein Tal noch keinen hat, könntest du das sein.

Was der Betrieb einer Gemeinschaft bedeutet

Etwa eine halbe Stunde, wenn du einer Anleitung folgen kannst. Sechs Dinge, die du vorab wissen solltest:

  • Was es kostet. Die Software ist kostenlos. Sie läuft auf einem ungenutzten Computer, der zu Hause eingeschaltet bleibt (ein Mini-PC, ein NAS oder ein Raspberry Pi mit 64-Bit-System), oder auf einem kleinen gemieteten Server für wenige Dollar im Monat (etwa 6 US$).
  • Wer es hostet. Du selbst, auf deinem eigenen Rechner oder dem gemieteten Server. beanpool.org wird dafür nicht benötigt: eine eigene Webadresse genügt.
  • Welche Aufgaben du übernimmst. Meldungen deiner Mitglieder gehen bei dir ein. Den Datenordner sicherst du selbst, mit einem Wiederherstellungscode. Bestimme zwei Eigentümer. Halte den Server online und auf dem neuesten Stand.
  • Was du niemals siehst. Die Direktnachrichten deiner Mitglieder.
  • Zuerst Docker. Auf dem Rechner muss vor dem folgenden Befehlsblock Docker installiert sein; ein frisch gemieteter Server hat dies nicht vorinstalliert.
  • Eine für Smartphones erreichbare Adresse. Smartphones erreichen eine Gemeinschaft im Internet nur über https. Auf einem gemieteten Server mit öffentlicher IP-Adresse und offenen Ports 80 und 443 reicht diese IP-Adresse aus: Dein Server erhält dafür sein eigenes Zertifikat, ganz ohne Cloudflare-Konto, und ebenso für eine eigene Domain. Zu Hause oder ohne offene Ports erhältst du bei der Beanspruchung einen kostenlosen Namen mit der Endung .beanpool.org über einen Tunnel, den dein Server selbst betreibt. Eine reine http://-Adresse funktioniert nur im Heimnetzwerk.
🧰

Worum du dich kümmerst

Du und die von dir ernannten Administratoren seid die Moderatoren eurer Gemeinschaft: Meldungen gehen bei euch ein. Die Daten eurer Mitglieder liegen auf eurem Rechner, also sichert ihr sie regelmäßig. Ihr könnt Diskussionen in Betrieben und Chats von Veranstaltungen mitlesen; Direktnachrichten könnt ihr nicht lesen. Du lädst die ersten Mitglieder ein, und diese laden die weiteren ein.

⚙️

Die Einstellungen-App

Dein Server bringt eine eigene Einstellungen-App im Browser mit. Darüber benennst du deine Gemeinschaft, ernennst Eigentümer und Administratoren, die sich mit ihren eigenen Schlüsseln anmelden, druckst QR-Einladungen, überwachst den Speicherzustand, wählst eine öffentliche Webadresse oder einen Tunnel und hilfst einem Mitglied, das sowohl Smartphone als auch seine 12 Wörter verloren hat, mit einem persönlich bestätigten Einmal-Code zurück in sein Konto auf einem neuen Telefon.

🔒

Privat ab dem ersten Start

Die Angebote, die Karte, die Nachrichten und die Salden einer Gemeinschaft sind ab dem ersten Start des Servers nur für ihre Mitglieder bestimmt; es muss nichts extra aktiviert werden. Wer die Adresse ohne Konto öffnet, wird zur globalen Gemeinschaft weitergeleitet, wo sie sehen können, was in ihrer Nähe angeboten wird, und um Beitritt bitten können.

🌐

Verbindung mit einer Nachbargemeinschaft

Zwei Gemeinschaften können vereinbaren, sich zu verbinden, damit ihre Mitglieder untereinander handeln können. Bohnen verlassen dabei nie ihren Heimatserver: Jedes Paar führt eine laufende Abrechnung darüber, was eine Gemeinschaft der anderen schuldet, und jede Seite legt ihr eigenes Limit fest. Die Verbindung ist deaktiviert, solange nicht beide Betreiber sie einschalten, und sie ist noch im Anfangsstadium: Sie ist fertig entwickelt, mit entsprechenden Bildschirmen in der Web-App, wurde bisher jedoch nur zwischen zwei unserer eigenen Testgemeinschaften erprobt, noch nie im Produktivbetrieb.

Deine Adresse

Wähle sie aus, bevor du den Code einfügst, und passe die letzte Zeile entsprechend an. Wenn du den Code bereits eingefügt hast, drücke bei den Abfragen die Eingabetaste und führe die letzte Zeile erneut aus: Der Beanspruchungscode wartet auf ein Smartphone. Bei einem gemieteten Server mit öffentlicher IP-Adresse und offenen Ports 80 und 443: Hänge --ip und die IP-Adresse an, etwa beanpool claim --ip 203.0.113.7. Dein Server bezieht für diese Adresse sein eigenes Zertifikat von Let's Encrypt über Port 80, und Telefone erreichen ihn unter https://203.0.113.7. Bei einem Rechner zu Hause oder ohne offene Ports: Belasse die Zeile so, wie sie ist. Es wird nach dem ersten Teil eines kostenlosen Namens gefragt (gib einfach deinestadt für deinestadt.beanpool.org ein; Eingabetaste überspringt), erreichbar über einen Tunnel, den dein Server selbst betreibt, und wartet bis zu drei Minuten, bis dieser aktiv ist. Eigene Domain: Richte einen A-Record auf die IP-Adresse des Servers ein, öffne die Ports 80 und 443 und hänge --address https://deine.domain an. Ein Name übersteht einen Serverwechsel, eine Nummer nicht: Du kannst später in den Einstellungen einen Namen hinzufügen, und Mitglieder, die die IP-Adresse nutzen, können weiterarbeiten. Um dies später in den Einstellungen festzulegen, hänge --no-name an. Eine einfache http://-Adresse funktioniert nur im Heimnetzwerk: Telefone verweigern sie im Internet und die Beanspruchung warnt dich. Sollte der Adressdienst des BeanPool-Projekts nicht erreichbar sein, funktioniert die Beanspruchung trotzdem.

Installieren

Füge dann auf diesem Rechner mit installiertem Docker diesen einen Block ein. Er lädt die Compose-Datei herunter, erstellt das vom Server genutzte Netzwerk, zieht das veröffentlichte Image (Intel/AMD oder ARM64), startet es, wartet, bis der Server seinen einmaligen Beanspruchungscode erstellt hat (bis zu fünf Minuten bei einem langsamen Erststart auf einem Raspberry Pi), und beansprucht ihn. Vor dem Start muss nichts konfiguriert werden.

bash — eine Gemeinschaft gründen
Ein Block: Herunterladen, Netzwerk, Image laden, starten, warten, beanspruchen git clone https://github.com/beanpool-org/beanpool.git && cd beanpool docker network create beanpool-shared docker compose pull docker compose up -d echo "Waiting for the server to make its claim code (up to 5 minutes)..." for i in $(seq 60); do docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null && break; sleep 5; done docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null || echo "No claim code after 5 minutes. The server's log says why: docker compose logs beanpool-node" docker compose exec beanpool-node beanpool claim

Die letzte Zeile: beanpool claim

  1. Code und QR-Code. Es wird ein einmaliger Beanspruchungscode und ein QR-Code angezeigt. Scanne den QR-Code mit der Kamera deines Smartphones oder öffne BeanPool, gib die Serveradresse unter Finde deine Community ein und tippe auf Beanspruchen. Dieses Telefon wird zum Eigentümer.
  2. Einstellungen. Öffne deine Adresse (oder die eigene Adresse des Servers) gefolgt von /settings. Der Einrichtungsassistent gibt deiner Gemeinschaft einen Namen, fordert dich auf, einen zweiten Eigentümer hinzuzufügen, und erstellt drei Gründungseinladungen. Lege deinen Standort auf der Karte unter Node-Identität fest, damit Menschen in der Nähe dich finden können.

Wenn der Block No claim code after 5 minutes anzeigt oder beanpool claim meldet This community has no claim code waiting, ist der Server noch nicht vollständig gestartet: docker compose logs beanpool-node zeigt den Status an. Sobald das Protokoll besagt, dass die Gemeinschaft noch keinen Eigentümer hat und ein Beanspruchungscode vorliegt, führe die letzte Zeile erneut aus. Alle Einzelschritte findest du in der Ersteinrichtung des Betreiber-Handbuchs.

Empfohlen: Halte deine Gemeinschaft am Laufen, wenn Docker sich aktualisiert

Der Schritt steht auf der Seite „Updates and health“ im Betreiber-Handbuch. Ein KI-Assistent, der die Installation durchführt, führt diesen Schritt immer aus (Deinen Server mit einem KI-Assistenten einrichten).
