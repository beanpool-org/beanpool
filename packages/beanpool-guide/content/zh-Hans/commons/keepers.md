## 管理者的职责

管理者负责运营企业：发布其“提供”和“需求”、支出其豆子并进行照料。其中一人担任**主管理者**。

项目的管理者则是其**负责人**和**协作者**：应用在项目中使用这两个称谓。协作者也是管理者：他们可以发布项目的“提供”和“需求”，并以同样的方式为其承担责任。本页的所有内容同样适用于他们。

管理者可以用自己的一部分信任额度为企业提供支持。这将深化企业的信用额度。这绝不会从你的余额中扣减豆子。如果你的社区使用已知底线机制，超出你已赚取信誉的支持额度将一对一从你自己的信用额度中抵扣。参见“信用额度”。

完整规则（包括当负责人长期不活跃时的应对措施）详见“规则与决策机制”。

## 申请加入

- 打开企业页面。
- 在**申请加入担任管理者**下方，输入你愿意为其提供支持的信任额度。填零也是允许的。
- 点按**申请加入担任管理者**。

主管理者负责批准或拒绝。如果企业已拥有多位管理者，你将在 3 天后正式成为管理者，除非其他管理者在此期间提出异议。

只有你能看到自己还剩余多少可用于支持的信任额度。主管理者只能看到你的认捐额度以及你的信誉是否足以覆盖该额度，绝看不到具体数值。如果批准你的申请被拒绝，或者在异议窗口期结束时你的变更被取消，系统仅会告知对方你的信誉无法覆盖该认捐额度：绝不会透露你的具体数值、余额或冻结情况。

## 管理者操作

- 在**待处理管理者申请**（在 Web 应用中为**申请加入担任管理者**）下方**批准**或**拒绝**申请。每份申请都会显示认捐额度，并说明申请人的信誉是否足以覆盖该额度。如果无法覆盖，批准操作将被拒绝，直到信誉达标为止。
- 列在**等待中的管理者变更**下方的待生效更动会显示异议窗口期。点按**提出异议**即可阻止某项更动。**提出异议在首次点按时立即生效，不会二次确认。**只要有一人提出异议即取消该更动。
- 主管理者可以通过**移除**并点选姓名来移除某位管理者。其他管理者可以按相同方式提出异议。
- **运营者控制面板**允许管理者代表企业发布“提供”和“需求”。

## 辞去职务

点按**辞去管理者职务**，然后确认（在手机上点按**辞去职务**，在 Web 应用中点按 **确定**）。

- 唯一的管理者无法直接辞去职务。他们可以改由对企业进行清算。
- 如果企业余额低于零且需要你的支持额度来弥补赤字，应用会提示你目前尚无法退出（在手机上显示为**暂不**）。

## 管理者内部投票

当企业拥有两位或更多管理者时，任何管理者均可发起内部投票。打开企业页面：其投票列在**决策**下方，且仅对其管理者可见。点按**发起一项投票**并选择要执行的操作：

- 从企业自有账户中**支出豆子**，支付给你指定的管理者。付款金额绝不能超过企业当前持有的数量，且绝不能从其信用额度中透支。你不能提议向自己付款。向管理者付款属于发放报酬，因此只能来自企业已赚取的收益。通常收取的 1.5% 交易费会从中扣除并流入公共资金池；表单会在你发送之前同时显示这两个数额。
- **移除管理者。**主管理者不能通过此方式移除：他们应被更换。
- **让另一位管理者担任主管理者。**仅适用于企业。项目的负责人不能被其协作者投票罢免。

在投票开启时身为管理者的所有人都可以投**赞成**或**反对**，提议人也不例外。必须有超过半数的管理者参与投票。支出款项和移除管理者需要 60% 的赞成票；推选新的主管理者需要超过半数赞成票。投票持续 7 天，或者在结果已成定局时提前结束。一旦通过，应用将自行执行该决议。

投票进行期间，所有人都能看到已有多少人参与了投票，但看不到具体投了什么。赞成和反对票数在投票截止后才会显示。没有任何人能看到谁投了什么选项。但在人数很少的群组中，结果与投票人名单可能会透露这一点：如果三位管理者全部投票且最终结果为 3 比 0，大家自然就会知道每个人的投票选择。

除了提议者之外，参与投票的每位管理者在投票开启时都会收到一条通知，除非他们将企业聊天设为了静音或关闭了聊天通知。通知中不会点名任何人：只会说明你的某个群组开启了一项投票，其余信息可在应用中查看。在首页上，你尚未投票的进行中投票会显示在**需要你处理**下方，点击可直接打开该企业。

在投票期间辞去职务的管理者将离开该投票，其投出的票数也会随之作废。在投票期间被移除的管理者则保留其已投出的票数。如果企业启动清算，其进行中的投票将直接终止，不产生任何效果。

## 当主管理者长期不活跃时

如果主管理者长时间未活跃，其他管理者会看到**提议现任管理者担任主管理者**，并可以投**赞成**或**反对**。在 Web 应用中，从列表中选择一名活跃管理者，然后点按**提议首席**（在项目上显示为**提议负责人**）。涉及管理者的投票一旦投出即无法更改。
