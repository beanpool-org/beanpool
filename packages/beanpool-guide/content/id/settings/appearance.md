## Memilih tema

- Buka **Pengaturan**. Di bawah **Pengaturan Aplikasi**, temukan **Tampilan**.
- Pilih salah satu:
- **Sama dengan ponsel** (**Sama seperti perangkat** di web app): aplikasi menjadi gelap saat ponsel atau komputermu diatur ke tema gelap, dan terang saat diatur ke tema terang.
- **Terang:** selalu terang. Ini adalah setelan awal aplikasi ponsel.
- **Gelap:** selalu gelap. Ini adalah setelan awal web app.

Ada satu set warna untuk tema terang dan satu set warna untuk tema gelap.

Di bawah **Pengaturan Aplikasi** juga, **Pola latar belakang** menempatkan coretan gambar di belakang aplikasi. Matikan untuk menggunakan latar belakang polos. Fitur ini aktif sejak awal, dan pengaturannya disimpan di masing-masing perangkat.

Di ponsel, peta memiliki tombol tema terang dan gelap tersendiri, di sebelah kiri peta.

Di web app, pilihan pertama dinamai **Sama seperti perangkat**.
