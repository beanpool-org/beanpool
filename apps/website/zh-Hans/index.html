BeanPool 是一款免费应用，供你的社区成员相互交易互助、物品与技能。使用豆子代替金钱：帮助他人，你会获得豆子；得到帮助，豆子则流向对方。目标是归零 — 付出与索取大致相当。

🚫 反剥削宣言

BeanPool 不是什么

✕
不是广告推送机器

没有类似受众追踪、数据收割，也没有暴富大师的算法推荐。

✕
不是投机性加密代币

豆子是用于真实交易的互助信用 — 绝不会在交易所被炒作拉盘。

✕
不是注意力老虎机

没有多巴胺循环的无休止刷屏 — 只有真实的本地提供与邻里。

✕
不是企业债务或剥削

没有利息，没有银行，没有中间商。唯一的费用微乎其微，并全部进入你社区自己的公共资金池，绝不流向我们。

✕
不是加密货币应用

没有区块链，没有硬币，没有需要付费购买的钱包。你的 12 个助记词仅用于打开你自己的账户。

豆子如何流转

三个邻居，一周生活

1

Sam 增加到 +30。Ana 减少到 −30。

2

Ana 回到了 0。Lee 变成了 −30。

3
Lee 照看了 Sam 的小狗 — 30 个豆子

所有人都回到了接近零，完成了三件事，而且谁都没有花钱。

每次交易价格的 98.5% 归卖家所有；另外的 1.5% 进入社区的公共资金池，所以实际数值会略低于这些。

BeanPool 是什么

社区在自己拥有的小型服务器上运行 BeanPool。成员发布他们能够提供的帮助和需求，并用豆子进行交易。豆子不是花钱买来的货币：它是某人帮助了他人的凭证。每个人的初始余额都是零。当你提供帮助时，你的余额增加；当你接受帮助时，余额减少；整个社区的所有余额相加始终为零。没有人发行豆子，没有人收取利息出借豆子，也没有人将豆子提现。每笔交易的小额费用进入社区自己的资金池，由成员投票决定如何使用。该应用免费且开源；社区自行选择服务器，其上的数据归社区所有。

  • 不是加密货币。没有区块链，没有代币，没有任何可供买卖的金融产品。你的 12 个助记词仅用于打开你自己的账户。
  • 不是银行。信用源自你自身的交易，没有利息：完成第一笔交易后便会开启小额信用额度，并随着交易的增加而成长。
  • 没有居中牟利的公司。BeanPool 不从交易中抽取任何分成，也不展示任何广告。

互助信用历史悠久：LETS 群体在纸质账本上运行了数十年，而在瑞士，商业联盟 WIR 自 1934 年起就使用其自身的信用进行交易。繁琐的纸质工作耗尽了他们大多数人的精力。BeanPool 则是由应用自动完成这套繁琐的记账工作。

你能做什么

应用打开即是“首页”，由你自主选择的一组卡片构成。其后包含：市集、地图、对话（网页端为聊天）、成员、脉搏、公共资金池和账本（你可以在此查看余额与交易）。

🧺

市集

社区成员正在提供的事物与需求，投票与活动也汇聚在同一信息流中。你可以搜索、按分类筛选，并点击进行交易。

🗺️

地图

查看你附近提供的事物。每一个图钉都由你亲自放置：可以使用你当时的定位，也可以手动放置图钉。当你允许时，应用还会根据你的位置展示距离你最近的内容，且绝不会在后台定位。活动图钉以及在网页端设置的企业图钉可以设为“大致”，将地点模糊到约 100 米。图钉仅对你所在社区的成员可见。在全球社区中，访客可以看到各种发布的内容及其大致位置，但看不到姓名、个人资料照片和确切地点。任何人都能在一分钟内加入，因此其成员看到的彼此刊登位置也会模糊到大约一公里范围；精确地点则由你在约定见面时自行告知对方。

📅

活动 新功能

发布互助劳动、维修咖啡馆或技能分享，附上时间和地点。大家可以点击“确定参加”或“感兴趣”。确定参加的人可以进入活动聊天室并查看组织者的私密备注 — 大门密码、需要携带的物品 — 并在时间和地点变动或活动取消时收到通知。在任何人都能加入的地方（如全球社区），默认由组织者先逐一审核入场。活动完全免费；不涉及任何豆子交易。你可以在地图上的“今天”、“本周末”或“未来 7 天”下找到它们，并使用“复制到新日期”再次举办。

💬

对话（网页端为聊天）

向你社区内的任何人发送消息。私信与群聊均采用端到端加密：你所在社区的节点负责传输但无法读取内容。在尚未更新的节点上，群聊仍可被运营该节点的人读取，聊天界面会对此进行说明。企业讨论和活动聊天可由运营社区节点的人读取，以便进行管理审核。

🏛️

公共资金池：企业 新功能

企业是你的社区共同运营的实体：养鸡合作社、工具图书馆、柴火储备站，或者带有明确目标和截止日期的项目。管理者负责日常运营，主管理者主持大局；成员可以申请加入成为管理者。企业拥有自己的豆子，像其他人一样在市集中发布提供与需求，公开其收支明细，并可按季节暂停运作。任何管理者都不得批准向自己付款：必须由另一位管理者批准。

🗳️

投票与决策 新功能

任何人都可以在市集中发起投票向社区提问。更重大的选择是决策，位于公共资金池标签页：从公共资金池向企业拨款、困难补助金、更换主管理者。一项决策开放投票 7 天，若通过则自动执行。一旦你完成了一笔交易，就可以发起提议。

👥

群组 新功能

为你的街道、园艺俱乐部或乐队创建群组，你将成为召集人。仅向群组内发布内容，并可自由选择群组是公开、需申请加入还是仅限受邀加入。

📡

脉搏

了解本地居民正在创作什么。成员可以关联自己的频道 — TikTok、Instagram、YouTube、SoundCloud 或博客订阅源 — 其公开动态就会显示在你社区的“脉搏”中。是否关联完全由每位成员自行决定。任何不当内容均可被举报，你社区的节点可以将其下架。

信用靠积累，而非借贷

0️⃣

每个人的初始都是零

新账户拥有 0 个豆子。当你出售时，余额增加；当你购买时，余额减少。在整个社区中，所有余额相加始终为零。

⚖️

第一笔交易开启信用额度

一旦你完成了一笔交易，就可以开始透支（低于零）在回馈之前先行获取帮助。你的信用额度从很小开始（一笔 100 个豆子的交易大约能获得 37 个豆子的额度），随着你与更多人交易而成长。你保持发布的提供数量决定了你能使用多少额度：1 个提供最多可达 200 个豆子，5 个提供最多可达 2000 个豆子。

🏅

徽章，而非门槛

随着时间的推移，你会获得徽章：新人、居民、管家、长者。它们展现你在社区中的历程。它们不会带来任何功能限制。管理员也可以授予某人一枚徽章，并随之附带该徽章的初始信用额度。

你的账户与安全

🔑

你的密钥保留在手机中

在手机应用中，你的密钥保存在手机的安全存储中，你还可以添加应用锁，它会要求验证你手机自身的屏幕锁。在网页版中，密钥保存在该浏览器的独立存储中。你的 12 个助记词是无需依赖任何人的独立备份。

🚩

举报任何问题

你可以举报任何帖子、成员、活动或脉搏动态，并屏蔽任何人。举报将发送给运营你社区节点的人员 — 即所有者与管理员 — 他们可以移除相关内容和账户。成员也可以通过投票表决决策来暂停或注销某人的账户。

与邻近社区建立互联

两个社区可以通过协商建立互联，以便彼此的成员相互交易。豆子绝不会流出本社区：双方社区保持一份彼此欠款的流水账，并且各自设定信用限额。除非双方运维人员都开启互联，否则默认处于关闭状态，目前该功能仍处于早期阶段：它已开发完成，在网页端有对应界面，但仅在我们的两个测试社区之间进行过试验，尚未在实际运行的社区之间使用。

建立一个社区

按照指南操作大约需要半小时。请先了解以下六件事：

  • 费用成本。软件是免费的。它可以运行在家里保持开机的闲置电脑上（迷你主机、NAS 或安装了 64 位系统的树莓派），也可以运行在每月花费数美元（约 6 美元）的小型租用服务器上。
  • 由谁托管。由你自行托管，在你自己的机器或你租用的服务器上。它从不需要依赖 beanpool.org：你自己的网络地址即可正常使用。
  • 你的职责承担。成员的举报会发送给你。数据文件夹由你使用恢复代码进行备份。请保持两位所有者。保持服务器开机运行并及时更新。
  • 你绝不会看到的内容。你成员之间的私信。
  • 先准备 Docker。在执行下方命令块之前，机器上需要安装 Docker；全新租用的服务器通常未安装。
  • 手机可访问的地址。手机在互联网上只能通过 https 连接社区。在拥有公网 IP 地址且开放了 80 和 443 端口的租用服务器上，直接使用该 IP 地址就足够了：你的服务器无需 Cloudflare 账户即可自行获取对应证书，使用你自己的域名也是如此。在家里或没有开放端口的情况下，认领过程会通过服务器自身运行的隧道为你提供一个以 .beanpool.org 结尾的免费域名。普通的 http:// 地址仅在家庭局域网内有效。

最后一行命令：beanpool claim

  1. 你的地址。在粘贴前确定好，并修改最后一行命令以保持一致。如果你已经粘贴了，在提示问题处按回车键，然后重新运行最后一行：认领码会等待手机扫码。租用服务器（具有公网 IP 地址且开放 80 和 443 端口）：添加 --ip 及其 IP 地址，例如 beanpool claim --ip 203.0.113.7。你的服务器会通过 80 端口从 Let's Encrypt 为该地址获取专属证书，手机可通过 https://203.0.113.7 访问。家用电脑或未开放端口：保持原样即可。它会询问免费域名的前缀（例如输入 yourtown 即可获得 yourtown.beanpool.org；按回车跳过），通过服务器自行运行的隧道进行访问，最多等待三分钟即可上线。自有域名：将其 A 记录指向服务器的 IP 地址，开放 80 和 443 端口，并添加 --address https://your.domain。域名在更换服务器后仍能沿用，而 IP 地址不行：你稍后也可以在“设置”中添加域名，使用 IP 地址的成员不受影响。如需稍后在“设置”中选择，请添加 --no-name。普通的 http:// 地址仅在家庭网络中有效：手机在互联网上会拒绝连接，认领过程也会给出警告。即使 BeanPool 项目的地址服务暂时不可用，认领操作依然可以正常工作。
  2. 认领码与二维码。它会显示一个一次性认领码和一个二维码。使用手机相机扫描二维码，或者打开 BeanPool，在寻找你的社区下输入服务器地址并点击认领。该手机即成为所有者。
  3. 设置。在浏览器中打开你的地址（或服务器自身地址）加上 /settings。设置向导会引导你为社区命名、添加第二位所有者，并生成三个创办邀请。在“节点身份”下设置你在地图上的位置，以便附近的人能找到你。

如果命令块提示 No claim code after 5 minutes，或者 beanpool claim 提示 This community has no claim code waiting，说明服务器尚未完成启动：docker compose logs beanpool-node 会显示当前进度。一旦日志显示该社区尚无所有者并已生成认领码，请重新运行最后一行命令。完整步骤可参见运维手册中的首次设置。
