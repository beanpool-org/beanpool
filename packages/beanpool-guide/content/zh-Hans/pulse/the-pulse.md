## 什么是社区动态

从**首页**上的**动态**卡片打开社区动态：点按任意帖子，或点按**查看全部**。如果首页上没有该卡片，可以通过手机上的**添加卡片**或 Web 应用中的**编辑首页**将其重新添加。在手机上，你也可以从**设置**中的**动态**下方将其打开。

社区动态汇集了你所在社区成员在其他网站上发布的内容：视频、音乐、博客、照片。这是一种了解邻居们在创作什么、做些什么的途径。

- **邻里：**来自成员频道的内容。顶部的按钮用于选取主题，例如“食物与种植”或“维修与再利用”。**全部**显示所有内容。
- **学习**（手机应用）：关于 BeanPool 运作方式的视频，以及简短的每日心得。参见““学习”板块”。在 Web 应用中，它们直接显示在动态流中，顶部的**运作方式**仅显示这些教学内容。

向下拉动即可刷新。在 Web 应用中，改为点按顶部的 🔄。

在手机上，当你向下滚动时，顶部的按钮会滑开。向上稍作滚动即可重新出现。

## 打开帖子

**YouTube 视频：**在手机上，点按带有 ▶ 的图片，视频就会直接在卡片内播放。在点按之前不会从 YouTube 加载任何内容 — 滚动滑过视频不会向任何人发送任何数据。点按视频角落的按钮可全屏播放。

当你将视频滚动出视野、离开动态或播放另一个视频时，当前视频就会停止。同一时间只能播放一个视频。

在 Web 应用中，视频不会在卡片内播放。点按图片或标题即可在浏览器的新标签页中打开 YouTube。

**其他所有内容** — TikTok、Instagram、博客、网站：点按图片或标题，即可在你的浏览器或该网站的专属应用中打开。

你也可以随时选择改为在 YouTube 上打开视频：点按标题，或点按其下方的 **Open on YouTube ↗**。如果视频无法在此播放（部分创作者禁止在其网站以外播放，部分手机也无法支持播放），卡片会说明原因并为你提供该按钮。

## 帖子存在问题

- **他人的帖子：**点按旗标，选择原因（**垃圾信息或诈骗**、**令人反感或冒犯的内容**、**误导性帖子**、**儿童安全**或**其他**），然后点按**提交举报**。运营你社区服务器的人员会进行审核。
- **你自己的帖子：**点按**隐藏**，然后点按**从动态隐藏**。该帖子将对所有人从动态中下架。已隐藏的帖子无法恢复。在 Web 应用中，你还可以点按**删除**，然后点按**永久删除**，彻底移除你的帖子。

你无法仅为自己单独隐藏他人的帖子。

## 添加你自己的内容

点按顶部的 **+ 频道**。参见“分享你的频道”。
