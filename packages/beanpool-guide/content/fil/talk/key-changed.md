## Ano ang ibig sabihin nito

Bawat mensahe sa pagitan ng dalawang tao ay naka-lock upang ang telepono lamang ng kabilang tao ang makakabukas nito. Naka-lock ito sa kanilang **key**, hindi sa kanilang pangalan. Inililista ng iyong komunidad kung aling key ang sa tao, at naaalala ng iyong telepono kung aling key nito ini-lock ang iyong chat.

Kapag naglista ang iyong komunidad ng bagong key para sa tao, ang gagawin ng iyong telepono ay nakadepende sa isang bagay: kung minarkahan mo sila bilang na-verify sa teleponong ito.

## Isang taong hindi mo pa minarkahan bilang na-verify

Nagpapatuloy ang chat gamit ang bagong key. Nagsusulat ang iyong telepono ng isang kulay-abong linya sa chat, halimbawa: **Nagbago ang key ni Ben. Kadalasan, ibig sabihin nito ay nakabalik siya sa account niya sa bagong telepono. I-tap para makita ang key code niya.**

Walang naka-pause, walang tag ang chat sa **Usapan**, at mababasa pa rin ang iyong mga naunang mensahe. Naroon ang linya para ipaalam sa iyo, hindi para magbabala. I-tap ito para makita ang kanilang key code.

## Bakit maaaring magbago ang isang key

- **Nakabalik sila sa kanilang account sa bagong telepono.** Ito ang karaniwang dahilan. Inilipat ng isang admin ang kanilang account sa bagong telepono, kaya may bago silang key.
- **May mali.** Inililista ng server ng komunidad kung sino ang nasa bawat chat. Ang isang server na gustong magbasa ng iyong mga mensahe ay maaaring maglagay ng key ng ibang tao sa likod ng pangalan ng iyong kaibigan. Mukhang tama ang pangalan, ngunit hindi ang key.

Hindi kayang pag-ibahin ng iyong telepono ang mga ito nang mag-isa. Magagawa mo ito, gamit ang key code.

## Suriin ang key code ng isang tao

- Sa chat, i-tap ang **⋯** sa itaas, pagkatapos ay ang **Key code**. Nabubuksan din ito kapag na-tap ang kulay-abong linya.
- Makikita mo ang kanilang key code: 20 digit sa limang pangkat ng apat.
- Hilingin sa tao na basahin sa iyo ang **Aking key code**. Sa app sa telepono, nasa **Mga Setting** ito, sa ilalim ng **Proteksyon ng Account**. Sa web app, nasa **Mga Setting** ito, sa ilalim ng **ACCOUNT AT PAGKAKAKILANLAN**.
- Suriin ito **nang personal, o sa isang tawag sa telepono o video** kung saan alam mong sila ito. Huwag itong suriin sa pamamagitan ng mensahe sa BeanPool: kung mali ang key, mali rin ang sinumang sumasagot.
- Kung tumutugma ang bawat digit, talagang sila ang kausap mo sa chat na ito. Maaari mo nang i-tap ang **Markahan bilang na-verify**.

Hindi lihim ang code. Ligtas itong basahin nang malakas.

## Markahan bilang na-verify

Sa **Markahan bilang na-verify**, magtatanong muna sa iyo ang iyong telepono bago ito magpadala sa bagong key para sa taong ito. Ipapakita na ng screen ng key code ang **Na-verify ✓**, at gayundin ang itaas ng chat, katabi ng **🔒 End-to-end encrypted** sa ilalim ng kanilang pangalan.

Sa teleponong ito lamang itinatago ang marka, para sa chat na ito sa komunidad na ito. Wala nito ang web app, at inaalis ito ng pag-reset sa memorya ng chat ng komunidad (sa ibaba).

Para bawiin ito, buksan muli ang **Key code**, i-tap ang **Alisin ang pag-verify**, at kumpirmahin gamit ang **Alisin ang pag-verify**.

## Kung nagbago ang key ng taong minarkahan mo bilang na-verify

Hihinto ang iyong telepono at magtatanong sa iyo, sa halip na magpadala sa bagong key. Sa itaas ng chat makikita mo ang **Nagbago ang key sa likod ni «Ben».** Nagsisimula ang banner sa **Minarkahan mo si Ben bilang na-verify, kaya nagtatanong muna ang teleponong ito bago magpadala sa bagong key.** at ipinapakita nito ang bagong key code.

Naka-grey out ang kahon ng mensahe, at sa itaas nito ay nakasulat ang **Nagbago ang key sa likod ni Ben, kaya pansamantalang itinigil ang pagpapadala.** Ang mensahe mula sa bagong key ay mababasang **Ipinadala mula sa bagong key. Ipapakita matapos kang magpatuloy.** hanggang sa magpasya ka. Nagpapakita ang chat ng tag na **nagbago ang key** sa **Usapan**.

Suriin ang bagong code sa tao, tulad ng nasa itaas. Kung tumutugma ang bawat digit, lagyan ng tsek ang **Tiningnan ko kay Ben: tumutugma dito ang key code sa Mga Setting niya.**, pagkatapos ay i-tap ang **Magpatuloy gamit ang bagong key**. Mula noon ang iyong mga mensahe ay mapupunta sa bagong key, mananatiling **Na-verify ✓** si Ben, mawawala ang banner at ang tag, at mababasa pa rin ang iyong mga naunang mensahe.

Kung hindi tumutugma ang code, o hindi mo masuri, i-tap ang **Huwag muna**. Walang ipinapadala at walang nagbabago. Mananatiling naka-pause ang chat hanggang sa magpatuloy ka: nagtatago ang iyong komunidad ng isang chat para sa inyong dalawa, kaya ang pagsisimula ng bagong chat sa parehong tao ay nagbubukas ng parehong chat na ito.

Kung hindi tumutugma ang code, huwag magpatuloy. Sabihin sa tao at sa mga admin ng iyong komunidad: maaaring may sumusubok na basahin ang iyong mga mensahe.

Sa screen ng key code, tinatapos din ng **Alisin ang pag-verify** ang pag-pause: nagpapatuloy ang chat gamit ang bagong key, nang walang pagsusuri.

## Kung nagbibigay ng petsa ang komunidad

Kapag maipapakita ng iyong komunidad na binigyan ng bagong key ang account, sinasabi ito ng banner, halimbawa: **Sinasabi ng komunidad na ito na binigyan ng bagong key ang account noong 3 Okt 2026.** Nakakatulong iyon upang maunawaan mo kung ano ang nangyari, ngunit hindi nito pinapalitan ang pagsusuri sa code: masasabi rin ito ng isang server.

## Kung walang key na maipagpapatuloy

Kung minsan ang komunidad ay hindi naglilista ng iisang key para sa tao sa isang chat sa pagitan ng dalawang tao: naglilista ito ng ilan, o wala. Kung gayon ay walang key na mapagla-lock-an ng iyong mga mensahe, minarkahan mo man sila bilang na-verify o hindi. Sinasabi ito ng banner at nag-aalok lamang ng **Huwag muna**, walang ipinapadala, at nagpapakita ang chat ng tag na **nagbago ang key** sa **Usapan**. Sinasabi ng screen ng key code ang **Walang inililistang iisang key ang komunidad para kay Ben sa chat na ito, kaya naghihintay ang pagpapadala.**

Makipag-usap sa tao nang personal o sa isang tawag. Sinusuri muli ng iyong telepono ang chat nang kusa kapag nagbago ang listahan ng komunidad, at ang isang bagong chat sa parehong tao ay ang parehong chat na ito.

Kung hindi rin maitugma ng iyong telepono ang mga naunang mensahe sa isang key, sa itaas ng kahon ng mensahe ay nakasulat ang **Hindi maitugma ng teleponong ito ang chat sa isang key, kaya naka-off ang pagpapadala. Maaaring hindi galing sa kanila ang mababasa mo rito.**, at walang code na maipapakita ang screen ng key code.

## Matapos mong i-restore o i-set up muli ang iyong telepono

Sinusuri ng iyong telepono ang bawat chat laban sa mga naunang mensaheng hawak nito. Kung nagmula ang mga mensaheng iyon sa mas lumang key kaysa sa inililista ngayon ng iyong komunidad, nagpapatuloy ang chat gamit ang nakalistang key, mababasa pa rin ang mga naunang mensahe, at isang beses lalabas ang kulay-abong linya.

Kung hindi maitugma ng iyong telepono ang ilan sa mga ito sa anumang key, nagpapatuloy pa rin ang chat gamit ang key na inililista ng iyong komunidad, nang walang linya. Ang mensaheng hindi nito mabuksan ay mababasang **Hindi ma-verify ang mensaheng ito, kaya hindi ito ipinapakita.** Mananatili itong ganoon.

## Memorya ng chat

Nagtatago ang iyong telepono ng maliit na memorya para sa bawat komunidad: kung saang key ang bawat isa sa iyong mga chat, sino ang minarkahan mo bilang na-verify, at aling mga chat ang pribado. Itinatago ito sa telepono. Nananatili ito sa telepono kapag nag-sign out ka, kaya ang pag-sign out at pag-sign in muli ay hindi nagbubura nito. Hindi ito kailanman ini-reset ng telepono nang kusa.

Maaari mo itong i-reset para sa isang komunidad: buksan ang **Mga Setting**, i-tap ang **Memorya ng chat** sa ilalim ng **ACCOUNT AT PAGKAKAKILANLAN**, i-tap ang **I-reset** sa tabi ng komunidad, basahin ang babala, at i-tap ang **I-reset** muli. Dinadala ka lamang ng app dito kapag sinabi nitong hindi nito mabasa ang memoryang iyon at hindi nakatulong ang muling pagsubok.

Pagkatapos ng pag-reset, sinusuri muli ng iyong telepono ang bawat chat sa komunidad na iyon mula sa simula, mula sa mga mensaheng hawak nito, gaya ng ginagawa nito pagkatapos ng pag-restore.

Sinasabi ng babala kung ano ang maaaring magbago bago ka magkumpirma. Ang isang chat na na-pause dahil nagbago ang key nito ay maaaring magbukas gamit ang bagong key. Ang isang pribadong chat na nawala sa Usapan ay maaaring bumalik bilang panggrupong chat na mababasa ng komunidad. Ang mga taong minarkahan mo bilang na-verify sa komunidad na ito ay babalik sa hindi na-verify. Suriin ang key code, o kung sino ang nasa chat, bago ka magpadala.

Ito ay sa app sa telepono. Walang memorya ng chat ang web app.

## Sa web app

Hindi naaalala ng web app ang mga key. Sa bawat pagpapadala mo, ini-lock nito ang iyong mensahe sa iisang key na inililista ng iyong komunidad para sa tao, at kung naglilista ito ng ilan o wala, hindi naipapadala ang iyong mensahe. Kaya wala itong ipinapakitang kulay-abong linya o banner, at wala itong **Markahan bilang na-verify**: ang taong minarkahan mo bilang na-verify sa iyong telepono ay hindi napapa-pause sa web app.

Mababasa mo pa rin doon ang mga key code. Ang **Aking key code** ay nasa **Mga Setting**, sa ilalim ng **ACCOUNT AT PAGKAKAKILANLAN**. Sa isang chat sa pagitan ng dalawang tao, may **Key code** ang menu na **⋮**: ipinapakita nito ang code ng tao, at sinasabi nitong hindi naaalala ng browser ang mga key code.

## Kung ano ang kayang suriin ng iyong telepono, at kung ano ang hindi

Para sa taong hindi mo pa minarkahan bilang na-verify, ang listahan ng iyong komunidad ang nagpapasya ng key tuwing nagbabago ito, at sinasabi ito sa iyo ng iyong telepono sa pamamagitan ng kulay-abong linya. Sa teleponong may hawak na ng chat, palaging nag-iiwan ng linya ang nagbagong key. Ang teleponong kaka-restore mo lang ay maaaring mailigaw: ang isang server na nagpipigil sa mga mas lumang mensahe ay walang iniiwang linya.

Hindi kayang pag-ibahin ng linya ang bagong telepono at ang pinalitang key. Ang key code lamang ang makakagawa nito, at ang **Markahan bilang na-verify** lamang ang magpapahinto sa iyong telepono sa susunod. Kung mahalaga sa iyo ang isang chat, suriin ang code nang personal, o sa isang tawag kung saan alam mong sila ito, at markahan sila bilang na-verify.
