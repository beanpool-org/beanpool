## Où l'envoyer

- **Dans une discussion avec une personne**, une fois que c'est une discussion ordinaire : pas tant que votre premier message est encore une demande de message.
- **Dans la discussion d'un groupe**, où elle est verrouillée de bout en bout.
- Sur le téléphone, et dans l'appli web avec Chrome, Edge et Safari.

On ne peut pas envoyer de messages vocaux dans les discussions d'événements ou d'entreprises (le serveur de la communauté peut les lire), dans une demande de message, dans le forum, ni dans une discussion avec quelqu'un d'une autre communauté. Le micro n'apparaît que là où le serveur de votre communauté accepte les messages vocaux : un serveur plus ancien ne les accepte pas, et il n'y a alors pas de micro. Si cela change pendant que vous enregistrez, l'enregistrement est conservé et la zone de saisie indique « Cette communauté n’accepte pas encore les messages vocaux. Rien n’a été envoyé. »

Un message vocal que quelqu'un vous envoie dans une demande de message s'affiche « 🎤 Message vocal : visible quand vous acceptez ». Il n'est pas récupéré tant que vous n'avez pas accepté.

## Enregistrer sur le téléphone

Quand la zone de saisie est vide, le bouton d'envoi est un micro.

- **Maintenez-le pour enregistrer et relâchez pour envoyer.** Le micro devient rouge et un chronomètre tourne pendant l'enregistrement.
- **Glissez à gauche pour annuler** (« Glissez pour annuler »). Rien n'est envoyé.
- **Glissez vers le haut pour verrouiller**, et vous pouvez relâcher. Touchez arrêter, puis réécoutez-le, supprimez-le avec la corbeille ou envoyez-le.
- Moins d'une seconde n'envoie rien, et « Maintenez pour enregistrer » s'affiche au-dessus de la zone de saisie.
- Un enregistrement peut durer jusqu'à 3 minutes. À 3:00, il s'arrête tout seul et attend que vous l'envoyiez.
- Avec un lecteur d'écran activé, ou avec un texte à 1.5 fois la taille ou plus, il n'y a rien à maintenir : touchez pour commencer (**Enregistrer un message vocal**), puis touchez arrêter.

La première fois, maintenir le micro demande seulement au téléphone de laisser BeanPool l'utiliser. Il ne le demande jamais avant. Si le micro est désactivé pour BeanPool, l'appli indique « Le micro est désactivé pour BeanPool » avec **Ouvrir les paramètres**.

Passer à une autre appli interrompt un enregistrement et le garde pour que vous l'envoyiez ou le supprimiez : il n'est jamais envoyé tout seul. Quitter la discussion jette un enregistrement que vous n'avez pas envoyé. Si un message vocal ne peut pas être envoyé, l'appli indique « Message vocal non envoyé » et garde l'enregistrement, pour que vous puissiez réessayer.

## Enregistrer dans l'appli web

Cliquez sur le micro pour commencer, et arrêtez quand vous avez fini. Puis réécoutez, supprimez ou envoyez. Le premier clic demande à votre navigateur de laisser le site utiliser le micro. Si le navigateur refuse, l'appli web indique « Le micro est désactivé pour ce site. Autorisez-le dans les réglages du site de votre navigateur, puis réessayez. » Moins d'une seconde n'envoie rien : « Trop court pour être envoyé. Enregistrez au moins une seconde. »

- **Firefox** peut lire les messages vocaux mais pas les enregistrer. À la place, l'appli web indique « Ce navigateur ne peut pas enregistrer de messages vocaux. Chrome, Edge, Safari et l’appli du téléphone le peuvent. »
- **La page d'une communauté ouverte en http simple**, comme sur un réseau domestique, ne peut pas enregistrer non plus : « Les messages vocaux ne peuvent pas être enregistrés à cette adresse. L’appli du téléphone le peut. »

## Écouter

- Touchez lecture. Faites glisser le doigt le long de l'onde pour vous déplacer dedans.
- Le bouton de vitesse passe par 1×, 1.5×, 2×, et se souvient de votre choix.
- Quand un message se termine, le message vocal suivant de la discussion qui n'est pas de vous et que vous n'avez pas écouté se lit tout seul. Un seul est lu à la fois.
- Sur le téléphone, il passe par le haut-parleur, même quand le téléphone est en mode silencieux. Il s'arrête quand vous quittez la discussion ou passez à une autre appli. Dans l'appli web, il s'arrête quand vous quittez la discussion.
- Personne n'est prévenu que vous avez écouté. Les deux coches bleues indiquent toujours qu'un message a été lu.

Votre liste de discussions, une carte de discussion sur Accueil et une réponse citée affichent « 🎤 Message vocal ». Une alerte indique seulement « Vous avez un nouveau message. » (dans un groupe, « Nouveau message dans l'un de vos groupes. »).

Les messages vocaux ne peuvent pas être modifiés. Vous pouvez en supprimer un des vôtres, comme n'importe quel message : voir « Messages ».

Si un message vocal ne se lit pas, il dit pourquoi : « Ce message vocal ne peut pas être lu. » (dans l'appli web, « Ce message vocal ne peut pas être lu dans ce navigateur. » là où le navigateur ne peut pas lire le son), ou « Message vocal indisponible. Touchez pour réessayer. »

## Combien de temps il est gardé

Le serveur de votre communauté garde un message vocal 30 jours, puis supprime le son. Le message reste dans la discussion.

- **Sur le téléphone**, les sons que vous avez envoyés ou écoutés sont gardés sur le téléphone, jusqu'à 200 Mo, les plus anciens partant en premier. Un message vocal que vous avez écouté là-bas se lit toujours après les 30 jours.
- **Dans l'appli web**, rien n'est gardé dans le navigateur. Après 30 jours, et sur un téléphone qui ne l'a jamais écouté, le message indique « Ce message vocal n’est plus sur le serveur. »
- Un message vocal signalé dans la discussion d'un groupe est gardé pour les modérateurs tant que le signalement attend.

Les messages vocaux comptent dans les photos que vous pouvez envoyer par jour (100 Mo par jour, sauf si votre communauté fixe une autre quantité). Au-delà, l'appli indique « Vous avez partagé beaucoup de photos aujourd'hui. Réessayez demain. »

## Ce qui est privé

Un message vocal est verrouillé sur votre téléphone ou dans votre navigateur avant d'être envoyé, avec les mêmes clés qu'une photo dans cette discussion, et signé par vous. Le serveur de votre communauté ne peut pas l'écouter. Il connaît sa taille, qui donne à peu près sa durée, et qui l'a envoyé à qui, et quand. Sa durée et son onde sont dans le verrou.

Vous pouvez signaler un message vocal comme n'importe quel message (voir « Signaler un problème »). Les modérateurs de votre communauté ne peuvent pas encore lire un message vocal signalé dans les paramètres : ils voient qu'il a été signalé, qui l'a envoyé et votre raison.

Supprimer votre compte supprime du serveur de votre communauté tous les messages vocaux que vous avez envoyés. Voir « Quitter ou supprimer le compte ».
