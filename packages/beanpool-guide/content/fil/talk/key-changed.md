## Ano ang ibig sabihin nito

Bawat mensahe sa pagitan ng dalawang tao ay naka-lock upang ang telepono lamang ng kabilang tao ang makakabukas nito. Naka-lock ito sa kanilang **key**, hindi sa kanilang pangalan. Naaalala ng iyong telepono kung aling key nito ini-lock ang iyong chat.

Kung magpapangalan ngayon ang iyong komunidad ng ibang key para sa tao, hihinto ang iyong telepono at sasabihin sa iyo, sa halip na tahimik na magpadala sa bagong key. Sa itaas ng chat makikita mo ang **Nagbago ang key sa likod ni "Ben".** Naka-grey out ang kahon ng mensahe at sinasabing pansamantalang itinigil ang pagpapadala.

Ang iyong mga naunang mensahe sa kanila ay karaniwang mababasa pa rin tulad ng dati. Sa isang teleponong kaka-restore mo lang o na-set up muli, ang mga mensahe mula sa bagong key ay mababasang **Ipinadala mula sa bagong key. Ipapakita matapos kang magpatuloy.** hanggang sa magpasya ka.

Ito ay sa app sa telepono. Hindi pa naaalala ng web app ang mga key.

## Bakit ito maaaring mangyari

- **Nagkaroon sila ng bagong telepono at nag-re-key.** Ito ang karaniwang dahilan. Nawala ang kanilang lumang key, kaya may bago na sila.
- **May mali.** Inililista ng server ng komunidad kung sino ang nasa bawat chat. Ang isang server na gustong magbasa ng iyong mga mensahe ay maaaring maglagay ng key ng ibang tao sa likod ng pangalan ng iyong kaibigan. Mukhang tama ang pangalan, ngunit hindi ang key.

Hindi kayang pag-ibahin ng iyong telepono ang mga ito nang mag-isa. Magagawa mo ito, gamit ang key code.

## Suriin ang key code sa kausap

- Nagpapakita ang banner ng isang code: 20 digit sa limang pangkat ng apat.
- Hilingin sa tao na buksan ang **Mga Setting**, pagkatapos ay **Proteksyon ng Account**, at basahin sa iyo ang **Aking key code**.
- Ang **Aking key code** ay nasa app lamang sa telepono. Kung ang tao ay gumagamit lamang ng web app, hindi pa nila ito mababasa sa iyo: i-tap ang **Huwag muna** hanggang sa mabuksan nila ang app sa telepono.
- Suriin ito **nang personal, o sa isang tawag sa telepono o video** kung saan alam mong sila ito. Huwag itong suriin sa pamamagitan ng mensahe sa BeanPool: kung mali ang key, mali rin ang sinumang sumasagot.
- Kung tumutugma ang bawat digit, lagyan ng tsek ang **Tiningnan ko kay Ben: tumutugma dito ang key code sa Mga Setting niya**, pagkatapos ay i-tap ang **Magpatuloy gamit ang bagong key**.

Mula noon ang iyong mga mensahe ay mapupunta sa bagong key. Ang banner at ang tag na **nagbago ang key** sa chat sa **Usapan** ay mawawala, at mababasa pa rin ang iyong mga naunang mensahe.

Hindi lihim ang code. Ligtas itong basahin nang malakas.

## Kung hindi tumutugma ang code, o hindi mo masuri

I-tap ang **Huwag muna**. Walang ipinapadala at walang nagbabago. Maaari kang bumalik sa chat mamaya.

Maaaring manatiling naka-pause ang isang naka-pause na chat hanggang sa magpatuloy ka. Walang ibang paraan upang magpatuloy sa pakikipag-usap dito: nagtatago ang iyong komunidad ng isang chat para sa inyong dalawa, kaya ang pagsisimula ng bagong chat sa parehong tao ay nagbubukas ng parehong chat na ito.

Kung hindi tumutugma ang code, huwag magpatuloy. Sabihin sa tao at sa mga admin ng iyong komunidad: maaaring may sumusubok na basahin ang iyong mga mensahe.

## Kung walang iniaalok na key ang banner para ipagpatuloy

Kung minsan ang komunidad ay hindi naglilista ng iisang key para sa tao sa isang chat sa pagitan ng dalawang tao: naglilista ito ng ilan, o wala. Wala kung gayon key na maipagpapatuloy, kaya sinasabi ito ng banner at nag-aalok lamang ng **Huwag muna**. Walang ipinapadala. Makipag-usap sa tao nang personal o sa isang tawag. Sinusuri muli ng iyong telepono ang chat nang kusa kapag nagbago ang listahan ng komunidad, at ang isang bagong chat sa parehong tao ay ang parehong chat na ito.

## Kung sinasabi ng banner na sinusuri ng iyong telepono ang chat mula sa simula

Matapos mong i-restore ang iyong telepono mula sa iyong 12 salita, o i-update ang app, sinusuri ng iyong telepono ang bawat chat laban sa sarili nitong mga naunang mensahe. Kung ang mga iyon ay nagmula sa ibang key kaysa sa ibinibigay ngayon ng iyong komunidad para sa tao, ang banner ay nagsisimula sa **Sinusuri ng teleponong ito ang chat na ito mula sa simula, gaya ng ginagawa nito matapos mong mag-restore o mag-update ng app.** Suriin ang code sa tao tulad ng nasa itaas. Matapos mong i-reset ang memorya ng chat ng komunidad, nagsisimula ito sa **Na-reset ang memorya ng chat ng komunidad na ito, kaya sinusuri ng telepono ang chat na ito mula sa simula.** sa halip.

## Memorya ng chat

Nagtatago ang iyong telepono ng maliit na memorya para sa bawat komunidad: kung saang key ang bawat isa sa iyong mga chat, at aling mga chat ang pribado. Itinatago ito sa telepono, at hindi maililipat ng server ng komunidad ang isang chat sa ibang key nang mag-isa: ikaw lamang ang makakagawa nito, sa banner. Nananatili ito sa telepono kapag nag-sign out ka, kaya ang pag-sign out at pag-sign in muli ay hindi nagbubura nito. Hindi ito kailanman ini-reset ng telepono nang kusa.

Maaari mo itong i-reset para sa isang komunidad: buksan ang **Mga Setting**, i-tap ang **Memorya ng chat** sa ilalim ng **ACCOUNT AT PAGKAKAKILANLAN**, i-tap ang **I-reset** sa tabi ng komunidad, basahin ang babala, at i-tap ang **I-reset** muli. Dinadala ka lamang ng app dito kapag sinabi nitong hindi nito mabasa ang memoryang iyon at hindi nakatulong ang muling pagsubok.

Pagkatapos ng pag-reset, sinusuri muli ng iyong telepono ang bawat chat sa komunidad na iyon mula sa simula, mula sa mga mensaheng hawak nito. Ang isang chat na ang mga mensahe ay nagmula sa ibang key kaysa sa ibinibigay ngayon ng komunidad ay nagpapakita muli ng banner, simula sa **Na-reset ang memorya ng chat ng komunidad na ito, kaya sinusuri ng telepono ang chat na ito mula sa simula.** Suriin ang code sa tao tulad ng nasa itaas.

Dalawang bagay ang maaaring magbago pagkatapos ng pag-reset, at sinasabi ito ng babala bago ka magkumpirma: ang isang chat na na-pause dahil nagbago ang key nito ay maaaring magbukas gamit ang bagong key, at ang isang pribadong chat na nawala sa Usapan ay maaaring bumalik bilang panggrupong chat na mababasa ng komunidad. Suriin ang key code, o kung sino ang nasa chat, bago ka magpadala.

Hindi nakakatulong ang pag-reset sa isang chat na hindi maitugma ng iyong telepono sa isang key: sinusuri itong muli at humihinto muli. Suriin ang code sa tao sa halip (sa itaas).

Ito ay sa app sa telepono. Walang memorya ng chat ang web app.

## Kung sinasabi ng banner na hindi maitugma ng iyong telepono ang chat sa isang key

Kung minsan ang mga naunang mensahe sa isang chat ay naka-lock sa mga key na hindi maitugma ng iyong telepono sa isang tao. Sa itaas ng kahon ng mensahe sinasabi nitong **Hindi maitugma ng teleponong ito ang chat sa isang key, kaya naka-off ang pagpapadala.** at ipinapakita ng banner ang code ng key na inililista ngayon ng iyong komunidad para sa tao.

Maaaring lumabas pa rin ang ilang mensahe. Maaaring hindi galing ang mga ito sa taong ang pangalan ay nasa chat: ang sarili nilang mga naunang mensahe ay maaaring ang mga mababasang **Hindi ma-verify ang mensaheng ito, kaya hindi ito ipinapakita.** Mananatili ang mga iyon sa ganoong paraan, kahit na magpatuloy ka.

Suriin ang code sa tao tulad ng nasa itaas, nang personal o sa isang tawag. Kung tumutugma ito, lagyan ng tsek ang kahon at i-tap ang **Magpatuloy gamit ang bagong key**: mula noon ang iyong mga mensahe ay mapupunta sa key na iyon. Kung hindi ito tumutugma, o hindi mo masuri, i-tap ang **Huwag muna**. Ang isang bagong chat sa parehong tao ay ang parehong chat na ito, kaya wala nang iba pang masusubukan. Kung walang inililistang iisang key ang komunidad para sa kanila, ang banner ay nag-aalok lamang ng **Huwag muna**, at sinusuri muli ng iyong telepono ang chat nang kusa kapag nagbago ang listahan ng komunidad.

## Kung ano ang kayang suriin ng iyong telepono, at kung ano ang hindi

Sinusuri ng iyong telepono ang isang chat laban sa mga mensaheng hawak na nito. Ang isang naibalik na telepono, o isang umiiral na telepono sa pag-update, ay pinapatnubayan lamang ng isang server na nagpipigil o pumapalibot sa pinakalumang bahagi ng chat sa ipinapadala nito. Ang isang teleponong may hawak na sa pinakalumang bahaging iyon ay hindi pinapatnubayan ng anuman na ipinapadala ng server pagkatapos ng update.

Kaya ang isang teleponong kaka-restore mo lang, o kaka-update lang, ay maaaring mailigaw tungkol sa key ng isang chat. Hindi iyon maiaalis ng banner. **Kumpirmahin ang nabagong key nang personal**, o sa isang tawag kung saan alam mong sila ito.

## Kung nagbibigay ng petsa ang komunidad

Kapag maipapakita ng iyong komunidad na binigyan ng bagong key ang account, sinasabi ito ng banner, halimbawa: **Sinasabi ng komunidad na ito na binigyan ng bagong key ang account noong 3 Okt 2026.** Nakakatulong iyon upang maunawaan mo kung ano ang nangyari, ngunit hindi nito pinapalitan ang pagsusuri sa code: masasabi rin ito ng isang server.
