## Ce qu'elle contient

Sur le téléphone, la barre en haut de l'écran est identique sur chaque onglet. De gauche à droite :

- **Le haricot :** votre communauté et ce guide.
- **Les icônes signalant ce qui vous attend :** uniquement tant que quelque chose attend votre action.
- **L'icône ?, l'icône d'invitation, les Paramètres et votre photo.**

Dans un navigateur web, la barre du haut est plus simple. Elle présente l'état de la connexion sur la gauche, le nom de la page, et votre profil, le **?** et les Paramètres sur la droite. Elle n'a pas de volet haricot, ni d'icônes d'action en attente, ni d'icône d'invitation : les **Invitations** se trouvent sous **Membres**. Les onglets se trouvent le long du bas, ou le long du côté gauche sur un écran large.

## Le haricot

Touchez le haricot en haut à gauche pour ouvrir le volet **BeanPool**. Il affiche :

- **Votre communauté:** son nom en haut, et si elle est accessible pour le moment.
- **Vos communautés :** touchez-en une pour basculer dessus, ou touchez **Ajouter une communauté**. La **Communauté mondiale** est toujours présente parmi elles : sa deuxième ligne indique si vous pouvez la rejoindre.
- **Rechercher dans le guide**, puis **Guides** (comment fonctionne BeanPool, les règles, les questions fréquentes), **Comment utiliser l'application** (ce guide, section par section) et **Le projet BeanPool**, avec les **Nouveautés**.
- **beanpool.org :** le site web public, avec **Partager** pour l'envoyer à un ami.

Le petit point sur le haricot vous indique la situation :

- **Vert :** connecté, et vous êtes membre ici.
- **Orange :** vous visitez en tant qu'invité.
- **Rouge :** le serveur de votre communauté est inaccessible pour le moment, ou ce téléphone n'est pas encore connecté à une communauté.

Une simple vérification lente ne fait pas virer le point au rouge. Il ne passe au rouge qu'après plusieurs échecs consécutifs.

## Les icônes signalant ce qui vous attend

Entre le haricot et les boutons de droite, de petites icônes apparaissent uniquement tant que quelque chose requiert votre attention. Chacune correspond à une tâche. Touchez-la pour vous y rendre directement.

- **Une poignée de main :** un accord vous attend. Quelqu'un attend que vous acceptiez sa demande, ou un accord dans lequel vous êtes engagé n'est pas encore terminé. S'il n'y en a qu'un, le geste ouvre cet accord. S'il y en a plusieurs, il ouvre **Mes accords**.
- **Une urne :** un vote auquel vous n'avez pas encore pris part. Le geste ouvre les **Communs**, à **Décider**. Si le premier vote a lieu dans un groupe ou s'il s'agit d'un vote de gestionnaires dans une entreprise, le geste ouvre ce groupe ou cette entreprise à la place. Un vote auquel vous ne pouvez pas encore participer ne compte pas ici, par exemple un vote qui nécessite de conclure un premier échange.
- **Une bulle de discussion :** un message non lu d'une personne. S'il provient d'une seule personne, le geste ouvre cette discussion. S'il provient de plusieurs personnes, il ouvre **Échanges**, à **Messages**, en n'affichant que les messages non lus.
- **Un groupe de personnes :** de nouveaux messages dans vos groupes, discussions d'entreprises ou échanges d'événements. Les discussions que vous avez mises en sourdine restent discrètes ici. Le geste ouvre la discussion, ou **Échanges**, à **Groupes**, s'il y en a plusieurs.
- **Un bouclier :** réservé aux personnes qui participent à la gestion de votre communauté. Il s'affiche lorsqu'un travail d'administration est en attente, comme un signalement à examiner ou un échange interrompu nécessitant un arbitrage. Le geste vous demande le verrouillage de l'écran de votre téléphone, puis ouvre les paramètres de votre communauté à cette tâche. Si les paramètres de votre communauté utilisent un code de connexion, il vous le demande également.

Les icônes s'empilent depuis la droite. La plus importante se place à côté de l'icône ?, et conserve sa place tandis que d'autres apparaissent et disparaissent.

### Le chiffre et la couleur

- Un petit chiffre sur une icône indique plusieurs éléments de ce type : par exemple 3 personnes qui vous ont écrit. Il affiche **9+** au-delà de 9.
- Une icône devient **orange** lorsqu'elle est plus urgente : un accord qui attend votre action, une tâche d'administration ou un vote qui se clôture sous 2 jours. Rien ne devient rouge.

### Sur un petit écran

S'il n'y a pas assez de place pour chaque icône, le dernier emplacement affiche **•••**. Touchez-le pour voir la liste complète, **Attend votre action**, sous forme textuelle. Touchez une ligne pour vous y rendre.

### Une barre calme est une bonne nouvelle

Quand rien n'attend votre action, il n'y a aucune icône. Vous n'avez rien manqué. Les icônes s'actualisent lorsque vous naviguez dans l'application et lorsque vous y revenez.

## Rejoindre ou Se connecter

À la place des icônes, vous pouvez voir un bouton :

- **Rejoindre** (orange) : vous visitez en tant qu'invité. Touchez-le pour ouvrir les **Invitations**. Dans une communauté locale, vous rejoignez avec une invitation. Dans la communauté globale, touchez **Rejoindre avec 12 mots ou une connexion** (**Rejoindre avec une connexion** là où une communauté n'accepte que les connexions).
- **Se connecter** (rouge) : ce téléphone n'est connecté à aucune communauté. Touchez-le pour ouvrir les **Réglages**, où vous pouvez en ajouter une.

Pendant que l'un de ces boutons s'affiche, l'icône d'invitation est masquée.

## Les boutons sur la droite

- **L'icône ?** (un point d'interrogation dans un cercle) : de l'aide pour l'écran où vous vous trouvez. Elle ouvre un court volet expliquant à quoi sert cet écran, puis **Lire la page du guide**, **Rechercher dans le guide** et **Refaire la visite**. Elle figure sur chaque onglet, pour les membres comme pour les invités. Dans l'application web, elle se trouve entre votre photo et les Paramètres en haut, et à côté des Paramètres en bas de la barre latérale sur grand écran.
- **L'icône d'invitation** (une silhouette avec un plus) : ouvre **Invitations**, pour inviter quelqu'un ou rejoindre une autre communauté. Voir « Rejoindre BeanPool ».
- **Réglages** (les curseurs) : ouvre les **Réglages**. Touchez à nouveau pour revenir là où vous étiez.
- **Votre photo :** ouvre votre propre profil, tel que les autres le voient.

## Messages de mise à jour

Parfois, un bandeau vert apparaît sous la barre du haut :

- **Mise à jour disponible :** une version plus récente de l'application est sortie. Touchez **Mettre à niveau** pour l'obtenir, ou la croix pour fermer le message.
- **Votre application est trop ancienne pour cette communauté :** vous devez effectuer une mise à jour pour que l'application fonctionne correctement ici. Celui-ci ne peut pas être fermé. Touchez **Mettre à niveau**.

## Les onglets

Sous la barre du haut se trouvent les onglets : **Accueil**, **Marché**, **Carte**, **Échanges**, **Communs** et **Registre**. Le nom de chaque onglet se trouve au-dessus de son icône. Sur le téléphone, une communauté locale sans haricots n'affiche ni les **Communs** ni le **Registre**. La communauté globale affiche les deux, avec des exemples issus d'une communauté locale. Voir « Haricots et communauté globale ».

Sur une longue page, touchez l'onglet sur lequel vous vous trouvez déjà pour remonter directement tout en haut. Cela fonctionne sur tous les onglets sauf **Carte**.
