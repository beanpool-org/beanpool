## Para kanino ito

Para lamang sa **mga may-ari** ng isang komunidad. Kung hindi ka may-ari, wala kang makikitang anuman dito.

## Bakit tinatanong ang mga may-ari

Nagtatago ang server ng iyong komunidad ng naka-lock na kopya ng mga susi nito, para sa paglipat ng komunidad sa ibang server kung mawala ang sarili nito, at naka-lock din ang mga backup nito. Naka-lock ang mga ito sa mga account ng mga may-ari: kayang buksan ng sinumang may-ari ang mga ito gamit ang kanilang telepono (tingnan ang Pamamahala o pagbabalik gamit ang iyong telepono, sa ibaba). Kung maiwala mo ang iyong telepono, ibinabalik ng iyong 12 salita ang iyong account, at kasama nito ang iyong susi sa lock ng server at sa mga backup nito. Pinakamahalaga iyon sa araw na mawala ang mismong server.

Kaya humihiling ang app sa bawat may-ari, paminsan-minsan, na suriin kung nasa kanila pa rin ang mga tamang 12 salita. Maaari mong piliin ang **Mamaya**. Walang anumang bina-block kailanman, at maaari mong ipagpatuloy ang paggawa ng lahat ng ginagawa ng isang may-ari.

## Kailan nagtatanong ang app

- Minsan, ilang sandali pagkatapos mong maging may-ari.
- Muli pagkalipas ng 12 buwan mula sa huling pagsusuri mo.

Nagpapakita ito ng card sa itaas ng Merkado (sa web app, sa itaas ng bawat screen maliban sa Mapa): **Suriin ngayon** o **Mamaya**. Itinatabi ng **Mamaya** ang card hanggang sa susunod na takdang oras. Maaari kang magsuri anumang oras mula sa **Mga Setting**: sa ilalim ng **Mga susi ng komunidad**, i-tap ang **Suriin ang iyong 12 salita** (sa web app, **Suriin ngayon**).

## Paano magsuri

- Kunin ang iyong papel na may 12 salita (mga salitang Ingles ang mga ito).
- I-type ang mga ito nang sunod-sunod, na may mga espasyo sa pagitan ng mga ito. Hindi mahalaga ang malalaking titik at sobrang mga espasyo.
- I-tap ang **Suriin ang aking mga salita**.

Kung tama ang mga ito, sinasabi ng app na **Ito ang mga tamang salita.** Kung hindi: **Hindi ito ang mga salita para sa account na ito.** Hindi nito sinasabi kung aling salita ang mali, kaya tingnan ang papel at i-type muli ang lahat ng ito.

Sa isang teleponong walang kopya ng iyong 12 salita (isang naibalik gamit ang sign-in account), nagdadala rin ang mga tamang salita ng **I-save ang mga ito sa teleponong ito**. I-tap ito at ipinapakita na ng **Tingnan ang Parirala sa Pagbawi** ang mga ito mula noon. Ito ay parehong pagsusuri at parehong pag-save gaya ng **Idagdag ang iyong 12 salita sa teleponong ito** (tingnan ang "Iyong 12 salita").

Hindi mahanap ang mga ito? Kung nasa teleponong ito pa rin ang mga ito, ipinapakita ang mga ito ng **Mga Setting**, pagkatapos ay **Tingnan ang Parirala sa Pagbawi**. Isulat muli ang mga ito, pagkatapos ay suriin. Sa isang teleponong walang kopya, sinasabi ito ng app: kapag nahanap mo ang mga ito, suriin ang mga ito rito, pagkatapos ay i-save ang mga ito.

## Kung ano ang ipinapadala, at kung ano ang hindi

- Nangyayari ang pagsusuri sa iyong telepono (o sa iyong browser, sa web app). Hindi kailanman ipinapadala saanman ang iyong mga salita. Binabakante ang kahon sa sandaling sumagot ang pagsusuri, at kapag umalis ka sa screen. Naka-save lamang ang mga ito kung ita-tap mo ang **I-save ang mga ito sa teleponong ito**, at doon lamang sa teleponong ito.
- Kapag tama ang mga salita, sinasabi lamang ng iyong telepono sa server ng iyong komunidad na nagsuri ka, at kung kailan, na nilagdaan gamit ang iyong account.
- Nakikita ng mga may-ari at admin, sa Mga Setting ng server, ang petsa ng "12 salita na sinuri" ng bawat may-ari, o "hindi pa". Ito ay sarili mong pahayag: hindi makikita o masusuri ng server ang iyong mga salita.

## Pamamahala o pagbabalik gamit ang iyong telepono

Kung mawala ang server ng iyong komunidad, sinumang nagpapatakbo ng standby server nito (o isang bagong server na nagbabalik ng backup) ay maaaring humiling sa isang may-ari na buksan ang mga naka-lock na susi. Sapat na ang sinumang isang may-ari. Kailangan mo ang pinakabagong bersyon ng BeanPool app. Gumagana rin ang web app kung bumubukas pa ito, ngunit nakatira ito sa sariling address ng iyong komunidad, na maaaring bumagsak kasama ng server: ang app sa telepono ang dapat asahan.

- Sa Mga Setting ng server, pipiliin nila ang **Take over as the main server**, pagkatapos ay **I understand: use an owner's phone**, o **Open with an owner's phone** kapag nagbabalik ng backup. May lilitaw na code sa kanilang screen.
- Sa app: **Mga Setting**, sa ilalim ng **Mga susi ng komunidad**, i-tap ang **Pamahalaan o ibalik gamit ang teleponong ito**, at itapat ang camera sa code. Kung nakabukas ang pahina ng server sa iyong sariling telepono, pareho rin ang ginagawa ng pag-tap sa link nito. Sa web app, kopyahin ang link mula sa kanilang screen at i-paste ito sa ilalim ng **Kunin ang pamamahala o i-restore gamit ang browser na ito** sa **Mga Setting**.
- Ipinapakita ng app kung aling komunidad, aling server, at kung ano ang mangyayari. Kung sumasagot pa rin ang iyong pangunahing server, sinasabi nito nang kulay pula: ang pamamahala ay para lamang sa server na talagang nawala na.
- I-tap ang **I-unlock para sa take-over** (o **I-unlock ang backup**). Hihilingin muna ng iyong telepono ang sarili nitong pag-unlock: fingerprint, mukha, o PIN. Walang ganoong hakbang ang web app, kaya naman ang app sa telepono ang mas ligtas na lugar para sa susi ng isang may-ari.
- Binubuksan ng iyong telepono ang sarili nitong bahagi ng lock at ipinapasa ang susi sa server na iyon, na naka-lock upang ang server lamang na iyon ang makakabasa nito. Hindi kailanman nakikita ng iyong telepono ang mga susi ng server o ang backup.
- Sa isang pamamahala (take-over), kukumpirmahin ng tao sa server ang nasa kanyang screen. Sasabihin sa komunidad na lumipat ito, at binuksan mo ang mga susi.

Tumatanggi ang app, at sinasabi kung bakit, kung ang lock ay pag-aari ng ibang komunidad, kung hindi ito naka-lock sa iyo, kung nag-expire na ang code ng server (tumatagal ito ng 10 minuto at gumagana nang isang beses), o kung ang mga susi ay hindi na-lock ng sariling server ng iyong komunidad.

## Sinusuri ng iyong telepono ang lock nang kusa

Sa bawat oras na nagbabago ang lock ng iyong komunidad (may idinagdag o inalis na may-ari, may ginawang bagong recovery code), tahimik na sinusuri ng iyong app na kaya pa rin nitong buksan ang bahagi nito. Binubuksan nito ito, agad na itinatapon ang susi, at sinasabi sa server kung gumana ito. Walang hinihiling mula sa iyo.

Nakikita ito ng mga may-ari at admin sa Mga Setting ng server, katabi ng petsa ng iyong 12 salita: **binuksan ng kanilang telepono ang kasalukuyang lock**, kasama ang petsa, o na huling binuksan nito ang mas luma. Kung sinasabi nitong ang iyong telepono ay **HINDI mabuksan** ang lock, suriin ang iyong 12 salita, at hilingin sa isa pang may-ari na tingnan ang Mga Setting ng server.
