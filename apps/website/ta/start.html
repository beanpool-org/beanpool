ஒரு சமூகத்தைத் தொடங்குங்கள்

ஒவ்வொரு சமூகமும் தனது சொந்த சர்வரில் இயங்குகிறது: இது அந்தச் சமூகத்தின் உறுப்பினர்கள், பதிவுகள் மற்றும் பேரேடு ஆகியவற்றை வைத்திருக்கும் ஒரு சிறிய சர்வர் ஆகும். உள்ளூர் நபர் ஒருவர் அதை இயக்குகிறார். உங்கள் நகரத்தில் அல்லது பள்ளத்தாக்கில் இன்னும் ஒன்று இல்லையென்றால், அது நீங்களாக இருக்கலாம்.

ஒரு சமூகத்தை நடத்துவதில் என்னென்ன உள்ளன

நீங்கள் ஒரு செய்முறையைப் பின்பற்ற முடிந்தால், சுமார் அரை மணி நேரம் ஆகும். முதலில் தெரிந்து கொள்ள வேண்டிய ஆறு விஷயங்கள்:

  • செலவு என்ன. மென்பொருள் இலவசமானது. இது வீட்டில் எப்போதும் இயங்கிக்கொண்டிருக்கும் ஒரு கூடுதல் கணினியிலோ (மினி பிசி, NAS அல்லது 64-பிட் அமைப்பு கொண்ட Raspberry Pi), அல்லது மாதத்திற்கு சில டாலர்கள் செலவாகும் ஒரு சிறிய வாடகை சர்வரிலோ (சுமார் US$6) இயங்குகிறது.
  • யார் ஹோஸ்ட் செய்கிறார்கள். நீங்களே, உங்கள் சொந்தக் கணினியில் அல்லது நீங்கள் வாடகைக்கு எடுத்த கணினியில் ஹோஸ்ட் செய்கிறீர்கள். அதற்கு ஒருபோதும் beanpool.org தேவையில்லை: உங்கள் சொந்த இணைய முகவரியே செயல்படும்.
  • நீங்கள் ஏற்கும் பொறுப்பு. உங்கள் உறுப்பினர்களிடமிருந்து வரும் புகார்கள் உங்களுக்கே வரும். மீட்புக் குறியீட்டுடன் தரவுக் கோப்புறையைக் காப்புப் பிரதி எடுப்பது உங்கள் பொறுப்பு. இரண்டு உரிமையாளர்களை வைத்திருங்கள். சர்வரைத் தொடர்ந்து இயங்க வைக்கவும், புதுப்பித்த நிலையிலும் வைத்திருக்கவும்.
  • நீங்கள் ஒருபோதும் பார்க்க முடியாதவை. உங்கள் உறுப்பினர்களின் நேரடிச் செய்திகள்.
  • முதலில் Docker. கீழே உள்ள கட்டளைத் தொகுதிக்கு முன் கணினியில் Docker நிறுவப்பட்டிருக்க வேண்டும்; புதிதாக வாடகைக்கு எடுக்கப்பட்ட சர்வரில் அது இருக்காது.
  • போன்கள் அணுகக்கூடிய ஒரு முகவரி. இணையத்தில் உள்ள ஒரு சமூகத்தை போன்கள் https வழியாக மட்டுமே சென்றடையும். பொது IP முகவரியுடன் 80 மற்றும் 443 ஆகிய போர்ட்கள் திறக்கப்பட்ட ஒரு வாடகை சர்வரில், அந்த IP முகவரியே போதுமானது: Cloudflare கணக்கு இல்லாமலேயே உங்கள் சர்வர் அதற்கான சொந்தச் சான்றிதழைப் பெறுகிறது, உங்கள் சொந்த டொமைனுக்கும் இது பொருந்தும். வீட்டில், அல்லது திறந்த போர்ட்கள் இல்லாத இடங்களில், உங்கள் சர்வர் தானாகவே இயக்கும் ஒரு டனல் வழியாக .beanpool.org என்று முடியும் இலவசப் பெயரை உரிமை கோரல் உங்களுக்கு வழங்குகிறது. சாதாரண http:// முகவரி வீட்டு நெட்வொர்க்கில் மட்டுமே செயல்படும்.

நீங்கள் எவற்றைக் கவனித்துக் கொள்கிறீர்கள்

நீங்களும் நீங்கள் நியமிக்கும் நிர்வாகிகளும் உங்கள் சமூகத்தின் நடுவர்கள்: புகார்கள் உங்களுக்கு வரும். உங்கள் உறுப்பினர்களின் தரவு உங்கள் கணினியில் உள்ளது, எனவே அதை நீங்கள் காப்புப் பிரதி எடுக்க வேண்டும். நீங்கள் கூட்டு முயற்சி விவாதங்கள் மற்றும் நிகழ்வு அரட்டைகளைப் படிக்கலாம்; நேரடிச் செய்திகளைப் படிக்க முடியாது. நீங்கள் முதல் உறுப்பினர்களை அழைக்கிறீர்கள், அவர்கள் மற்றவர்களை அழைக்கிறார்கள்.

அமைப்புகள் செயலி

உங்கள் சர்வர் உலாவியில் அதற்கென சொந்த அமைப்புகள் செயலியுடன் வருகிறது. அதிலிருந்து நீங்கள் உங்கள் சமூகத்திற்குப் பெயரிடலாம், தங்களின் சொந்த சாவிகளுடன் உள்நுழையும் ஓர் உரிமையாளர் மற்றும் நிர்வாகிகளை நியமிக்கலாம், QR அழைப்புகளை அச்சிடலாம், வட்டு ஆரோக்கியத்தைக் கண்காணிக்கலாம், பொது இணைய முகவரி அல்லது டனலைத் தேர்ந்தெடுக்கலாம், மேலும் தங்கள் தொலைபேசி மற்றும் 12 சொற்கள் இரண்டையும் இழந்த ஓர் உறுப்பினர் நேரில் உறுதிசெய்யும் ஒருமுறை குறியீட்டுடன் புதிய போனில் அவர்களின் சொந்தக் கணக்கிற்குத் திரும்ப உதவலாம்.

ஒரு சமூகத்தின் பதிவுகள், வரைபடம், செய்திகள் மற்றும் இருப்புகள் அதன் சர்வர் தொடங்கும் தருணத்திலிருந்தே அதன் உறுப்பினர்களுக்கானவை; இயக்க வேண்டியது எதுவும் இல்லை. கணக்கு இல்லாமல் அதன் முகவரியைத் திறப்பவர் உலகளாவிய சமூகத்திற்கு வழிகாட்டப்படுவார், அங்கு அவர்கள் தங்களுக்கு அருகில் என்ன இருக்கிறது என்பதைப் பார்த்து சேரக் கோரலாம்.

BeanPool திட்டத்தின் முகவரி சேவை முடங்கியிருந்தாலும், உரிமை கோரல் தொடர்ந்து செயல்படும்.

நிறுவுங்கள்

பிறகு, Docker நிறுவப்பட்ட அந்தக் கணினியில், இந்தக் கட்டளைத் தொகுதியை ஒட்டவும். இது compose கோப்பைப் பெறுகிறது, சர்வர் பயன்படுத்தும் நெட்வொர்க்கை உருவாக்குகிறது, வெளியிடப்பட்ட படத்தை (Intel/AMD அல்லது ARM64) இழுக்கிறது, அதைத் தொடங்குகிறது, சர்வர் தனது ஒருமுறை உரிமை கோரல் குறியீட்டை உருவாக்கும் வரை காத்திருக்கிறது (Raspberry Pi-ல் மெதுவான முதல் தொடக்கத்திற்கு ஐந்து நிமிடங்கள் வரை), மேலும் அதற்கு உரிமை கோருகிறது. அது தொடங்குவதற்கு முன் உள்ளமைக்க வேண்டியது எதுவுமில்லை.

bash — ஒரு சமூகத்தைத் தொடங்குங்கள்
ஒரே தொகுதி: பெறுதல், நெட்வொர்க், இழுத்தல், தொடங்குதல், காத்திருப்பு, உரிமை கோருதல் git clone https://github.com/beanpool-org/beanpool.git && cd beanpool docker network create beanpool-shared docker compose pull docker compose up -d echo "Waiting for the server to make its claim code (up to 5 minutes)..." for i in $(seq 60); do docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null && break; sleep 5; done docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null || echo "No claim code after 5 minutes. The server's log says why: docker compose logs beanpool-node" docker compose exec beanpool-node beanpool claim

கடைசி வரி: beanpool claim

  1. குறியீடும் QR-உம். இது ஒருமுறை உரிமை கோரல் குறியீட்டையும் ஒரு QR குறியீட்டையும் காட்டுகிறது. உங்கள் போனின் கேமரா மூலம் QR குறியீட்டை ஸ்கேன் செய்யவும், அல்லது BeanPool-ஐத் திறந்து, உங்கள் சமூகத்தைக் கண்டறியவும் என்பதன் கீழ் சர்வரின் முகவரியைத் தட்டச்சு செய்து உரிமை கோருங்கள் என்பதைத் தட்டவும். அந்தப் போன் உரிமையாளராக மாறும்.
  2. அமைப்புகள். உங்கள் முகவரியைத் (அல்லது சர்வரின் சொந்த முகவரி) தொடர்ந்து /settings என்பதைத் திறக்கவும். அமைவு வழிகாட்டி உங்கள் சமூகத்திற்குப் பெயரிடுகிறது, இரண்டாவது உரிமையாளரைச் சேர்க்கும்படி கேட்கிறது மற்றும் மூன்று தொடக்க அழைப்புகளை உருவாக்குகிறது. அருகிலுள்ளவர்கள் உங்களைக் கண்டறியும் வகையில் முனை அடையாளத்தின் (Node Identity) கீழ் வரைபடத்தில் உங்கள் இடத்தை அமைக்கவும்.

தொகுதியில் 5 நிமிடங்களுக்குப் பிறகு உரிமை கோரல் குறியீடு இல்லை என்று கூறினால், அல்லது beanpool claim இந்தச் சமூகத்திற்கு உரிமை கோரல் குறியீடு எதுவும் காத்திருக்கவில்லை என்று கூறினால், சர்வர் இன்னும் தொடங்கி முடியவில்லை: docker compose logs beanpool-node அது எங்குள்ளது என்பதைக் காட்டுகிறது. சமூகம் இன்னும் உரிமையாளர் இல்லை மற்றும் உரிமை கோரல் குறியீட்டைக் கொண்டுள்ளது என்று பதிவு கூறியவுடன், கடைசி வரியை மீண்டும் இயக்கவும். முழுமையான படிகள் ஆபரேட்டர் கையேட்டின் முதல் முறை அமைப்பில் உள்ளன.

பரிந்துரைக்கப்படுகிறது: Docker புதுப்பிக்கப்படும்போதும் உங்கள் சமூகத்தை இயங்க வைத்திருங்கள்

இந்தப் படி ஆபரேட்டர் கையேட்டின் "Updates and health" பக்கத்தில் உள்ளது. நிறுவலைச் செய்யும் AI உதவியாளர் இந்தப் படியை எப்போதும் செய்வார் (AI உதவியாளருடன் உங்கள் சர்வரை அமைத்தல்).
