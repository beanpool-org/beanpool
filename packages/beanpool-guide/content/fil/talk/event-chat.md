## Sino ang kasama rito

Bawat kaganapan ay may sarili nitong chat. Mababasa at makakasulat dito ang host at ang bawat nag-tap ng **Pupunta**. Kung saan nagpapasok ang host ng mga tao, ito ang mga taong pupunta na pinapasok ng host: hanggang noon ay sinasabi ng chat na **Magbubukas ang chat kapag pinapasok ka ng host.** Kung magpalit ka sa **Interesado**, o i-tap ang **Pupunta** muli upang alisin ito, aalis ka sa chat. Palaging kasama ang host dito.

## Pagbubukas nito

- Buksan ang kaganapan at i-tap ang **Buksan ang event chat**.
- O hanapin ito sa **Usapan**, sa ilalim ng **Mga Grupo**, na minarkahang 📅 **Kaganapan**. Sa web app ito ay nasa tab na **Chat**, kasama ng iba mo pang mga chat.

Sa itaas, nagpapakita ang isang naka-pin na kahon ng **Paalala para sa mga pupunta** ng host, tulad ng eksaktong address. I-tap ang pangalan ng kaganapan sa pinakataas (sa web app, **Tingnan ang event**) upang bumalik sa kaganapan.

## Pagsusulat

Mag-type sa **Magpadala ng mensahe sa lahat ng pupunta…** at i-tap ang send button. Maaari kang magpadala ng hanggang 30 mensahe kada minuto. Ang pinakabagong mensahe ay nasa itaas lamang ng kahon ng mensahe at nananatili roon kapag bumukas ang keyboard.

## Mabuting malaman

- Ang mga event chat ay hindi naka-encrypt nang end-to-end. Mababasa ang mga ito ng host, ng bawat pupunta (kung saan nagpapasok ang host ng mga tao, ang mga pinapasok ng host), at ng mga taong nagpapatakbo ng server ng iyong komunidad. Sinasabi ito ng chat sa itaas ng kahon ng mensahe.
- Maaaring alisin ng host ang anumang mensahe. I-tap ito, pagkatapos ay **Alisin**. Sinasabi nito pagkatapos na "inalis ng host".
- Ang event chat ay walang tugon (reply), walang mga reaksyon, walang pag-edit, at walang pagbura ng iyong sariling mensahe — hindi katulad ng chat sa isang tao o chat ng isang grupo. Hilingin sa host na alisin ang isang bagay na pinagsisisihan mo. Kung buburahin mo ang iyong account, bawat mensaheng isinulat mo rito ay mababasang **Binura ang mensaheng ito**.
- Kapag natapos o nakansela ang kaganapan, magiging read-only ang chat. Ang chat ng isang umuulit na kaganapan ay nananatiling bukas sa pagitan ng mga petsa: hanggang sa huling petsa nito kung nagtakda ang host ng **HANGGANG**, at hanggang sa kanselahin ng host ang kaganapan kung hindi. Tatlumpung araw pagkatapos ng pagtatapos, mawawala na ito.
