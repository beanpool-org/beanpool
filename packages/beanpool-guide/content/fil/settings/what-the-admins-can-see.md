## Ang listahan ng mga pangalan

Ang mga admin ng ilang komunidad ay nagtatabi ng **listahan ng mga pangalan**: kung sino ang mga miyembro, ayon sa tunay na pangalan, kung paano nagtatago ng listahan ng kasapian ang isang komite ng LETS. Hindi lahat ng komunidad ay nagtatago nito. Tanungin ang iyong mga admin kung ang sa iyo ay nagtatago nito.

Ang isang entry ay naglalaman ng iyong pangalan at, kung minsan, isang maikling tala na isinusulat ng isang admin, tulad ng kung paano ka nakikilala ng komunidad. Wala nang iba pa: walang address, walang petsa ng kapanganakan, walang numero ng ID.

## Sino ang makakabasa nito

**Ang mga may-ari at admin lamang ng iyong komunidad, sa kanilang sariling mga telepono.** Ang iyong pangalan ay tinatatakan sa telepono ng isang admin bago ito ipadala sa server ng iyong komunidad. Nagtatago ang server ng scrambled na teksto: ang isang backup, isang kopya, BeanPool, o sinumang magnakaw ng database ay walang hawak na anumang mababasa.

Sinumang nagpapatakbo ng server ay hindi makakabasa nito. Ibinibigay lamang ng mga telepono ng mga admin ang mga susi ng listahan sa mga admin na ang mga telepono ay nasuri ng isa pang admin, sa isang tawag o nang personal, at tumatanggap lamang ng mga bagong susi mula sa kanila. Nakasalalay iyon sa mga admin: ang isang admin na sumuri sa telepono ng maling tao, ang telepono ng isang admin na napasok ng ibang tao, o isang nawalang telepono bago alisin ng mga admin ang susi nito, ay maaaring magpahintulot sa ibang tao na basahin ang mga pangalan. Gayundin ang telepono ng isang admin na pinipigilan ng sinumang nagpapatakbo ng server na malaman na inalis na ang isang admin: hanggang sa malaman nito, ang isinusulat nito ay mababasa gamit ang mga susing mayroon ang inalis na admin. Ang isang admin na ang telepono ay nagpapakita pa rin ng inalis na admin ay manu-manong nag-aalis ng kanilang susi, at ang teleponong iyon ay gagawa ng bagong susi nang wala sila o walang isusulat.

**Hindi nakikita ng ibang mga miyembro ang mga pangalan.** Nakikita nila ang iyong pangalan sa BeanPool, tulad ng dati.

Maaaring gumawa ang isang admin ng PDF na kopya ng listahan sa kanilang telepono, para sa ligtas na pagtatago. Kapag nagawa na, nasa kanila na ang pananagutan na panatilihin itong ligtas, tulad ng isang listahang papel. Sa bawat oras na buksan o kopyahin ang listahan, makikita ng ibang mga admin kung sino ang gumawa nito at kung kailan.

## Pagiging kumpirmado

Maaari kang **kumpirmahin** ng isang admin: sinasabi nila na ang iyong account ay ang tao sa iyong entry. Ang isang taong nakakakilala lamang sa iyo ang dapat gumawa niyon, at sa ilang komunidad ay dapat magkasundo ang dalawang admin.

- Ang isang kumpirmasyon ay walang dalang pangalan. Itinatala ng server kung aling account, aling entry, at aling admin, hindi kailanman kung sino ka.
- Hindi ito isang trust badge. Nagbibigay din ito sa iyo ng credit line kaagad, ang kilalang floor, maliban kung ini-off ito ng may-ari ng komunidad mo: tingnan ang "Iyong credit line".
- Kung inimbita ka ng isang admin ayon sa pangalan, ang pagsali gamit ang kanilang imbitasyon ay nagkumpirma sa iyo laban sa iyong entry, ng admin na iyon. Ang ibig sabihin ng "Kumpirmado" ay sinasabi lamang ng isang admin na ang account na ito ay ang tao sa entry na iyon.
- Kung papalitan mo ang isang nawalang telepono at lumipat ang iyong account sa isang bagong susi, lilipat din ang iyong kumpirmasyon kasama nito.
- Kung aalis ka o buburahin mo ang iyong account, magtatapos ang iyong kumpirmasyon. Mananatili ang iyong entry sa listahan ng mga admin hanggang sa burahin ito ng isang admin: hilingin sa kanila na gawin ito.
- Kung ikaw ay kumpirmado at umalis ka, inalis ka, o binura mo ang iyong account habang may utang kang Munggo, sasagutin ng Komun ang utang tulad ng dati. Ang listahan ng mga admin ay nagtatabi rin ng tala sa iyong entry kung ano ang iyong utang, bakit at kailan, sa loob ng 3 taon, at nakikita ito ng mga admin sa tabi ng iyong pangalan sa kanilang mga telepono. Walang sinuman ang maaaring makumpirma laban sa entry na iyon hanggang sa ito ay mabayaran muli, mapagtrabahuhan, o mapatawad.

## Kung ano ang hindi ipinapakita ng listahan ng mga pangalan sa mga admin

Nagtataglay ang listahan ng mga pangalan at tala, at kung aling account ang para kanino. Bukod sa tala, sa itaas, ng isang utang na iniwan mong hindi nabayaran, hindi nito ipinapakita sa sinuman ang iyong balanse o ang iyong mga kalakalan (makikita ng isang admin ang iyong balanse sa mga kaso sa ibaba, at ang ilan sa iyong mga kalakalan: tingnan ang dulo ng pahinang ito). Tingnan ang "Iyong privacy" para sa kung ano ang makikita ng mga miyembro at admin sa ibang pagkakataon.

## Kung ano ang sinasang-ayunan mo sa isang kilalang komunidad

Ang isang komunidad na nagpapatunay sa mga miyembro nito, isang **kilalang komunidad**, ay gumagana tulad ng dati nang pamamaraan ng isang LETS: binabantayan ng mga admin ang mga utang na lumalaki nang sobra o nananatili nang napakatagal. Kapag sumali ka sa isa, sinasabi ng screen ng pagsali nang eksakto kung kailan, sa mga numero ng iyong komunidad, halimbawa:

"Sa komunidad na ito, makikita ng mga admin ang iyong balanse kung lumampas ito sa 50% ng iyong linya ng kredito o kung mananatili kang may utang sa loob ng 60 araw nang walang benta. Ganoon palagi gumana ang isang LETS. Bawat oras na buksan ng isang admin ang listahan ng mga miyembrong lumampas sa mga linyang iyon, at bawat oras na tingnan ng isang admin ang iyong balanse habang inaalis ka, ito ay naka-log. Sa isang boto sa pag-alis sa iyo, makikita ng bawat makakaboto rito ang iyong balanse at anumang utang, sa botong iyon lamang, at ang mga pagtinging iyon ay hindi naka-log. Maaari mo itong bawiin anumang oras sa Mga Setting. Anuman ang iyong piliin, makikita ng sinumang admin ang ilan sa iyong mga kalakalan: isang kalakalan na hindi pa natatapos o inayos ng isang admin (kung kanino, ang listing, ang presyo, at ang iyong one-to-one chat sa kanila, na hindi nila mababasa kung ito ay pribado), upang maayos ang isang nakatenggang kalakalan; isang kalakalan na ang mga Munggo ay naiwang nakatengga noong inalis ang isang miyembro sa mas lumang server (ang status ng kalakalan, ang listing, ang presyo, ang mga petsa nito, ang mga Munggong naiwang nakatengga, gaano karaming kabayaran ang dumaan dito, at ang halaga at tala ng huli); isang alerto sa pandaraya na nagpapangalan sa iyo kung ikaw at ang isang miyembro ay bumibili sa isa't isa nang pabalik-balik, halos magkapantay, lampas sa isang limitasyon, kasama ang kabuuang Munggo at kung gaano kapantay ang napunta sa bawat panig; isa na nagpapangalan sa iyo, kasama ang kabuuang Munggo at kung ilan sa mga miyembrong inimbita mo ang nakipagkalakalan sa wala kundi ikaw lamang, kung ang mga miyembrong inimbita mo ay nagpadala sa iyo ng Munggo lampas sa limitasyon sa loob ng nakatakdang bilang ng mga araw, o kung isa ka sa mga miyembrong iyon; isa na nagpapangalan sa iyo, kasama kung gaano karami sa pakikipagkalakalan ng grupo ay sa isa't isa ngunit walang Munggo, kung ikaw ay nasa isang grupo ng mga miyembro, hindi bababa sa kalahati sa kanila ay bago, na halos sa isa't isa lamang nakikipagkalakalan; at isang alerto na nagpapangalan sa iyo kung walang Munggo na pumasok o lumabas sa iyong account sa loob ng nakatakdang bilang ng mga araw. Naka-log ang bawat pagtingin sa isa sa mga kalakalang iyon, kasama kung sino ang tumingin, kailan, at sa aling mga kalakalan; ang pagtingin sa mga alertong nagpapangalan sa iyo ay naka-log sa unang pagkakataon na buksan ng bawat admin ang mga ito, at muli sa unang pagtingin ng admin na iyon pagkalipas ng 24 oras, at ang mga pagtingin sa pagitan ay hindi nagdaragdag ng linya. Makikita ng may-ari at ng mga admin ang log na iyon. Ang mga istatistika ng miyembro na nakikita ng mga admin ay nagpapakita kung gaano karaming post ang mayroon ka at mga mensaheng naipadala mo, at sa mga kalakalan ay ang kabuuan lamang ng buong komunidad, hindi ang sa iyo. Nakikita ng bawat miyembro, kasama ang mga admin, ang iyong profile ng tiwala: gaano karami sa iyong mga kalakalan ang natapos at ilan ang nakansela, at ang bahaging natapos, gaano karaming kabayaran sa Munggo ang naipadala mo o natanggap mula sa mga miyembro kasama ang mga kalakalang natapos mo, kasama ang kung ilang magkakaibang miyembro ang binayaran mo, binayaran ka o kinalakal mo, gaano karaming kabayaran at kalakalan ang nagawa mo sa miyembrong tumitingin, at ang iyong Mga Puntos ng Tiwala. Hindi iyon naka-log, dahil makikita ito ng bawat miyembro. Wala nang iba pa sa iyong mga kalakalan. Sinumang nagpapatakbo ng server ng komunidad na ito ay hawak ang buong database nito, kasama ang iyong balanse at mga kalakalan, at ang mga backup, snapshot, at standby na kopya nito."

Ang pagsang-ayon doon ay ang iyong pahintulot. Pagkatapos, at habang kinumpirma ka lamang ng isang admin:

- Kung lumampas ang iyong balanse sa alinmang linya, lilitaw ang iyong account sa mga telepono ng mga admin kasama ang iyong balanse, upang ang isang admin na nakakakilala sa iyo ay makipag-usap sa iyo. Walang ibang ipinapakita ang listahang iyon tungkol sa iyo, at wala sa iyong mga kalakalan.
- Sa bawat oras na buksan ng isang admin ang listahang iyon, makikita ng ibang mga admin at ng may-ari kung sino ang nagbukas nito at kung kailan.
- Kung hindi ka sumang-ayon, o walang nagkumpirma sa iyo, o hindi nagkukumpirma ng mga miyembro ang iyong komunidad, hindi ka kailanman ipinapakita ng listahang iyon.

Kung sumali ka bago nagtanong ang iyong komunidad, iniaalok ito ng iyong app sa iyo. Ang pagsasabi ng hindi, o hindi pagsagot, ay walang binabago sa iba: miyembro ka pa rin. Kung babaguhin ng komunidad ang mga linya nito sa ibang pagkakataon, tatanungin ka muli ng iyong app.

Maaari mong bawiin ang iyong pahintulot anumang oras: buksan ang **Mga Setting**, kung saan ipinapakita ng iyong app kung ano ang sinang-ayunan mo at kailan, at i-tap ang **Bawiin**. Mula sa sandaling iyon ay wala ka na sa listahan. Nagtatago ang iyong komunidad ng tala na ikaw ay sumang-ayon at na ikaw ay nagbawi, at maaari kang sumang-ayon muli mamaya.

## Kailan nakikita ng isang admin ang iyong balanse kahit paano

Sumang-ayon ka man o hindi sa anuman, sa anumang komunidad:

- **Kapag inalis ng isang admin ang iyong account.** Ang admin na magsisimulang mag-alis sa iyo ay makikita ang iyong balanse at kung gaano karaming kalakalan ang bukas mo, upang maayos kung ano ang hawak mo o utang mo. Makikita ng ibang mga admin at ng may-ari kung sino ang tumingin, sa balanse ninuman, at kung kailan.
- **Kapag bumoto ang iyong komunidad sa pag-alis sa iyo.** Makikita ng bawat makakaboto rito ang iyong balanse at anumang utang, sa botong iyon lamang. Ang isang admin o may-ari na hindi makakaboto rito ay hindi makakakita sa mga ito roon. Ang mga pagtinging iyon ay hindi naka-log.
- **Sinumang nagpapatakbo ng server ng iyong komunidad** ay hawak ang buong database nito, kasama ang iyong balanse at mga kalakalan, at ang mga backup, snapshot, at standby na kopya nito.

## Kung ano ang makikita ng sinumang admin sa iyong mga kalakalan

Sumang-ayon ka man o hindi sa anuman, sa anumang komunidad, makikita ng sinumang admin ang:

- **Isang kalakalan na hindi pa natatapos, o inayos ng isang admin.** Ang dalawang miyembro, ang listing, ang presyo, at ang mga mensahe sa one-to-one chat ng dalawang miyembro. Hindi mababasa ng isang admin ang pribadong chat, makikita lamang kung sino ang sumulat at kailan. Ito ay upang maayos ng isang admin ang isang kalakalan na natetengga.
- **Isang kalakalan na ang mga Munggo ay naiwang nakatengga noong inalis ang isang miyembro sa mas lumang server.** Ang status ng kalakalan, ang listing, ang presyo, ang mga petsa nito, ang mga Munggong naiwang nakatengga, gaano karaming kabayaran ang dumaan dito, at ang halaga at tala ng huli, upang ma-write off ng may-ari ang mga nakatenggang Munggo.
- **Mga alerto sa pandaraya na nagpapangalan ng mga miyembro,** na may Munggo. Ang isa ay nagpapangalan ng dalawang miyembro na bumibili sa isa't isa nang pabalik-balik, halos magkapantay, lampas sa isang limitasyon. Ipinapakita nito ang kabuuang Munggo at kung gaano kapantay ang napunta sa bawat panig. Ang isa pa ay nagpapangalan ng isang miyembro at ng mga miyembrong kanilang inimbita, kapag ang mga miyembrong iyon ay nagpadala sa kanila ng Munggo lampas sa limitasyon sa loob ng nakatakdang bilang ng mga araw. Ipinapakita nito ang kabuuang Munggo at kung ilan sa mga miyembrong inimbita nila ang nakipagkalakalan sa wala kundi sila lamang.
- **Isang alerto sa pandaraya na nagpapangalan ng isang grupo ng mga miyembro,** hindi bababa sa kalahati sa kanila ay bago, na halos sa isa't isa lamang nakikipagkalakalan. Ipinapakita nito kung gaano karami sa pakikipagkalakalan ng grupo ay sa isa't isa, ngunit walang Munggo.
- **Isang alerto na nagpapangalan sa mga miyembrong walang Munggo na pumasok o lumabas** sa loob ng nakatakdang bilang ng mga araw.

**Naka-log ang bawat pagtingin sa isa sa mga kalakalang ito:** sino ang tumingin, kailan, at sa aling mga kalakalan. **Ang pagtingin sa mga alertong nagpapangalan sa isang miyembro ay naka-log** sa unang pagkakataon na buksan ng bawat admin ang mga ito, at muli sa unang pagtingin ng admin na iyon pagkalipas ng 24 oras; ang mga pagtingin sa pagitan ay hindi nagdaragdag ng linya. Makikita ng may-ari at ng mga admin ang log na iyon sa Kalusugan ng komunidad, bilang isang hiwalay na listahan katabi ng listahan ng kung sino ang tumingin sa balanse. Ang isang pagtingin na ginawa ng isang automation token (isang script na na-set up ng isang may-ari) ay nagsasabi nito: mababasa sa linya ang "by token" at ang pangalan ng token, katabi ng may-ari na gumawa nito.

Ang mga istatistika ng miyembro na nakikita ng mga admin ay nagpapakita kung gaano karaming post ang mayroon ang bawat miyembro at mga mensaheng naipadala nila, at sa mga kalakalan ay ang kabuuan lamang ng buong komunidad: gaano karaming kalakalan ang natapos o nakansela at kung magkano ang kinalabasan ng mga natapos, hindi kailanman ang sa isang miyembro.

Nakikita ng bawat miyembro, kasama ang mga admin, ang **profile ng tiwala** ng bawat miyembro: gaano karami sa kanilang mga kalakalan ang natapos at ilan ang nakansela, at ang bahaging natapos, gaano karaming kabayaran sa Munggo ang naipadala nila o natanggap mula sa mga miyembro kasama ang mga kalakalang natapos nila, kasama ang kung ilang magkakaibang miyembro ang binayaran nila, binayaran sila o kinalakal nila, gaano karaming kabayaran at kalakalan ang nagawa nila sa miyembrong tumitingin, at ang kanilang Mga Puntos ng Tiwala. Hindi ito naka-log, dahil makikita ito ng bawat miyembro.

Wala nang iba pa sa iyong mga kalakalan.

## AI assistant ng isang admin

Maaaring ikonekta ng isang may-ari o admin ang kanilang sariling AI assistant sa server upang tulungan sila. Mas kaunti ang nakikita nito kaysa sa kanila: hindi kailanman ang iyong mga mensahe, balanse, kalakalan, mga susi, mga larawan, o ang listahan ng mga pangalan, at hindi kailanman kung sino ang nag-ulat ng sinuman. Tingnan ang "Kapag gumagamit ang admin ng AI assistant".

## Pagtatanong tungkol sa iyong entry

Maaari mong tanungin ang iyong mga admin kung ano ang sinasabi ng iyong entry, upang itama ito, o burahin ito kapag hindi ka na kabilang sa komunidad. Sila ang nagtatabi ng listahan, hindi ang BeanPool.
