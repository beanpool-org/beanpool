## 핀

탭 행에서 **지도**를 탭하세요. 지도에 커뮤니티의 게시물이 표시돼요:

- **초록색 핀:** 제공.
- **주황색 핀:** 요청.
- **달력이 있는 보라색 핀:** 아직 종료되지 않은 행사.

핀에는 게시물의 카테고리 그림이 표시돼요. 여러 제공과 요청이 가까이 모여 있는 곳은 숫자가 적힌 원으로 합쳐져요. 원은 휴대폰에서는 파란색, 웹 앱에서는 짙은 회색이에요. 확대하면 하나씩 볼 수 있어요. 행사는 항상 개별적으로 표시돼요.

사람과 모임은 지도에 표시되지 않아요. 웹 앱에서는 장소를 설정한 기업이 해당 사진이 들어간 사각형 핀으로 표시돼요. 탭하면 기업이 열려요.

설문도 지도에 표시되지 않아요. 한 가지 예외로 휴대폰의 글로벌 커뮤니티에서는 설문 작성자의 지역에 설문이 핀으로 표시될 수 있어요. 주황색 요청 핀처럼 보이며, **전체** 아래에서만 보여요.

## 핀 탭하기

- **제공 또는 요청:** 카드에 제목과 등록한 사람이 표시돼요. 열어보려면 **상세 보기**를 탭하세요. 휴대폰에서는 상대방 이름을 탭하여 프로필을 볼 수 있어요. 지도를 탭하거나 **✕**를 누르면 카드가 닫혀요.
- **행사:** 카드에 일시, 장소, 참석자 수가 표시돼요. **이벤트 보기**를 탭하세요. 웹 앱에서는 버튼이 **상세 보기**로 되어 있으며, 카드에서 바로 **참석** 또는 **관심 있음**을 탭할 수도 있어요.

## 필터

휴대폰의 지도 상단에서:

- **전체**, **제공**, **요청**, 또는 **행사**. 지우려면 **✕**를 탭하세요.
- 하나의 카테고리만 보려면 **모든 카테고리**를 누르세요.
- 행사의 경우: **전체**, **오늘**, **이번 주말**, 또는 **앞으로 7일**. 지도 화면이 해당 행사에 맞게 이동해요.

웹 앱의 지도에는 행사 날짜 칩만 있어요: **오늘**, **이번 주말**, **앞으로 7일**, **모든 이벤트**예요. 커뮤니티에 다가오는 행사가 있을 때만 표시돼요.

## 왼쪽 버튼들

- 휴대폰에서는 달 또는 태양 아이콘: 다크 모드 또는 라이트 모드 지도.
- 과녁 모양 아이콘: 내 현재 위치 표시. 처음 사용할 때 앱에서 위치 정보 사용 권한을 요청해요.
- **+** 및 **−**: 확대/축소.

주황색 원은 커뮤니티가 서비스를 제공하는 지역 범위를 나타내요.

## 지도에서 게시물 추가하기

**+ 게시물 추가**를 탭하세요. 웹 앱에서는 오른쪽 하단의 둥근 **+**를 탭하세요. "제공 또는 요청 등록하기"를 참조하세요.
