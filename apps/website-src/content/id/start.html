Mulai sebuah komunitas

Setiap komunitas berjalan pada nodenya sendiri: server kecil yang menyimpan anggota, kiriman, dan buku kas komunitas tersebut. Dijalankan oleh warga lokal. Jika kota atau wilayah Anda belum memilikinya, Anda bisa menjadi orangnya.

Apa saja yang diperlukan untuk menjalankan sebuah komunitas

Sekitar setengah jam, jika Anda bisa mengikuti petunjuk. Enam hal yang perlu diketahui terlebih dahulu:

  • Biaya yang dibutuhkan. Perangkat lunaknya gratis. Aplikasi ini berjalan pada komputer cadangan yang terus menyala di rumah (Mini PC, NAS, atau Raspberry Pi dengan sistem 64-bit), atau pada server sewaan kecil dengan biaya beberapa dolar per bulan (sekitar US$6).
  • Siapa yang meng-hosting. Anda sendiri, di komputer Anda sendiri atau yang Anda sewa. Tidak memerlukan beanpool.org: alamat web Anda sendiri berfungsi.
  • Tanggung jawab Anda. Laporan dari anggota Anda masuk kepada Anda. Folder data adalah tanggung jawab Anda untuk dicadangkan, dengan kode pemulihan. Pertahankan dua pemilik. Biarkan server terus menyala dan diperbarui.
  • Yang tidak pernah Anda lihat. Pesan langsung anggota Anda.
  • Docker terlebih dahulu. Komputer tersebut harus sudah terpasang Docker sebelum menjalankan blok di bawah; server yang baru disewa belum memilikinya.
  • Alamat yang dapat dijangkau ponsel. Ponsel hanya dapat menjangkau komunitas di internet melalui https. Pada server sewaan dengan alamat IP publik dan porta 80 serta 443 terbuka, alamat IP tersebut sudah cukup: server Anda mendapatkan sertifikatnya sendiri untuk alamat itu, tanpa akun Cloudflare, dan hal yang sama berlaku untuk domain milik Anda sendiri. Di rumah, atau tanpa porta yang terbuka, proses klaim memberi Anda nama gratis berakhiran .beanpool.org, melalui tunnel yang dijalankan sendiri oleh server Anda. Alamat http:// biasa hanya berfungsi di jaringan rumah.
🧰

Yang Anda kelola

Anda dan admin yang Anda tunjuk adalah moderator komunitas Anda: laporan masuk kepada Anda. Data anggota Anda berada di komputer Anda, jadi Anda yang menjaga cadangannya. Anda dapat membaca diskusi usaha dan obrolan acara; Anda tidak dapat membaca pesan langsung. Anda mengundang anggota pertama, dan mereka mengundang yang lain.

⚙️

Aplikasi pengaturan

Node Anda dilengkapi dengan aplikasi pengaturannya sendiri di peramban. Dari sana Anda memberi nama komunitas Anda, menunjuk pemilik dan admin yang masuk dengan kunci mereka sendiri, mencetak undangan QR, memantau kesehatan disk, memilih alamat web publik atau tunnel, dan membantu anggota yang kehilangan ponsel sekaligus 12 katanya kembali ke akun mereka sendiri di ponsel baru, dengan kode sekali pakai yang Anda konfirmasi langsung secara tatap muka.

🔒

Pribadi sejak pertama kali dinyalakan

Daftar penawaran, peta, pesan, dan saldo komunitas hanya untuk anggotanya sejak node dinyalakan; tidak ada yang perlu diaktifkan secara manual. Seseorang yang membuka alamatnya tanpa akun akan diarahkan ke komunitas global, tempat mereka dapat melihat apa yang ada di dekat mereka dan meminta untuk bergabung.

🌐

Menghubungkan dengan komunitas tetangga

Dua komunitas dapat sepakat untuk terhubung agar anggotanya dapat saling bertransaksi. Kacang tidak pernah keluar dari tempat asalnya: setiap pasangan mencatat saldo berjalan dari utang piutang antar-komunitas, dan masing-masing pihak menentukan batasnya sendiri. Hubungan ini nonaktif kecuali kedua operator menyalakannya, dan ini masih tahap awal: fitur ini sudah dibangun, dengan antarmukanya di aplikasi web, dan baru diuji coba di antara dua komunitas uji kami sendiri, belum pernah di antara komunitas yang berjalan langsung.

Alamat Anda

Pilih sebelum Anda menempelkan perintah, dan ubah baris terakhir agar sesuai. Jika Anda sudah menempelkannya, tekan Enter pada pertanyaannya, lalu jalankan baris terakhir lagi: kode klaim menunggu ponsel. Server sewaan dengan alamat IP publik dan porta 80 serta 443 terbuka: tambahkan --ip dan alamat IP-nya, seperti pada beanpool claim --ip 203.0.113.7. Server Anda mendapatkan sertifikatnya sendiri untuk alamat tersebut dari Let's Encrypt, melalui porta 80, dan ponsel menjangkaunya di https://203.0.113.7. Komputer di rumah, atau tanpa porta yang terbuka: biarkan apa adanya. Perintah ini akan meminta bagian pertama dari nama gratis (cukup ketik namakota untuk namakota.beanpool.org; Enter untuk melewati), yang dijangkau melalui tunnel yang dijalankan sendiri oleh server Anda, dan menunggu hingga tiga menit untuk aktif. Domain milik Anda sendiri: arahkan data DNS record A ke alamat IP server, buka porta 80 dan 443, serta tambahkan --address https://domain.anda. Sebuah nama tetap bertahan saat berganti server; sebuah angka tidak: Anda dapat menambahkan nama nanti di Pengaturan, dan anggota yang menggunakan alamat IP tetap dapat terhubung. Untuk memilih nanti di Pengaturan, tambahkan --no-name. Alamat http:// biasa hanya berfungsi di jaringan rumah: ponsel menolaknya di internet, dan proses klaim akan memperingatkan Anda. Jika layanan alamat proyek BeanPool sedang tidak aktif, klaim tetap berfungsi.

Pasang

Kemudian, pada komputer tersebut yang telah terpasang Docker, tempel satu blok ini. Perintah ini mengambil file compose, membuat jaringan yang digunakan node, menarik citra yang diterbitkan (Intel/AMD atau ARM64), memulainya, menunggu hingga server membuat kode klaim sekali pakai (hingga lima menit, untuk booting pertama yang lambat di Raspberry Pi), dan mengklaimnya. Tidak ada yang perlu dikonfigurasi sebelum dimulai.

bash — mulai komunitas
Satu blok: unduh, jaringan, tarik, mulai, tunggu, klaim git clone https://github.com/beanpool-org/beanpool.git && cd beanpool docker network create beanpool-shared docker compose pull docker compose up -d echo "Waiting for the server to make its claim code (up to 5 minutes)..." for i in $(seq 60); do docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null && break; sleep 5; done docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null || echo "No claim code after 5 minutes. The server's log says why: docker compose logs beanpool-node" docker compose exec beanpool-node beanpool claim

Baris terakhir: beanpool claim

  1. Kode dan QR. Perintah ini menampilkan kode klaim sekali pakai dan kode QR. Pindai kode QR dengan kamera ponsel Anda, atau buka BeanPool, ketik alamat server di bawah Temukan komunitas Anda dan ketuk Klaim. Ponsel tersebut menjadi pemilik.
  2. Pengaturan. Buka alamat Anda (atau alamat server itu sendiri) diikuti dengan /settings. Panduan penyiapan memberi nama komunitas Anda, meminta Anda menambahkan pemilik kedua, dan membuat tiga undangan awal. Tentukan tempat Anda di peta di bawah Identitas Node agar orang-orang di sekitar dapat menemukan Anda.

Jika blok perintah menyatakan No claim code after 5 minutes, atau beanpool claim menyatakan This community has no claim code waiting, server belum selesai memulai: docker compose logs beanpool-node menunjukkan statusnya. Setelah log menyatakan komunitas belum memiliki pemilik dan memiliki kode klaim, jalankan baris terakhir lagi. Langkah-langkah selengkapnya ada di penyiapan pertama kali pada panduan operator.

Disarankan: jaga komunitas Anda tetap berjalan saat Docker diperbarui
