ایک کمیونٹی شروع کریں

ہر کمیونٹی اپنے نوڈ پر چلتی ہے: ایک چھوٹا سرور جو اس کمیونٹی کے اراکین، پوسٹس اور لیجر کو رکھتا ہے۔ کوئی مقامی شخص اسے چلاتا ہے۔ اگر آپ کے قصبے یا وادی میں ابھی تک کوئی نہیں ہے، تو وہ آپ ہو سکتے ہیں۔

کمیونٹی چلانے میں کیا کچھ شامل ہے

تقریباً آدھا گھنٹہ، اگر آپ کسی ترکیب پر عمل کر سکتے ہوں۔ پہلے جاننے کے لیے چھ باتیں:

  • اس پر کتنا خرچ آتا ہے۔ سافٹ ویئر مفت ہے۔ یہ ایک فالتو کمپیوٹر پر چلتا ہے جو گھر پر چلتا رہے (ایک منی پی سی، NAS، یا 64-بٹ سسٹم والا Raspberry Pi)، یا چند ڈالرز ماہانہ (تقریباً US$6) کے کرائے کے چھوٹے سرور پر۔
  • اس کی میزبانی کون کرتا ہے۔ آپ خود، اپنی مشین پر یا کرائے پر لی گئی مشین پر۔ اسے کبھی beanpool.org کی ضرورت نہیں ہوتی: آپ کا اپنا ویب پتہ کام کرتا ہے۔
  • آپ کی ذمہ داری کیا ہے۔ آپ کے اراکین کی رپورٹس آپ کے پاس آتی ہیں۔ ریکوری کوڈ کے ساتھ ڈیٹا فولڈر کا بیک اپ لینا آپ کی ذمہ داری ہے۔ دو مالکان رکھیں۔ سرور کو آن اور اپ ڈیٹ رکھیں۔
  • آپ کبھی کیا نہیں دیکھتے۔ اپنے اراکین کے براہ راست پیغامات۔
  • پہلے Docker۔ نیچے دیے گئے بلاک سے پہلے مشین پر Docker انسٹال ہونا ضروری ہے؛ نئے کرائے پر لیے گئے سرور پر یہ نہیں ہوتا۔
  • ایک ایسا پتہ جس تک فون پہنچ سکیں۔ فون انٹرنیٹ پر کسی کمیونٹی تک صرف https کے ذریعے پہنچتے ہیں۔ عوامی IP ایڈریس اور پورٹس 80 اور 443 کھلے ہونے کے ساتھ کرائے کے سرور پر، وہ IP ایڈریس ہی کافی ہے: آپ کے سرور کو اس کے لیے اپنا سرٹیفکیٹ مل جاتا ہے، بغیر کسی Cloudflare اکاؤنٹ کے، اور آپ کے اپنے ڈومین کے لیے بھی ایسا ہی ہے۔ گھر پر، یا بغیر کھلی پورٹس کے، کلیم آپ کو ایک مفت نام دیتا ہے جو .beanpool.org پر ختم ہوتا ہے، ایک ٹنل کے ذریعے جسے آپ کا سرور خود چلاتا ہے۔ ایک سادہ http:// پتہ صرف گھریلو نیٹ ورک پر کام کرتا ہے۔
🧰

آپ کس چیز کی دیکھ بھال کرتے ہیں

آپ اور آپ کے مقرر کردہ ایڈمنز آپ کی کمیونٹی کے ماڈریٹرز ہیں: رپورٹس آپ کے پاس آتی ہیں۔ آپ کے اراکین کا ڈیٹا آپ کی مشین پر رہتا ہے، اس لیے آپ اس کا بیک اپ رکھتے ہیں۔ آپ انٹرپرائز کے مباحثے اور تقریبات کی چیٹس پڑھ سکتے ہیں؛ آپ براہ راست پیغامات نہیں پڑھ سکتے۔ آپ پہلے اراکین کو مدعو کرتے ہیں، اور وہ باقی لوگوں کو مدعو کرتے ہیں۔

⚙️

سیٹنگز ایپ

آپ کا نوڈ براؤزر میں اپنی سیٹنگز ایپ کے ساتھ آتا ہے۔ اس سے آپ اپنی کمیونٹی کا نام رکھتے ہیں، ایک مالک اور ایڈمنز مقرر کرتے ہیں جو اپنی کیز کے ساتھ سائن ان کرتے ہیں، QR دعوت نامے پرنٹ کرتے ہیں، ڈسک کی حالت دیکھتے ہیں، ایک پبلک ویب پتہ یا ٹنل منتخب کرتے ہیں، اور کسی ایسے رکن کی مدد کرتے ہیں جس کا فون اور 12 الفاظ دونوں گم ہو گئے ہوں تاکہ وہ نئے فون پر اپنے اکاؤنٹ میں واپس آ سکے، ایک وقتی کوڈ کے ساتھ جس کی آپ ذاتی طور پر تصدیق کرتے ہیں۔

🔒

پہلے بوٹ سے ہی نجی

کسی کمیونٹی کی فہرستیں، نقشہ، پیغامات اور بیلنس اس کے اراکین کے لیے ہوتے ہیں جیسے ہی اس کا نوڈ شروع ہوتا ہے؛ آن کرنے کے لیے کچھ بھی نہیں ہے۔ کوئی شخص جو اکاؤنٹ کے بغیر اس کا پتہ کھولتا ہے اسے عالمی کمیونٹی کی طرف بھیج دیا جاتا ہے، جہاں وہ دیکھ سکتے ہیں کہ ان کے آس پاس کیا ہے اور شامل ہونے کی درخواست کر سکتے ہیں۔

🌐

پڑوسی کمیونٹی کے ساتھ رابطہ

دو کمیونٹیز آپس میں جڑنے پر اتفاق کر سکتی ہیں تاکہ ان کے اراکین ایک دوسرے کے ساتھ تجارت کر سکیں۔ پھلیاں کبھی بھی اپنے ہوم سے باہر نہیں جاتیں: ہر جوڑا اس بات کا مسلسل حساب رکھتا ہے کہ ایک کمیونٹی پر دوسری کمیونٹی کا کتنا واجب الادا ہے، اور ہر طرف اپنی حد مقرر کرتی ہے۔ رابطہ اس وقت تک بند رہتا ہے جب تک کہ دونوں آپریٹرز اسے آن نہ کریں، اور یہ ابھی ابتدائی مراحل میں ہے: یہ ویب ایپ میں اپنی اسکرینوں کے ساتھ تیار ہے، اور اسے صرف ہماری اپنی دو آزمائشی کمیونٹیز کے درمیان آزمایا گیا ہے، کبھی فعال کمیونٹیز کے درمیان نہیں۔

آپ کا پتہ

پیسٹ کرنے سے پہلے اسے منتخب کریں، اور آخری لائن کو اس کے مطابق تبدیل کریں۔ اگر آپ پہلے ہی پیسٹ کر چکے ہیں، تو اس کے سوالات پر Enter دبائیں، پھر آخری لائن دوبارہ چلائیں: کلیم کوڈ فون کا انتظار کرتا ہے۔ کرائے کا سرور جس کا پبلک IP ایڈریس ہو اور پورٹس 80 اور 443 کھلی ہوں: --ip اور اس کا IP ایڈریس شامل کریں، جیسا کہ beanpool claim --ip 203.0.113.7 میں ہے۔ آپ کے سرور کو Let's Encrypt سے پورٹ 80 پر اس پتے کے لیے اپنا سرٹیفکیٹ ملتا ہے، اور فون https://203.0.113.7 پر اس تک پہنچتے ہیں۔ گھر پر کمپیوٹر، یا کوئی کھلی پورٹ نہیں: اسے ویسے ہی رہنے دیں۔ یہ ایک مفت نام کے پہلے حصے کے لیے پوچھتا ہے (yourtown.beanpool.org کے لیے صرف yourtown ٹائپ کریں؛ Enter چھوڑ دیتا ہے)، جس تک آپ کا سرور خود چلائی جانے والی ٹنل کے ذریعے پہنچتا ہے، اور اس کے فعال ہونے کے لیے تین منٹ تک انتظار کرتا ہے۔ آپ کا اپنا ڈومین: سرور کے IP ایڈریس پر اس کے لیے ایک A ریکارڈ کی نشاندہی کریں، پورٹس 80 اور 443 کھولیں، اور --address https://your.domain شامل کریں۔ نام سرور کی تبدیلی کے بعد بھی قائم رہتا ہے؛ نمبر قائم نہیں رہتا: آپ بعد میں سیٹنگز میں نام شامل کر سکتے ہیں، اور IP ایڈریس استعمال کرنے والے اراکین کا کام چلتا رہتا ہے۔ بعد میں سیٹنگز میں انتخاب کرنے کے لیے، --no-name شامل کریں۔ ایک سادہ http:// پتہ صرف گھریلو نیٹ ورک پر کام کرتا ہے: فون انٹرنیٹ پر اس سے انکار کرتے ہیں، اور کلیم آپ کو متنبہ کرتا ہے۔ اگر BeanPool پروجیکٹ کی ایڈریس سروس ڈاؤن ہو، تب بھی کلیم کام کرتا ہے۔

انسٹال کریں

پھر، Docker انسٹال ہونے والی اس مشین پر، یہ ایک بلاک پیسٹ کریں۔ یہ کمپوز فائل لاتا ہے، وہ نیٹ ورک بناتا ہے جو نوڈ استعمال کرتا ہے، شائع شدہ امیج (Intel/AMD یا ARM64) ڈاؤن لوڈ کرتا ہے، اسے شروع کرتا ہے، اس وقت تک انتظار کرتا ہے جب تک سرور اپنا یک وقتی کلیم کوڈ تیار نہ کر لے (Raspberry Pi پر سست پہلی شروعات کے لیے پانچ منٹ تک)، اور اس کا کلیم کرتا ہے۔ شروع ہونے سے پہلے کنفیگر کرنے کے لیے کچھ بھی نہیں ہے۔

bash — ایک کمیونٹی شروع کریں
ایک بلاک: ڈاؤن لوڈ، نیٹ ورک، پل، شروع، انتظار، کلیم git clone https://github.com/beanpool-org/beanpool.git && cd beanpool docker network create beanpool-shared docker compose pull docker compose up -d echo "Waiting for the server to make its claim code (up to 5 minutes)..." for i in $(seq 60); do docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null && break; sleep 5; done docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null || echo "No claim code after 5 minutes. The server's log says why: docker compose logs beanpool-node" docker compose exec beanpool-node beanpool claim

آخری لائن: beanpool claim

  1. کوڈ اور QR۔ یہ ایک وقتی کلیم کوڈ اور ایک QR کوڈ دکھاتا ہے۔ اپنے فون کے کیمرے سے QR کوڈ اسکین کریں، یا BeanPool کھولیں، اپنی کمیونٹی تلاش کریں کے تحت سرور کا پتہ ٹائپ کریں اور کلیم کریں پر ٹیپ کریں۔ وہ فون مالک بن جاتا ہے۔
  2. سیٹنگز۔ اپنا پتہ (یا سرور کا اپنا پتہ) اور اس کے بعد /settings کھولیں۔ سیٹ اپ وزرڈ آپ کی کمیونٹی کا نام رکھتا ہے، آپ سے دوسرا مالک شامل کرنے کو کہتا ہے، اور تین بانی دعوت نامے بناتا ہے۔ نوڈ شناخت کے تحت نقشے پر اپنا مقام متعین کریں تاکہ آس پاس کے لوگ آپ کو تلاش کر سکیں۔

اگر بلاک No claim code after 5 minutes کہتا ہے، یا beanpool claim یہ کہتا ہے کہ This community has no claim code waiting، تو سرور نے شروع ہونا ختم نہیں کیا ہے: docker compose logs beanpool-node دکھاتا ہے کہ یہ کہاں تک پہنچا ہے۔ ایک بار جب لاگ بتائے کہ کمیونٹی کا ابھی تک کوئی مالک نہیں ہے اور اس کے پاس کلیم کوڈ موجود ہے، تو آخری لائن دوبارہ چلائیں۔ مکمل اقدامات آپریٹر مینوئل کے پہلی بار سیٹ اپ میں موجود ہیں۔
