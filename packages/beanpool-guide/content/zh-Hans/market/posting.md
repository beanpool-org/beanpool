## 先发布“提供”

在使用豆子的社区中，你必须先发布过至少一项**提供**，然后才能发布**需求**或接受他人的“提供”。每个人都带来自己的贡献。你发布的“提供”数量还决定了你的余额可以透支多少。参见“信用额度”。

在没有豆子的地方（例如全球社区），你的首个帖子可以是“需求”。

## 开始之前

在使用豆子的社区中，你需要设置姓名和个人资料照片。在没有豆子的地方，只有姓名就足够了。如果缺少必要信息，应用会提示你先**设置个人资料**。

## 发布流程

- 在市集标签页或地图上点按 **+ 发布内容**。
- 选择**提供**或**需求**。表单会在地图上打开。
- **标题：**几个词，在手机上最多 50 个字符。例如“天然酵母面包”、“周五搭顺风车进城”。
- **分类：**选取最贴近的一项。
- **描述：**什么事情、时间、地点，以及人们需要了解的任何信息。
- **照片：**至少一张，最多五张。点按**相机**或**相册**。在没有豆子的地方，“需求”的照片是可选的。
- **位置：**点按**我的位置**，或者点按**放置图钉**并在地图上轻触，然后点按**确认图钉**。你所在社区的每位成员都能看到该图钉，因此如果你愿意，可以将其放置在住所附近，而非精确放置在大门口。参见“你的图钉位置”。
- **价格：**一定数量的豆子。点按单位按钮选择 **Total** 或 **/ Hr**。点按**免费**可无偿赠送。该按钮还提供 **/ Dy**、**/ Wk** 和 **/ Mo**，但新刊登目前尚不支持保存这些单位：它会被保存为总价。请选择 **Total**，并在描述中说明时间周期。
- 点按**发布提供**或**发布需求**。

在所有必要信息填写完毕之前，按钮会提示缺少的内容，例如**添加照片**或 **Set a price**。

在 Web 应用中，步骤略有不同：

- 点按地图上的 **+** 按钮（名称为**新发布**），或市集上的 **+ 发布内容**。
- 如需放置图钉，点按**我的位置**，或点按**放置图钉**后轻触地图。Web 应用中没有**确认图钉**这一步。
- 价格由一个数字输入框和一个单位列表组成。没有**免费**按钮：输入 0 即可免费赠送。
- 标题没有 50 个字符的限制。
- 缺少内容时，按钮会显示 **Map location required** 或 **Fill required fields**。在你添加至少一张照片之前，按钮会保持灰色。
- 该表单不保存草稿。

## 在全球社区中

全球社区中没有豆子，因此那里的刊登没有价格。表单中没有**价格**项：请在描述中说明你希望换取什么回报，或者说明它是免费的。在原本显示价格的位置，Web 应用的表单以及手机端用于修改刊登的表单会显示“🏘️ In a local community this is a price in Beans ›”：点按它可以了解原因。参见“豆子与全球社区”。

全球社区的访客在加入之前即可查看该刊登的照片及其大致区域。他们可以看到刊登的文字和照片以及大致位置，但看不到你的姓名、头像或确切地点。在 Web 应用中，表单会在照片下方说明这一点。全球社区的成员看到的地点范围大约在 1 公里左右。

## 不确定该收多少？

在手机上，点按价格下方的 **Not sure what to charge?**。在 Web 应用中，表单中没有这一行：改为在市集中打开 **💡 定价指南**。简要参考：40 颗豆子大约相当于一个人一小时的时间。**社区定价指南**为许多日常事务提供了估算值。在手机上，轻触其中一项即可为你自动填写一份“提供”。在 Web 应用中，轻触其中一项会在地图上打开“新发布”表单，但不会自动预填任何内容。

在价格下方，你可以看到扣除 1.5% 市集费用后实际收到的数额。赠予无需扣减费用。

## 额外选项

- **Repeatable：**刊登在每笔交易后仍保持有效，且可以同时供多个人接受。非常适合每周的顺风车或每个周六的面包。
- **亦需少量现金：**如果你还需要少量现金（用于燃油或材料费），请勾选此项。应用绝不处理现金交易；由你们双方私下结清。
- **传播范围：**仅当你所在社区与其他社区开展交易时可用：将刊登保留在此处，或进一步分享出去。

在手机上，应用会在你输入时保存草稿。如果你离开后返回，它会询问是**继续**还是**重新开始**。

## 仅发布到群组

打开**公共资金池**，然后打开**群组**，进入你的群组，并点按 **Post to** 以及该群组的名称。只有该群组成员可以看到该刊登。在手机上，这种较短的表单没有照片和位置信息。在 Web 应用中，它会在地图上打开常规表单，并预设为该群组。

## 修改或删除刊登

打开你的刊登。如果上面没有正在进行的交易：

- **Edit Post** 可以修改文字、分类、价格和照片。点按**保存**。位置无法修改；若要更改位置，请删除刊登并重新发布。
- **Pause Offer** 可以暂时隐藏“提供”。**Activate Offer** 可使其恢复展示。“需求”无法暂停。
- **删除帖子**可将其移除。任何仍在申请该刊登的人都会看到其申请被标记为已拒绝。

当有人正在申请你的刊登时，你仍可以修改其文字和照片，但无法修改其价格：应用会给出相应提示。当刊登上的豆子处于暂管中时，你完全无法对其进行编辑。唯一的例外是可重复刊登（它可以同时存在多笔交易）：你仍可以修改其文字和照片，但无法修改其价格。如需修改价格，请先拒绝或取消该交易。

在本地社区中，刊登永不过期。事情完成后请自行将其删除。

在全球社区中，刊登在最后一次修改 90 天后会自动归档：它会从市集中下架，其照片也会被删除。通过 **Edit Post** 保存刊登可将其保留时间再延长 90 天。参见“全球社区的限制”。
