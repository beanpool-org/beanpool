## Sa bagong telepono

Wala sa mga backup ng iyong telepono ang susi ng iyong account. Ang isang bagong telepono ay nangangailangan ng iyong 12 salita (mga salitang Ingles) o isang naka-link na sign-in account, kahit ang isang iPhone na naibalik mula sa isang backup ng luma mo.

- I-install ang BeanPool at buksan ito.
- I-tap ang **Miyembro ka na ba? Ibalik ang account**.
- Piliin ang **Ibalik gamit ang 12 Salita** o **Ibalik gamit ang Social**.

## Gamit ang iyong 12 salita

- I-type ang 12 salita nang sunod-sunod, o i-tap ang **I-paste**.
- Sa ilalim ng **Aling komunidad?**, i-tap ang **Pandaigdigang komunidad**, o isa sa mga komunidad na mayroon ang teleponong ito. Para sa iba pa, i-tap ang **ibang address** at i-type ang pangalan o address ng iyong komunidad.
- I-tap ang **Ibalik ang Pagkakakilanlan**. Babalik ang iyong pangalan at larawan mula sa iyong komunidad.

## Gamit ang isang sign-in account

Gumagana lamang ito kung nag-link ka ng isa dati (tingnan sa ibaba), at habang tumatakbo lamang ang server ng iyong komunidad.

- I-type ang iyong pangalan sa komunidad. Maaaring magmungkahi ang app ng "Ikaw ba ito?".
- I-type ang pangalan o address ng iyong komunidad.
- I-tap ang **Ibalik gamit ang** at ang account na iyong ini-link: Google o Facebook, o Apple sa isang iPhone.
- Sa Google sa isang iPhone, magbubukas ang isang web page ng Google. Mag-sign in doon at piliin ang account na iyong ini-link. Sa Android, ipinapakita ng Google ang sarili nitong listahan ng mga account. Kung hindi ito makakapagpakita sa teleponong iyon, isang web page ng Google ang bubukas sa halip.

Kung ang sign-in account ay ini-link mula sa isang teleponong mayroon ng iyong 12 salita, sa isang updated na app, babalik din ang iyong 12 salita. Kung hindi, walang 12 salita ang telepono: hindi mabubuo muli ang mga ito mula sa isang sign-in. Kung nakasulat ang mga ito, maaari mo silang idagdag (tingnan ang "Iyong 12 salita"). Hanggang noon, ang isang naka-link na sign-in account ang paraan ng teleponong iyon para makabalik, kaya panatilihing naka-link ang isa, at mag-link ng pangalawa kung kaya mo (tingnan sa ibaba).

## Pagprotekta sa iyong account ngayon

- Buksan ang **Mga Setting** at i-tap ang **Proteksyon ng Account**.
- Sa ilalim ng **Mga Sign-In Recovery Provider (1-of-N)**, i-tap ang **Protektahan gamit ang** at pumili ng account.
- Ipasa ang pagsusuri sa lock screen ng iyong telepono. Maibabalik ng naka-link na account ang iyong account, kaya nagtatanong muna ang app.
- Sa Google sa isang iPhone, magbubukas ang isang web page ng Google. Mag-sign in doon at piliin ang iyong account, at babalik ka sa BeanPool.

Gumagana rin ito sa isang teleponong walang 12 salita.

Kung sumali ka sa pandaigdigang komunidad gamit ang 12 salita, gamitin ang **Magdagdag ng sign-in**, malapit sa itaas ng **Proteksyon ng Account**, sa halip. Isa rin itong paraan pabalik, at tinatanggal din nito ang mga limitasyon sa isang bagong 12-salitang account. Tingnan ang "Iyong 12 salita".

Kung nasa teleponong ito ang iyong 12 salita, itinatago rin ng naka-link na account ang mga ito, kaya ibinabalik ng pag-restore gamit ito ang mga ito. Ang isang account na ini-link mo sa mas lumang bersyon ng app ay nagtatago lamang ng iyong susi: i-tap ang **Ikonekta muli** sa tabi nito, at ipasa ang pagsusuri sa lock screen ng iyong telepono, upang maisama ang mga salita. Sa isang teleponong walang 12 salita, walang maisasama, kaya hindi ipinapakita ang **Ikonekta muli**.

Hindi ito paraan para mag-log in. Ang iyong account ay ang sarili mo pa ring susi. Tumutulong lamang ang naka-link na account na maibalik mo ito, sa komunidad na iyon.

Upang alisin ito, i-tap ang **Idiskonekta**.

## Kung nag-link ka ng GitHub

Hindi na gumagamit ng GitHub ang BeanPool. Pampubliko ang ID ng GitHub account, kaya ang kopyang naka-lock dito ay hindi naka-lock sa anumang ikaw lamang ang mayroon. Kapag na-update ang server ng iyong komunidad, binubura nito ang bawat kopyang naka-link sa GitHub. Hindi ginalaw ang mismong account mo, at gumagana pa rin ang iyong 12 salita.

- Kung GitHub lamang ang tanging account na ini-link mo at nasa teleponong ito ang iyong 12 salita ngunit hindi nakasulat, isulat ang mga ito ngayon (**Mga Setting**, pagkatapos ay **Tingnan ang Parirala sa Pagbawi**), o i-link ang Google, Facebook o (sa isang iPhone) Apple, tulad ng nasa itaas. Hanggang sa gawin mo ang isa sa mga ito, ang teleponong ito ang tanging paraan mo para makapasok sa iyong account.
- Kung nakasulat ang iyong 12 salita, wala kang kailangang gawin. Upang magkaroon din ng sign-in account, i-link ang Google, Facebook o (sa isang iPhone) Apple, tulad ng nasa itaas.
- Kung GitHub lamang ang account na ini-link mo, walang 12 salita ang teleponong ito at wala kang nakasulat, i-link ang Google, Facebook o (sa isang iPhone) Apple ngayon. Hanggang sa magawa mo ito, ang teleponong ito ang tanging paraan mo para makapasok sa iyong account.

## Sino ang makakabukas sa kopya

Gumagana ang isang naka-link na sign-in account dahil nagtatago ang server ng iyong komunidad ng naka-lock na kopya ng iyong account para rito. Ang mga taong nagpapatakbo ng server na iyon ay maaaring magbukas sa kopyang ito, dahil sinusuri ng kanilang server ang iyong sign-in. Sa pandaigdigang komunidad, iyon ay ang BeanPool. Ang isang ninakaw na kopya ng database ng server ay hindi magagawa ito, kapag na-update na ang server para rito. Sinumang kukuha sa iyong sign-in account ay makakapasok din: tingnan ang "Kung may ibang sumusubok".

Kung mas gusto mong walang sinuman maliban sa iyo ang makakapasok, gamitin lamang ang iyong 12 salita: panatilihing nakasulat ang mga ito, at i-tap ang **Idiskonekta** sa tabi ng bawat sign-in account. Binubura ng pagdiskonekta ang kopya. Ang standby server, ang pangalawang server na inihahanda ng ilang komunidad upang humalili, ay nagbubura rin ng kopya nito, sa susunod na kumopya ito mula sa pangunahing server (mga isang beses kada minuto). Hindi binubura ng pagdiskonekta ang mga kopyang nasa mga backup na ng server, o ang kopyang itinatago ng server, bilang tala, sa bawat pagkakataon na ibinabalik ng isang sign-in ang iyong account. Mabubuksan din ng mga taong nagpapatakbo ng server ang mga iyon.

## Kung may ibang sumusubok

Kung may magsisimulang magbawi ng iyong account, ipinapakita ng Mga Setting ang **May nagbabawi ng iyong account** habang isinasagawa ito. Kung hindi ikaw ito, i-tap ang **Ihinto Na Ito Ngayon**: wala nang ibibigay ang server ng iyong komunidad sa pagbabalik na iyon. Kung makapasok sila gamit ang iyong naka-link na sign-in account, makakakuha ka ng alerto na kaka-restore lang ng iyong account sa ibang device, at maaaring nakapasok na sila bago mo pa ito makita. Panatilihing ligtas ang sign-in account na iyon, gamit ang sarili nitong malakas na password.

## Kung may account na ang telepono

Pinapalitan ng pag-restore ng ibang account ang nasa teleponong ito, nag-restore ka man gamit ang iyong 12 salita o gamit ang sign-in account. Nagtatanong muna ang app, sa **Palitan ang account ng teleponong ito?** (gamit ang sign-in account, kapag naka-sign in ka na). Walang magbabago hanggang sa i-type mo ang **WIPE**, i-tap ang **Palitan ang Account** at ipasa ang pagsusuri sa lock screen ng iyong telepono. I-tap ang **Panatilihin**, pagkatapos ay ang pangalan ng account, **bumalik** upang iwanan ang lahat kung ano ito.

Tiyaking nasa iyo ang 12 salita para sa account na iyong pinapalitan. Kung nasa teleponong ito ang mga ito, ipinapakita ng screen na iyon ang mga ito kapag tinap mo ang **Ipakita ang 12 salita ni** (pangalan ng account) at ipinasa ang pagsusuri sa lock screen ng iyong telepono. Kung ang teleponong ito ay walang 12 salita para sa account na iyon (sinasabi ito ng Mga Setting), kung walang naka-link na sign-in account ay hindi mo na ito maibabalik.

## Nawala ang iyong telepono at ang iyong 12 salita

Kung wala ang iyong 12 salita at walang naka-link na sign-in account, maaaring ilipat ng isang admin ng iyong komunidad ang iyong account sa isang bagong telepono, kasama ang iyong Munggo, ang iyong pangalan, at ang iyong kasaysayan. Pumunta at makipagkita sa kanila nang personal: sinusuri muna nila kung ikaw talaga ito.

- Gumagawa ang admin ng re-key code sa kanilang screen. Kung nasa lumang telepono mo pa rin ang app, makakatanggap ito ng abiso na sinimulan ng isang admin ang paglipat ng iyong account.
- Sa iyong bagong telepono, buksan ang BeanPool, i-tap ang **Miyembro ka na ba? Ibalik ang account**, pagkatapos ay **Binigyan ako ng admin ng re-key code**. I-scan ang QR sa screen ng admin, o i-type ang code (nagsisimula ito sa RK-) at ang pangalan ng iyong komunidad. Sa isang browser, binubuksan ng link ng QR ang parehong screen; o buksan ang web app ng iyong komunidad, i-tap ang **Miyembro Na Ako →**, pagkatapos ay **Binigyan ako ng admin ng re-key code**, at i-type ang code.
- Nagpapakita ang iyong telepono ng dalawang-digit na numero, at sa ilalim nito ang address ng komunidad na tinanong nito. Ipakita ang dalawa sa admin: itina-type nila ang numero sa kanilang screen. Sinisiguro ng numero na telepono mo ang kanilang itinatali, at hindi ang isang taong nakakita sa code. Iniiwan ng **Huwag muna** ang numero: pinapanatili ng iyong telepono ang puwang nito, at ipinapakita ng parehong code ang parehong numero muli.
- Kung ang bagong telepono ay walang BeanPool account, ipinapakita nito pagkatapos ang 12 salita (mga salitang Ingles) ng iyong **bagong** susi. Isulat ang mga ito: hindi na gumagana ang iyong mga lumang salita, at ang iyong lumang telepono ay tuluyan nang titigil sa paggana. Ang isang teleponong mayroon nang account (para sa ibang komunidad) ay nagpapanatili ng 12 salita ng account na iyon, at ibinabalik na rin ng mga ito ang account na ito ngayon.
- Kung nag-link ka ng isang sign-in account, hihilingin sa iyo ng telepono na i-link itong muli sa Proteksyon ng Account: ang mayroon ka ay nagpoprotekta sa iyong lumang susi, kaya inalis ito.
- Makikita ng mga taong ka-chat mo na nagbago ang iyong susi. Sabihin sa kanila na ikaw iyon, at basahin sa kanila ang iyong **Aking key code**, sa **Mga Setting** sa ilalim ng **Proteksyon ng Account** sa telepono. Tingnan ang "Kung sinasabi ng chat na nagbago ang susi sa likod ng isang pangalan".

Tumatagal ang code nang 24 oras. Kung sinabi ng iyong admin na hindi ang iyong telepono ang nakita nila, o nag-expire na ang code, humingi sa kanila ng bago.
