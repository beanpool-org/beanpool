## 동일한 계정, 다른 화면

컴퓨터나 휴대폰의 웹 브라우저에서도 커뮤니티를 이용할 수 있어요. 이 가이드는 휴대폰 앱을 기준으로 작성되었어요. 웹 앱도 동일하게 작동하지만, 일부 명칭이나 위치가 다를 수 있어요.

양쪽 모두에서 하나의 계정을 사용하세요. 브라우저에서 가입하셨나요? 휴대폰에 동일한 계정을 등록하세요: 아래의 "웹 계정을 휴대폰에 연결하기"를 참조하세요. 휴대폰에서 가입하셨나요? 브라우저로 가져오세요: "휴대폰 계정을 컴퓨터에서 사용하기"를 참조하세요. 새로 가입하면 두 번째 계정이 생성되며, 두 계정은 하나로 합칠 수 없어요.

## 브라우저에서 global.beanpool.org 가입하기

global.beanpool.org의 글로벌 커뮤니티는 누구에게나 열려 있으며, 웹 브라우저에서 바로 가입할 수 있어요. 초대장이나 휴대폰 앱이 필요하지 않아요.

가입하기 전에는 방문자가 보는 방식으로 **홈**, **장터**, **지도**, **장부**(지역 커뮤니티의 예시)가 표시돼요: 공개 카드, 게시물, 사진, 대략적인 위치가 표시되지만 이름, 얼굴, 정확한 위치는 표시되지 않아요. 가입하기 전에는 글을 올리거나 답변을 보낼 수 없어요. 페이지 상단과 게시물 위의 카드에 **참여**가 있어요.

휴대폰 브라우저에서는 해당 카드에 **BeanPool 앱에서 열기**가 먼저 표시돼요. 글로벌 커뮤니티의 가입 화면으로 BeanPool 앱을 열어주며, 앱이 설치되어 있지 않다면 휴대폰의 앱 스토어로 이동하므로 처음부터 앱에서 계정을 만들 수 있어요. 앱에 이미 계정이 있는 경우 해당 계정으로 **글로벌 커뮤니티 참여**가 열리거나, 이미 그곳의 멤버인 경우 **BeanPool** 시트가 열려요. "BeanPool 가입하기"를 참조하세요. 그 아래의 **또는 브라우저에서 바로 참여하기**를 누르면 아래 설명처럼 브라우저에서 바로 가입해요. 컴퓨터에서는 카드에 **참여**가 표시돼요.

글로벌 커뮤니티에 게시물이 몇 개 없을 때는 **장터**에 **예시**로 표시된 몇 개의 카드가 함께 나타나요. 사람들이 올리는 게시물을 보여주기 위해 만들어진 가상의 게시물이며 열어볼 수 없어요. 실제 게시물이 충분해지면 사라져요.

누군가 공유한 게시물이나 이벤트 링크를 통해 접속한 경우 해당 페이지가 먼저 열려요. 그 페이지에서 가입하고 나면 작성자 정보가 포함된 상태로 페이지가 다시 열려요.

- **참여**를 탭한 다음 **BeanPool을 처음 써봐요**를 탭하세요.
- 사람들이 보게 될 이름을 선택하세요. 최소 2자 이상, 최대 20자 이하이어야 해요.
- 가입 방법을 선택하세요. **12개 비밀 단어로 계정 만들기**는 다른 계정이 필요하지 않아요. 또는 **또는 로그인** 아래에서 페이지에 표시되는 계정 중 하나로 한 번 로그인하세요: **Google**, **Apple**, 또는 **Facebook**. 해당 업체의 로그인 페이지로 이동한 후 다시 돌아와요. 커뮤니티에서 로그인만 받는 경우 로그인 버튼만 표시돼요.
- 그다음은 모두와 동일한 단계예요: 사진, 대략적인 내 위치, 12개 단어, 그리고 짧은 둘러보기예요. 상단 바에 **로그인**(12개 단어로 가입한 경우 **내 이름**), **내 사진**, **내 지역**, **안전 백업**, **이용 방법**이 표시돼요. **내 지역** 단계에서 **내 위치 사용**은 브라우저에 한 번 확인을 요청하고 결과를 약 10km 단위로 반올림하여 전송해요. **동네나 도시 이름 입력**는 이름으로 장소를 찾으며, **지금은 건너뛰기**는 아무것도 전송하지 않아요. 마지막에 브라우저가 위치 권한을 다시 묻지 않아요. "BeanPool 가입하기"를 참조하세요.

**12개 단어로 가입할 때.** Google, Apple, Facebook 계정이 필요 없으며, 커뮤니티는 내 이름과 가입한 네트워크의 암호화된 참조값(하루 동안 보관) 외에는 나에 대한 어떤 정보도 보관하지 않아요. 이름을 입력하는 동안 페이지는 아무도 무한히 빠르게 계정을 생성하지 못하도록 백그라운드에서 커뮤니티를 위한 작은 작업을 수행해요. 이 작업을 기다릴 필요는 없어요: 완료되기 전에 버튼을 누르면 8단계 진행 표시줄과 함께 **계정 설정 중…**이 표시돼요. 많은 사람이 가입하고 있는 경우 더 오래 걸리며 브라우저에서 걸리는 예상 시간이 표시돼요: 이때는 소셜 로그인이 더 빨라요. **← 다른 방법 선택**를 누르면 작업이 계속 진행되는 상태로 두 가지 선택 화면으로 돌아가요. 영어로 된 12개 단어가 유일한 복구 방법이에요. 우리도 커뮤니티도 단어를 재설정할 수 없어요: **안전 백업** 단계에서 이 점을 안내하며 **다시 돌아오는 두 번째 방법으로 로그인 추가**를 제안해요: 사진이 저장된 후 짧은 둘러보기의 마지막에서 로그인을 선택할 수 있어요(아래 "나중에 로그인 추가하기" 참조). 둘 다 선택 사항이에요.

**간편 로그인으로 가입할 때.** 커뮤니티는 해당 계정의 암호화된 참조값만 보관하며 이메일이나 이름은 절대 저장하지 않아요. 하나의 로그인 계정으로 한 번 가입할 수 있어요.

동일한 로그인은 계정을 복구하는 방법으로도 보관돼요. 페이지에 **계정 보안 설정 중…**이 표시되는 동안, 영어로 된 12개 단어와 함께 계정의 잠긴 사본을 만들고 가입 시 커뮤니티에 전달해요. 해당 로그인 계정으로 이 사본을 열 수 있어요. 휴대폰 앱에서 연결된 로그인 계정과 마찬가지로 서버가 로그인을 확인하므로 서버 운영자도 열 수 있어요: "계정 복구하기"를 참조하세요. 그러면 설정에 **로그인 복구: 연결됨**과 어떤 로그인인지가 표시돼요. 사본을 만들거나 보관할 수 없는 경우에도 가입은 완료되며 설정에 **로그인 복구: 연결되지 않음**으로 표시돼요: 이 경우 12개 단어가 유일한 복구 방법이에요.

커뮤니티가 해당 사본을 보관하지 않기를 원한다면 웹 앱에서는 아직 삭제할 수 없어요. 휴대폰에도 계정이 등록되어 있다면 휴대폰 앱에서 삭제할 수 있어요: 글로벌 커뮤니티를 연 상태에서 **설정**으로 이동하여 **계정 보호**를 탭한 다음 로그인 옆의 **연결 해제**를 탭하세요. 어느 쪽이든 12개 단어를 안전하게 보관하세요: 나만의 유일한 복구 방법이에요.

선택한 이름을 누군가 이미 사용 중이라면 숫자가 붙어서 생성돼요. 설정에서 변경할 수 있어요.

**이미 BeanPool을 사용 중이신가요?** 두 번째 계정을 만들지 마세요. **참여**를 누른 후 휴대폰 앱에서 연결하려면 **휴대폰에서 BeanPool을 쓰고 있어요**를 선택하거나 **내 12개 단어를 가지고 있어요**를 선택하세요. 해당 계정이 아직 글로벌 커뮤니티에 가입하지 않은 경우 동일한 가입 방법(12개 단어 또는 한 번 로그인)이 제공되며 이미 가지고 있는 계정으로 가입돼요. 이전에 로그인 방식으로 글로벌 커뮤니티에 가입한 적이 있다면 **이전에 로그인으로 가입했어요**를 선택하세요(아래 참조).

도중에 페이지를 닫은 경우 10분 이내에 다시 열면 동일한 이름으로 이어서 진행돼요.

**브라우저당 하나의 계정.** 두 개의 탭에서 동시에 가입하면 두 번째 탭에 **이 브라우저에 이미 계정이 있어요**라고 표시되며 해당 계정 이름과 함께 **진행 중**이 제공돼요. 아무것도 기존 계정을 덮어쓰지 않아요. 두 번째 탭의 가입도 완료되었다면 해당 계정도 이 브라우저에 보관되며 **표시** (이름) **12 words**에 단어가 표시돼요: 계정을 유지하려면 종이에 적어두세요. 대신 해당 계정을 사용하려면 설정에서 로그아웃(**이 기기에서만 제거**)한 다음 해당 단어로 복원하세요.

**이미 전송된 가입 요청이 항상 우선해요.** 이 브라우저에서 전송한 가입 요청이 성공했을 가능성이 있다면, 페이지는 초대나 다른 계정 복원보다 먼저 커뮤니티에 그 요청에 대해 확인해요. 이미 가입되었다면 그대로 계속 진행해요. 여전히 처리 중일 수 있다면 몇 분 기다린 다음 **다시 확인**하라고 안내해요. 커뮤니티가 새 멤버 가입을 중단한 경우에도 이 원칙이 적용돼요.

가입 요청이 전송된 후 페이지에 문제가 발생하면 안내와 함께 **페이지 새로고침**이 제공돼요. 가입 정보는 이 브라우저에 보관되며 새로고침 시 가입 여부를 확인해요.

**하나의 네트워크에서 많은 사람이 가입할 때:** 하나의 인터넷 연결에서 많은 새 계정이 유입될 때 가입을 거부하기보다는 브라우저에 약간 더 많은 작업을 요구해요. 동일한 네트워크의 모든 사람이 함께 계산되므로 학교 캠퍼스, 사무실, 모임 장소에서는 내가 아니라 다른 사람들이 가입하고 있는 중일 수 있어요. 요청 수가 매우 많은 수준을 넘어설 때만 당분간 가입할 수 없다는 안내와 함께 대기 시간이 표시돼요. 12개 단어 계정에 대해 그런 안내가 나오더라도 로그인 방식 가입은 여전히 작동해요.

## 새 계정의 제한

글로벌 커뮤니티에서 새 계정은 첫 3일 동안, 그리고 작성한 게시물 중 3개가 유지될 때까지 몇 가지 일일 한도가 적용돼요: 24시간 동안 게시물 3개, 사진 5장, 대화를 걸 수 있는 새 상대 10명으로 제한돼요. 12개 단어로만 생성된 계정은 첫 7일 동안, 그리고 작성한 게시물 중 3개가 유지될 때까지 더 적은 한도가 적용돼요: 게시물 2개, 사진 4장, 대화를 걸 수 있는 새 상대 3명이에요. 로그인을 추가하면 즉시 일반 한도로 상향돼요. 나에게 먼저 글을 보낸 사람에게 답장하는 것은 제한되지 않아요. 그 이유는 "문제 신고하기"를 참조하세요.

- 가입 후 **새 계정이에요**라는 카드에 각 항목의 남은 수량과 충전 시점이 표시돼요. **✕**를 탭하여 닫으세요. 한도가 끝날 때까지 **설정**에 남아 있어요.
- 한도에 도달하면 **새 게시물**이나 채팅창에서 어떤 한도인지와 언제 해제되는지 알려주며, **새 게시물**에 동일한 카드가 표시돼요.
- 중재자가 게시 활동을 일시 중지한 경우 **새 게시물**과 채팅창에 안내가 표시되며 **게시 일시 중지됨** 카드에 언제까지인지 표시돼요. 일시 중지가 끝날 때까지 유지돼요.
- 웹 앱이 닫혀 있는 동안 중재자가 내 게시물 중 하나를 숨기거나 삭제하거나 게시 활동을 일시 중지한 경우, 웹 앱을 다음에 열 때 최대 60일 동안 알림이 표시돼요. 각 알림은 **확인**을 탭할 때까지 유지되며 탭한 후에는 다시 나타나지 않아요. 대기 중인 알림이 여러 개라면 **Close all**을 눌러 모두 닫을 수 있어요. 휴대폰에도 계정이 등록되어 있다면 휴대폰에서 이미 본 알림이 웹 앱에 다시 표시될 수도 있어요.

내 지역 커뮤니티에는 이러한 제한이 전혀 없어요.

## 간편 로그인으로 계정 복구하기

글로벌 커뮤니티에서는 가입할 때 사용한 로그인을 통해 브라우저로 계정을 복원할 수 있어요: 저장된 데이터가 삭제된 브라우저나 다른 컴퓨터의 새 브라우저에서 복원할 수 있어요. 동일한 계정이 복원되며 두 번째 계정은 생성되지 않아요.

- **이미 BeanPool을 사용 중이신가요?**를 탭한 다음 **내 로그인 사용**을 탭하세요. (**참여**를 누른 후 **이전에 로그인으로 가입했어요**를 눌러도 동일해요.)
- BeanPool 계정을 보관하기에 너무 오래된 브라우저는 이 선택지 대신 해당 안내를 표시해요(**참여** 자리에도 마찬가지예요). 최신 Chrome, Firefox, Safari, Edge를 사용하세요.
- 여기에 이름을 입력하세요. 내 계정이 나타나면 탭하세요.
- 가입할 때 사용한 로그인을 선택하세요: **Google**, **Apple**, 또는 **Facebook**. 가입할 때와 마찬가지로 해당 업체의 로그인 페이지로 이동한 후 다시 돌아와요.
- 페이지가 브라우저에서 계정의 잠긴 사본을 열고 내가 탭한 계정이 맞는지 확인해요. 맞지 않다면 **That isn't** (이름)이라고 표시되며 아무것도 저장하지 않아요.
- 사본에 12개 단어가 보관되어 있다면 영어로 된 12개 단어와 함께 로그인돼요: 브라우저에서 가입한 계정은 항상 단어를 가지고 있어요. 사본에 단어가 보관되지 않았다면 이 브라우저에는 단어가 없으며 설정에 그렇게 표시돼요(아래 "12개 단어 보관하기" 참조).

본인이 아닌 경우에 대비하여 계정 복원이 진행 중이라는 사실이 계정의 다른 기기들에 전달돼요.

GitHub로 가입한 경우 복원할 수 없어요: BeanPool은 더 이상 GitHub를 지원하지 않아요("계정 복구하기" 참조). 대신 12개 단어를 사용하세요.

가입할 때 사용하지 않은 다른 계정으로 로그인하면 페이지가 이를 안내하고 다시 선택할 수 있게 해줘요. **참여**를 탭한 뒤 이미 가입된 계정으로 로그인하면 페이지에 **이미 이곳의 멤버예요**라고 표시되며 **Restore with** (해당 로그인)을 제안해요.

**브라우저당 하나의 계정** 원칙이 여기에도 적용돼요. 이 브라우저에 이미 다른 계정이 있다면 아무것도 이를 대체하지 않아요: 페이지에 **이 브라우저에 이미 계정이 있어요**라고 표시되며 해당 계정을 열 수 있도록 제안해요. 대신 내 계정을 가져오려면 먼저 기존 계정에서 로그아웃하세요. 이 브라우저에 이미 내 계정이 있다면 이미 등록되어 있다고 안내해요.

## 나중에 로그인 추가하기

글로벌 커뮤니티에 12개 단어로 가입한 경우 그 단어들이 유일한 복구 방법이에요. 가입 후 **복구 방법 한 가지** 카드가 **내 12개 단어 보기** 및 **로그인 추가**와 함께 이를 안내해요. **✕**를 눌러 닫으세요: 작성한 게시물이 유지된 후 한 번, 첫 1주일이 지난 후 한 번 다시 나타나요. 로그인을 추가할 때까지 **설정**에 남아 있어요.

- **로그인 추가**를 탭한 다음 **Google**, **Apple**, 또는 **Facebook**을 탭하세요. 가입할 때처럼 해당 업체의 로그인 페이지로 이동한 후 다시 돌아와요.
- **설정**이 열리며 추가되었는지가 표시돼요. 그때부터 해당 로그인은 계정 복구 방법이 되기도 해요: 로그인으로 가입할 때처럼 커뮤니티가 계정의 잠긴 사본을 보관하며 서버 운영자가 그 사본을 열 수 있어요. 새 계정 한도가 즉시 일반 한도로 상향돼요.
- 여기에 이미 다른 BeanPool 계정이 있는 로그인 계정이거나 커뮤니티에서 제명된 계정에 속했던 로그인 계정은 추가할 수 없으며, 페이지가 이를 안내하고 아무것도 변경되지 않아요.

## 다른 명칭과 위치

- **초대로 가입하기:** 첫 단계 버튼에 **계정 만들고 참여하기 →**라고 표시돼요. 선택한 이름을 누군가 이미 사용 중이라면 숫자가 붙어서 생성돼요. **내 사진** 단계에서 **← 뒤로**을 누르면 **다음 →**와 함께 이름만 표시돼요: 동일한 계정에서 이름을 변경(최대 20자)하거나 유지하세요. 새 이름을 누군가 이미 사용 중이라면 페이지가 이를 알리고 다른 이름을 제안해요.
- **탭:** 웹 앱에는 **홈**, **장터**, **지도**, **공유지**, **채팅**, **사람 탐색**, **장부**가 있어요. 휴대폰 앱에서 **대화**라고 부르는 것이 웹에서는 **채팅**이며, **사람 탐색**은 별도의 탭으로 분리되어 있어요.
- **설정과 내 프로필:** 오른쪽 상단의 작은 버튼들이에요: 내 프로필, **?**, 설정 순서예요. 넓은 화면에서는 왼쪽 메뉴 하단에 있어요.
- **제공 또는 요청 등록:** **지도** 페이지에서 **새 게시물**을 사용하세요.
- **화면 모드:** 휴대폰의 "휴대폰 설정과 동일" 대신 **기기 설정과 동일**로 표시돼요.
- **차단:** 설정에 **차단한 멤버 관리**가 있어요. 커뮤니티는 차단 목록을 계정과 함께 보관하므로 어느 브라우저에서 로그인하든 복원되며, 로그아웃하면 컴퓨터에 차단 정보가 남지 않아요. 커뮤니티 서버 운영자는 내가 누구를 차단했는지 볼 수 있어요. 차단 및 차단 해제는 인터넷 연결이 필요해요: 연결이 없으면 웹 앱이 이를 안내하고 아무것도 변경되지 않아요. 휴대폰 앱에서 설정한 차단은 휴대폰에만 유지되며 여기에는 표시되지 않아요.
- **대화방:** 웹 채팅 상단에는 **신고** 및 **차단** 버튼이 있어요.
- **내 지역:** 글로벌 커뮤니티의 경우 웹 앱 설정에도 **내 지역**이 있으며, 장터와 지도가 그 위치를 기준으로 시작돼요. "내 지역"을 참조하세요.
- **글로벌 커뮤니티:** 지역 커뮤니티의 경우 설정의 **BEANPOOL** 아래에 **글로벌 커뮤니티** 항목이 있으며 주소와 함께 **글로벌 커뮤니티는 여러 커뮤니티 중 하나일 뿐이에요. 로컬 커뮤니티는 자체 서버에서 운영되며 글로벌 커뮤니티가 없어도 잘 돌아가요.**라고 표시돼요. 커뮤니티 서버가 지정한 글로벌 커뮤니티가 새 탭으로 열려요. 직접 계정을 가져오기 전까지는 내 계정이 그곳에 없어요: 해당 탭에서 **참여**를 누른 다음 **내 12개 단어를 가지고 있어요**를 선택하세요. 커뮤니티가 지정하지 않은 경우 이 항목이 표시되지 않아요.

## 웹 앱에 없는 기능

- 글로벌 커뮤니티 이외의 커뮤니티에서 간편 로그인으로 계정 복구하기. 다른 커뮤니티에서는 12개 단어로 복원하거나, 계정이 휴대폰에도 있는 경우 휴대폰 앱에서 연결하여 복원해요.
- 동향의 **배움** 레인.
- 휴대폰의 앱 잠금.
- 소유자와 관리자가 자체 키로 커뮤니티 설정에 직접 로그인하는 기능. 웹 앱의 **Manage** 링크는 설정을 열어주지만 브라우저 자체에는 잠금 해제 기능이 없어요. 컴퓨터의 설정에서 **휴대폰으로 로그인**을 선택하고 휴대폰 앱(**설정**에서 **컴퓨터에서 이 커뮤니티 관리**, 이전 앱의 경우: **Sign in on a computer**)으로 코드를 스캔하세요.

## 웹 계정을 휴대폰에 연결하기

브라우저에서 가입했다면 동일한 계정을 휴대폰 앱으로 가져오세요. 휴대폰에서 다시 가입하지 마세요: 그러면 두 번째 계정이 생성되며 두 계정은 하나로 합칠 수 없어요. 12개 단어 옆의 **안전 백업**과 설정의 **로그인 복구** 카드가 방법을 안내해요:

- BeanPool 앱을 설치하고 여세요.
- **이미 회원이신가요? 계정 복원**을 탭한 다음 **12개 단어로 복구**를 탭하세요.
- 영어로 된 12개 단어를 입력하고 **어느 커뮤니티인가요?** 아래에서 **글로벌 커뮤니티**를 탭하세요. 해당 선택지가 없는 앱에서는 글로벌 커뮤니티 주소인 global.beanpool.org를 입력하세요. 다른 커뮤니티의 경우 해당 커뮤니티의 주소를 입력하세요(웹 앱의 동일한 문장에 주소가 나와 있어요).
- 간편 로그인으로 가입한 경우 동일한 로그인 계정으로 **Recover with Social**을 사용할 수도 있어요. "계정 복구하기"를 참조하세요.

브라우저 가입 화면 1에서도 반대 방향으로 동일한 내용을 안내해요: 휴대폰이나 컴퓨터에서 이미 BeanPool을 이용 중이라면 새 계정을 만들지 말고 기존 계정을 가져오세요.

## 휴대폰 계정을 컴퓨터에서 사용하기

- 컴퓨터의 웹 앱에서 모바일 앱과 연결하는 옵션을 선택하세요. QR 코드가 표시돼요.
- 휴대폰에서 **설정**을 열고 **기기 연결**(이전 앱의 경우: **Use your account on another device**)을 탭하세요.
- 휴대폰 카메라로 QR 코드를 비추고 **확인 및 기기 연결**을 탭한 다음 휴대폰 화면 잠금 확인을 통과하세요.
- 그러면 휴대폰에 **4자리 숫자**가 표시돼요. 컴퓨터에 해당 숫자를 입력하고 **확인**을 누르세요. 그 후에야 내 계정이 컴퓨터로 전달돼요. 세 번 잘못 입력하면 아무것도 전송되지 않으며 새 코드를 생성해야 해요. 숫자를 소리 내어 읽거나 다른 사람에게 보내지 마세요.
- 휴대폰에 앱 버전이 너무 낮다는 메시지가 뜨면 휴대폰의 BeanPool 앱을 업데이트한 다음 새 코드를 스캔하세요.

## 앱 설치하기

웹 앱이 앱처럼 홈 화면에서 바로 열릴 수 있도록 **BeanPool 설치**를 제공할 수 있어요. 브라우저가 이를 지원하지 않는 경우 **방법은?**을 눌러 안내 단계를 확인하세요.

## 12개 단어 보관하기

브라우저는 방문 없이 일주일이 지나면 데이터를 지우는 Safari처럼 저장된 데이터를 지우기도 해요. 12개 단어를 확인할 때까지 웹 앱 설정에 **복구 문구 확인 및 저장**과 함께 경고가 표시돼요. 반드시 확인하고 종이에 적어두세요.

12개 단어를 보관하지 않은 로그인 사본을 통해 복원된 브라우저는 단어를 가지고 있지 않으므로 이러한 경고를 표시하지 않아요. 거기서 **복구 문구 보기**는 **이 브라우저에 저장되지 않음**으로 표시되며 대신 계정을 복원할 수 있는 수단(종이에 적어둔 12개 단어, 또는 설정에 연결됨으로 표시된 로그인)을 안내하는 페이지가 열려요. 둘 다 없다면 계정이 휴대폰에도 있는 경우에 한해 휴대폰 앱으로만 복원할 수 있어요. 로그아웃하기 전 **이 기기에서만 제거**에서도 동일한 내용을 안내해요.
