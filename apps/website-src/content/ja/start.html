コミュニティを始める

すべてのコミュニティは専用のノード（メンバー、投稿、台帳のデータを保持する小さなサーバー）上で動いています。地域の誰かがそれを運営しています。あなたの町や地域にまだないなら、あなたが立ち上げることもできます。

コミュニティを運営するには何が必要か

手順に従えば約30分で完了します。まず知っておくべき6つのこと：

  • 費用。 ソフトウェアは無料です。自宅で常時稼働できる予備のコンピューター（ミニPC、NAS、64ビットOSのRaspberry Piなど）、または月額数ドル（約6米ドル）の小さなレンタルサーバーで動作します。
  • ホスティングの担当者。 ご自身で管理します（自前のマシンまたはレンタルしたサーバー）。beanpool.orgへの依存は不要で、独自のWebアドレスで運用できます。
  • 担当する役割。 メンバーからの通報はあなたに届きます。データフォルダーはリカバリーコードを使ってご自身でバックアップしてください。オーナーは2名体制にしてください。サーバーの常時稼働とアップデートを維持してください。
  • 閲覧できないもの。 メンバー同士のダイレクトメッセージ。
  • Dockerの事前準備。 以下のコマンドを実行する前に、マシンにDockerがインストールされている必要があります（契約直後のレンタルサーバーには通常入っていません）。
  • スマートフォンから接続できるアドレス。 スマートフォンがインターネット経由でコミュニティに接続するにはhttpsが必須です。パブリックIPアドレスがありポート80と443が開いているレンタルサーバーなら、そのIPアドレスだけで十分です。Cloudflareアカウントなしでサーバーが自動的に証明書を取得します。独自ドメインでも同様です。自宅環境や開放ポートがない場合でも、申請手続きによってサーバー自身がトンネルを実行し、.beanpool.orgで終わる無料の名前が取得できます。暗号化のないhttp://アドレスはホームネットワーク内でのみ機能します。
🧰

管理するもの

あなたとあなたが指名した管理者がコミュニティのモデレーターとなります。通報はあなたに届きます。メンバーのデータはあなたのマシン上にあるため、バックアップを管理します。事業体のディスカッションやイベントチャットは閲覧できますが、ダイレクトメッセージは閲覧できません。あなたが最初のメンバーを招待し、その人たちが次のメンバーを招待していきます。

⚙️

設定アプリ

ノードにはブラウザで操作できる専用の設定アプリが付属しています。そこからコミュニティの名前を設定し、各自の鍵でサインインするオーナーや管理者を指名し、QR招待状を印刷し、ディスクの健全性を監視し、公開Webアドレスやトンネルを選択できます。また、スマートフォンと12個の単語の両方を失ったメンバーに対して、対面で確認したうえでワンタイムコードを発行し、新しい端末でアカウントに復帰できるよう手助けすることもできます。

🔒

起動直後からプライベート

ノードが起動した瞬間から、コミュニティの出品、地図、メッセージ、残高はメンバー専用となります。特別な設定は不要です。アカウントを持たずにそのアドレスを開いた人は、グローバルコミュニティへと案内され、そこで近くにあるものを見て参加をリクエストできます。

🌐

近隣コミュニティとの連携

2つのコミュニティが合意して連携することで、メンバー同士が取引できるようになります。豆がコミュニティの外に出ることはありません。相互のコミュニティ間で貸し借りの累計を記録し、双方が独自の上限を設定します。双方の運営者が有効にしない限り連携はオフのままであり、機能はまだ初期段階です。Webアプリに画面は用意されていますが、テストコミュニティ間で試行されたのみで、本番環境同士での実績はまだありません。

アドレスの決定

貼り付ける前に選択し、最後の行をそれに合わせて変更します。すでに貼り付けてしまった場合は、質問でEnterキーを押し、その後に最後の行を再実行してください（申請コードはスマートフォンからの接続を待機します）。パブリックIPアドレスとポート80および443が開いているレンタルサーバーの場合：beanpool claim --ip 203.0.113.7のように、--ipとIPアドレスを追加します。サーバーはポート80経由でLet's Encryptからそのアドレス用の証明書を取得し、スマートフォンはhttps://203.0.113.7で接続できるようになります。自宅のコンピューターまたは開放ポートがない場合：そのまま変更せず実行します。無料のサブドメイン名の先頭部分を聞かれます（yourtown.beanpool.orgにする場合はyourtownと入力、Enterでスキップ）。サーバーが自ら実行するトンネル経由で接続され、開通まで最大3分待機します。独自ドメインの場合：ドメインのAレコードをサーバーのIPアドレスに向け、ポート80と443を開放し、--address https://your.domainを追加します。ドメイン名ならサーバーを変更しても使い続けられますが、IPアドレスの数値は引き継げません（後から「設定」で名前を追加でき、以前のIPアドレスを使っていたメンバーもそのまま接続できます）。後で「設定」から選択する場合は--no-nameを追加してください。暗号化のないhttp://アドレスはホームネットワークでのみ動作します。インターネット上ではスマートフォンに接続を拒否され、申請時にも警告されます。BeanPoolプロジェクトのアドレスサービスが停止していても、申請自体は問題なく機能します。

インストールする

次に、Dockerをインストールしたマシンで、このコマンドブロックを貼り付けます。composeファイルを取得し、ノードが使用するネットワークを作成し、公開イメージ（Intel/AMDまたはARM64）をダウンロードして起動し、サーバーがワンタイム申請コードを生成するのを待って（Raspberry Piでの初回起動など遅い場合は最大5分）、所有権の申請（claim）を行います。起動前に設定が必要な項目はありません。

bash — コミュニティを始める
1つのブロック：取得、ネットワーク作成、イメージ取得、起動、待機、申請 git clone https://github.com/beanpool-org/beanpool.git && cd beanpool docker network create beanpool-shared docker compose pull docker compose up -d echo "Waiting for the server to make its claim code (up to 5 minutes)..." for i in $(seq 60); do docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null && break; sleep 5; done docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null || echo "No claim code after 5 minutes. The server's log says why: docker compose logs beanpool-node" docker compose exec beanpool-node beanpool claim

最後の行：beanpool claim

  1. コードとQRコード。 ワンタイム申請コードとQRコードが表示されます。スマートフォンのカメラでQRコードをスキャンするか、BeanPoolを開いてコミュニティを探すの下にサーバーのアドレスを入力し、申請をタップします。そのスマートフォンがオーナーになります。
  2. 設定。 あなたのアドレス（またはサーバーのアドレス）の末尾に/settingsを付けてブラウザで開きます。セットアップウィザードに従ってコミュニティの名前を決め、2人目のオーナーを追加し、3つの設立メンバー用招待状を作成します。「ノードの識別情報」で地図上の位置を設定すると、近くの人があなたを見つけられるようになります。

ブロックにNo claim code after 5 minutesと表示されたり、beanpool claimにThis community has no claim code waitingと表示されたりした場合、サーバーの起動がまだ完了していません。docker compose logs beanpool-nodeで進捗状況を確認できます。ログにコミュニティにまだオーナーがおらず申請コードが発行された旨が表示されたら、最後の行を再度実行してください。詳しい手順は運営者マニュアルの初回セットアップに記載されています。

おすすめ：Dockerの更新中もコミュニティを動かし続ける

このステップは、運営者マニュアルの「Updates and health」ページにあります。 インストールを行うAIアシスタントは、このステップを必ず実行します (AIアシスタントでサーバーをセットアップする)。
