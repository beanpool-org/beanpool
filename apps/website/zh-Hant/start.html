建立社群

每個社群都運作在自己的節點上：一台保存該社群成員、貼文與帳本的小型伺服器。由在地人員負責維護。如果你所在的城鎮或山谷還沒有節點，你可以成為發起人。

營運一個社群要做什麼

如果你能照著步驟操作，大約需要半小時。首先需要了解的六件事：

  • 花費成本。軟體完全免費。它可以運作在家中常開的閒置電腦上（迷你電腦 Mini PC、NAS，或搭載 64 位元系統的 Raspberry Pi 樹莓派），或每月幾美元（約 6 美元）的小型租用伺服器上。
  • 由誰主機託管。由你主機託管，運行在你自己的機器或租用的伺服器上。它絕不需要 beanpool.org：使用你自己的專屬網址即可。
  • 你承擔的責任。成員的檢舉會發送給你。資料資料夾由你透過還原代碼自行備份。請維持兩位所有者。確保伺服器持續開啟並保持更新。
  • 你絕不會看到的內容。成員的私人一對一訊息。
  • 先安裝 Docker。在執行下方指令區塊前，機器需要先安裝 Docker；新租用的伺服器通常沒有預載。
  • 手機可連線的網址。手機在網際網路上僅能透過 https 連線至社群。在具有公開 IP 位址且開放連接埠 80 和 443 的租用伺服器上，該 IP 位址即已足夠：伺服器會自動取得專屬憑證，無需 Cloudflare 帳號，自有網域亦同。在家中或未開放連接埠的情況下，認領程序會透過伺服器自行執行的穿透通道，為你提供以 .beanpool.org 結尾的免費網域名稱。純 http:// 位址僅在家庭區域網路中有效。
🧰

你負責照顧的事項

你和你指定的管理員是你社群的版主：檢舉會發送給你們。成員的資料存放在你的機器上，因此你需要負責備份。你可以讀取在地事業討論與活動聊天；但你無法讀取私訊。你負責邀請第一批成員，再由他們邀請其他人。

⚙️

設定應用程式

你的節點在瀏覽器中隨附專屬的設定應用程式。你可以從中為社群命名、指定使用自身金鑰登入的所有者與管理員、列印 QR 碼邀請函、監控硬碟健全狀況、選擇公開網址或穿透通道，並協助同時遺失手機與 12 個助記詞的成員，透過你當面確認的一次性驗證碼，在全新手機上重新取回自己的帳號。

🔒

從首次啟動即維持私密

社群的刊登內容、地圖、訊息與餘額從節點啟動的那一刻起就僅供成員使用；無需開啟任何設定。未持有帳號而開啟該網址的訪客會被引導至全球社群，在那裡他們可以看到附近的內容並申請加入。

🌐

與相鄰社群連結

兩個社群可以協議連結，以便雙方成員相互交易。豆子絕不會離開本地：每對社群都會持續記錄彼此積欠對方的差額，雙方各自設定交易限額。除非雙方營運者都開啟此功能，否則連結預設處於關閉狀態，且目前仍處於早期階段：該功能已建置完成，在網頁版應用程式中備有操作畫面，但僅在我們自有的兩個測試社群之間進行過試驗，尚未在實際運作的社群間使用過。

你的網址

在貼上指令前先選定，並修改最後一行以相符合。如果你已經貼上執行，請在提問時按 Enter 跳過，然後再次執行最後一行：認領代碼會等待手機連線。租用伺服器若擁有公開 IP 位址並開放連接埠 80 和 443：加上 --ip 及其 IP 位址，例如 beanpool claim --ip 203.0.113.7。伺服器會透過連接埠 80 從 Let's Encrypt 自動取得該位址的憑證，手機即可透過 https://203.0.113.7 連線。家中的電腦，或沒有開放連接埠：保持原樣即可。它會要求輸入免費名稱的第一部分（若要使用 yourtown.beanpool.org，只需輸入 yourtown；按 Enter 可略過），透過伺服器自行執行的穿透通道連線，並等待最多三分鐘完成上線。自有網域：為該網域設定指向伺服器 IP 位址的 A 記錄，開放連接埠 80 和 443，並加上 --address https://your.domain。網域名稱在更換伺服器後仍可繼續使用；數字 IP 則不行：你也可以稍後在「設定」中新增名稱，使用 IP 位址的成員連線不會中斷。若想稍後在「設定」中選擇，請加上 --no-name。純 http:// 位址僅適用於家用網路：手機在網際網路上會拒絕連線，認領程序也會發出警告。即使 BeanPool 專案的網址服務發生中斷，認領功能依然有效。

安裝

接著，在已安裝 Docker 的機器上，貼上這段單一指令區塊。它會取得 compose 檔案、建立節點使用的網路、拉取已發布的映像檔（Intel/AMD 或 ARM64）、啟動節點、等待伺服器產生一次性認領代碼（在 Raspberry Pi 樹莓派上初次啟動較慢，最多約需五分鐘），並執行認領。啟動前無需進行任何設定。

bash — 建立社群
單一指令區塊：取得、建立網路、拉取、啟動、等待、認領 git clone https://github.com/beanpool-org/beanpool.git && cd beanpool docker network create beanpool-shared docker compose pull docker compose up -d echo "Waiting for the server to make its claim code (up to 5 minutes)..." for i in $(seq 60); do docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null && break; sleep 5; done docker compose exec -T beanpool-node test -f /data/claim-code.txt </dev/null 2>/dev/null || echo "No claim code after 5 minutes. The server's log says why: docker compose logs beanpool-node" docker compose exec beanpool-node beanpool claim

最後一行：beanpool claim

  1. 代碼與 QR 碼。畫面會顯示一次性認領代碼與 QR 碼。使用手機鏡頭掃描 QR 碼，或開啟 BeanPool，在尋找你的社群下方輸入伺服器網址，然後點擊認領。該手機即成為所有者。
  2. 設定。在網址（或伺服器專屬位址）後加上 /settings 開啟。設定精靈會引導你為社群命名、要求新增第二位所有者，並產生三份創始邀請。在「節點身分」下設定地圖上的位置，以便附近的人能找到你。

如果指令區塊顯示 No claim code after 5 minutes，或 beanpool claim 顯示 This community has no claim code waiting，表示伺服器尚未完成啟動：docker compose logs beanpool-node 會顯示目前進度。一旦記錄檔顯示社群尚無所有者且已有認領代碼，請重新執行最後一行。完整步驟請參閱營運者手冊的首次設定。

建議：Docker 更新時讓社群持續運作

這一步在營運者手冊的「Updates and health」頁面裡。 負責安裝的 AI 助理一定會執行這一步 (用 AI 助理設定你的伺服器)。
