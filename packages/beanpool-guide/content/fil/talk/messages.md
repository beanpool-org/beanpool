## Iyong mga chat

Ang **Usapan** ay may tatlong button sa itaas: **Mga Mensahe**, **Mga Grupo** at **Mga Tao**.

I-tap ang **Usapan** sa hanay ng mga tab, pagkatapos ay **Mga Mensahe**. Ang iyong mga chat sa mga tao ay nakalista roon. Ang mga kasunduang nangangailangan sa iyo ay nasa itaas, sa ilalim ng **Kinakailangang Aksyon**.

Ang mga chat na kabilang sa isang grupo, negosyo, o kaganapan ay nasa ilalim ng **Mga Grupo**, hindi rito. Tingnan ang "Mga Grupo".

- Maghanap gamit ang **Maghanap sa mga chat, post, partner...**.
- Inaayos ng filter button ayon sa **Kamakailan** o **Hindi Pa Nababasa** (at, kung saan gumagamit ang iyong komunidad ng Munggo, ayon sa Munggo sa bawat kasunduan, pinakamataas o pinakamababa muna), at maaaring magpakita ng **Hindi Pa Nababasa Lang** o **Mga Kaibigan Lang**.
- Sa telepono, ang button sa paghahanap at pag-filter ay dumudulas palayo habang nag-i-scroll ka pababa. Mag-scroll pataas nang kaunti at babalik ang mga ito. I-tap ang **Usapan** muli upang lumukso sa itaas.

Sa web app ito ang tab na **Usapan**. Inililista nito ang lahat ng iyong mga chat, mga grupo at kaganapan din, na may **Lahat**, **Mga Transaksyon**, **Direkta** at **Mga Grupo** sa itaas, at wala itong paghahanap o filter.

## Pagsisimula ng chat

- Mula sa isang post: i-tap ang **Mensahe** at ang pangalan ng tao.
- Mula sa **Usapan**: i-tap ang button na lapis, pagkatapos ay hanapin ang tao ayon sa pangalan. Sa pandaigdigang komunidad, inililista ng Bagong Mensahe ang mga taong nakatransaksyon mo at ang iyong mga kaibigan. Upang makahanap ng sinumang iba pa, mag-type ng hindi bababa sa 2 titik ng kanilang pangalan.
- Mula sa iyong mga kaibigan: **Usapan**, pagkatapos ay **Mga Tao**, pagkatapos ay **Mga kaibigan**, at i-tap ang button ng mensahe sa tabi ng pangalan.

Sa web app, gamitin ang **✉️ Bagong DM**, o ang button na **💬 Mensahe** sa isang post. Ang iyong mga kaibigan ay nasa ilalim ng tab na **Mga Tao**.

## Pagpapadala

- Mag-type sa **Mensahe...** at i-tap ang send button.
- Upang magpadala ng larawan, i-tap ang **+**, pagkatapos ay **Kamera** o **Galerya**. Sa web app, gamitin ang button na **📎**, o i-paste o i-drag ang isang larawan nang diretso sa chat — ipinapakita muna nito sa iyo ang larawan, at anumang na-type mo na ay sasama rito bilang caption. Ang mga larawan ay maaari lamang ipadala sa mga chat sa pagitan ng dalawang tao.

Ang mga tsek sa ilalim ng iyong mensahe:

- isang tsek: naipadala;
- dalawang asul na tsek: nabasa na;
- isang orasan: ipinapadala pa rin;
- **hindi naihatid**: nabigo ito. I-tap ito upang **Ipadala Muli** o **I-discard** ito.

Ang orasan at **hindi naihatid** ay nasa telepono. Sa web app, ang isang mensaheng nabigo ay nananatili sa kahon, at sinasabi ito ng app.

## Tumugon, mag-react, mag-edit, magbura

Sa telepono, i-tap ang isang mensahe. May lilitaw na maliliit na bilog na button sa tabi nito:

- Ang **Tumugon** ay nagko-quote nito sa itaas ng susunod mong isusulat. I-tap ang quote sa isang naipadalang mensahe upang lumukso pabalik sa sinasagot nito.
- Binubuksan ng **Mag-react** ang pitong emoji. I-tap ang isa upang idagdag ito, i-tap ito muli upang bawiin. Isang reaksyon para sa bawat isa; ang pag-tap sa iba ay nagpapalit nito. Ipinapakita ang mga reaksyon bilang isang maliit na badge sa ilalim ng mensahe.
- **I-edit**, sa sarili mong mga mensahe, sa loob ng 15 minuto pagkatapos mong ipadala ito. Ipinapakita ng mensahe pagkatapos ang **na-edit**. Hindi maaaring i-edit ang mga larawan.
- **Burahin**, sa sarili mong mga mensahe, anumang oras — walang limitasyon sa oras. Nagtatanong ito ng **Burahin para sa lahat?** nang isang beses. Ang mensahe ay mababasang **Binura ang mensaheng ito** para sa inyong dalawa, at walang sinuman ang makakapag-react dito o makakatugon dito.

Ang parehong mga button ay nasa chat ng isang grupo. Tingnan ang "Mga Grupo".

Sa web app, ang **Tumugon**, **Mag-react** at **I-edit** ay maliliit na salita sa bawat mensahe, at walang **Burahin**: burahin ang isang mensahe mula sa app sa telepono.

Inaalis din ng pagbura ang mga salita sa server ng iyong komunidad, kaya hindi na kailanman makikita ng isang bagong telepono na magsa-sign in mamaya ang mga ito.

## Pag-mute ng chat

I-tap ang **⋯** sa kanang itaas (**⋮** sa chat ng isang grupo), pagkatapos ay **I-mute ang mga abiso**: **Nang 8 oras**, **Nang isang linggo** o **Palagi**. I-tap ang parehong button at **I-unmute** upang bawiin ito. Hindi pa maaaring mag-mute ng chat ang web app. Tingnan ang "Pag-mute ng chat".

## Kung ano ang pribado

- Ang isang chat sa pagitan ng dalawang tao ay **naka-encrypt nang end-to-end**: naka-lock ito sa iyong telepono at naka-unlock sa kanila, kaya hindi ito mababasa ng server ng iyong komunidad. Sa telepono, ipinapakita ng chat ang **Naka-encrypt nang end-to-end** sa itaas. Naka-encrypt din ang mga larawan dito, at gayundin ang iyong mga pag-edit.
- Ang bawat mensahe ay naka-lock din sa kung sino ang nagpadala nito, sa isang mensaheng iyon, sa chat nito at, kung ito ay isang tugon, sa mensaheng sinasagot nito. Kaya hindi maipapakita ng server ang iyong mensahe bilang sa kabilang tao, ipadala itong muli bilang bagong mensahe, o ituro ang iyong sagot sa ibang mensahe. Kung saan ito sumusubok, ipinapakita ng app ang **Hindi ma-verify ang mensaheng ito, kaya hindi ito ipinapakita.** sa gitna ng chat, bilang walang nagmamay-ari, sa halip na ang mga salita. Ang isang larawang ipinagpalit ng server sa iba ay mababasang **Hindi available ang larawan**.
- Kung maglalagay ang server ng mensahe sa ibang chat, tatanggihan ito ng app doon. Kapag ang dalawa sa iyong mga chat sa parehong tao ay pinagsama sa isa, dinadala ng bawat mensahe ang chat na pinanggalingan nito. Ang isa na ipinadala mula noong update na ito ay ipinapakita na may **Inilipat dito mula sa ibang pag-uusap.** sa ilalim. Ang isa na ipinadala bago ito ay nagpapakita ng linyang mas lumang bersyon sa halip (tingnan sa ibaba).
- Naaalala rin ng bawat mensahe ang pinakabagong mensaheng mayroon ang sumulat nito noong isinulat nila ito. Kung ipapakita ito ng server bago ang isang iyon, mababasa rito ang **Ipinapakita nang wala sa pagkakasunud-sunod kung kailan ito isinulat.** sa ilalim. Ang dalawang mensaheng isinulat sa parehong sandali, walang nauna sa isa't isa, ay maaaring dumating sa alinmang pagkakasunud-sunod nang wala ito.
- Anumang bagay sa isang chat sa pagitan ng dalawang tao na hindi naka-lock ay hindi kailanman ipinapakita bilang mga salita ng alinmang tao: mababasa rito ang **Hindi naka-encrypt ang mensaheng ito, kaya hindi makumpirma ng BeanPool kung sino ang sumulat nito.** sa gitna ng chat, at hindi ipinapakita ang mga salita nito. Ang iyong listahan ng mga chat ay nagpapakita ng parehong linya.
- Ang isang mensaheng ipinadala sa iyo ng mga admin ng iyong komunidad mula sa admin page ng server ay hindi naka-lock, at hindi isang pribadong mensahe. Lumalabas ito sa gitna ng chat, hindi kailanman bilang sariling mensahe ninuman, na may **Mula sa mga admin ng iyong komunidad. Hindi pribadong mensahe: mababasa ito ng server ng komunidad.** sa ilalim.
- Ang mga mensaheng ipinadala bago ang update na ito, ng anumang app, ay na-lock nang wala ang mga pagsusuring ito: maaaring binago ng server kung kanino nagmumula ang mga ito, o nagpadala muli ng isa. Bumubukas pa rin ang mga ito, at bawat isa ay mababasang **Ipinadala mula sa mas lumang bersyon ng app: hindi makumpirma ng BeanPool kung sino ang sumulat nito.** sa ilalim, saanman ito naroroon sa chat. Ang isang taong nasa mas lumang app pa rin ay hindi mababasa ang mga mensahe mula sa isang na-update hanggang sa mag-update sila.
- Ipinapakita ng isang tugon ang mensaheng sinasagot nito sa paraang ipinapakita ang mismong mensaheng iyon. Pinapangalanan lamang nito ang sumulat kapag nabuksan ang kanilang mensahe, at dinadala ang linya ng mensaheng iyon sa ilalim, tulad ng sa mas lumang bersyon. Pinapangalanan nitong **Paalala** ang isa sa mga abiso ng server at **Mga admin ng iyong komunidad** para sa mensahe ng mga admin. Anumang hindi nabuksan o hindi na-lock ay kinokopya (quoted) bilang **Hindi kumpirmado**, kasama ang linyang kumakatawan sa mga salita nito.
- Kaya ang server lamang ay hindi magagawang magmukhang sumulat ang sinuman sa inyo ng mga salitang hindi ninyo isinulat. Maaari pa rin nitong pigilan ang isang mensahe, ihatid ito nang huli, o gawin itong mababasang **Binura ang mensaheng ito**. Maaari nitong ipakita ang mga naunang salita ng isang na-edit na mensahe sa halip na ang mga bago: parehong talagang sa nagpadala ang mga ito. Nakikita nito kung aling mensahe ang sinasagot ng bawat mensahe, ngunit hindi mababago iyon nang hindi nakikita. Maaari itong magdagdag o mag-alis ng reaksyon ng emoji sa pangalan ng alinmang tao: hindi naka-lock ang mga reaksyon. At maaari itong magdagdag ng sarili nitong mga abiso sa isang chat. Ang isang abiso ay ipinapakita bilang isang abiso, kinokopya bilang **Paalala**, at mababasang **Paalala:** sa iyong listahan ng mga chat, hindi kailanman bilang sinuman sa inyo.
- Pinapatunayan ng pag-lock na ang isang mensahe ay nagmula sa isa sa inyong dalawa, hindi kung alin: ang kabilang tao, sa tulong ng mga taong nagpapatakbo ng iyong server, ay maaaring maglagay ng mga salita sa iyong pangalan.
- Nakasalalay ang lahat ng ito sa pagkakaroon ng iyong app ng tunay na key ng kabilang tao, na nakukuha nito mula sa server ng iyong komunidad, tulad ng mismong pag-encrypt. Sa web app nakasalalay din ito sa mismong app, na ipinapadala ng server ng iyong komunidad sa iyong browser. Ang app sa telepono ay nagmumula sa app store.
- Ang isang mensaheng hindi mai-lock ay hindi ipinapadala. Kung hindi pa mahanap ng app ang key ng kabilang tao, o nabigo ang pag-lock, mananatili ang iyong mga salita sa kahon ng mensahe na may linyang nagsasabi nito. Magpadala muli sa ilang sandali. Tinatanggihan din ng server ng iyong komunidad ang isang mensahe sa pagitan ng dalawang tao na hindi naka-lock.
- Ang mga abisong idinaragdag ng BeanPool sa isang chat tungkol sa isang kasunduan ay hindi naka-encrypt: Munggo na hawak para sa kalakalan, binayaran, o ibinalik kapag ito ay nakansela, ang halaga, at kung paano inayos ng isang admin ang isang nakatenggang kalakalan at bakit. Mababasa ang mga ito ng mga taong nagpapatakbo ng server ng iyong komunidad.
- Alam din ng server kung sino ang nagpadala ng mensahe kanino, at kailan, aling mensahe ang sinasagot ng bawat isa, at nakikita ang mga reaksyon ng emoji. Ang isang mensaheng ipinadala ng mas lumang bersyon ng app nang walang lock ay nananatiling mababasa sa server.
- Ang chat ng isang grupo ay **naka-encrypt nang end-to-end** din, sa telepono at sa web app: ang mga miyembro lamang ng grupo ang makakabasa nito, at ang mga taong nagpapatakbo ng server ng iyong komunidad ay hindi. Sa itaas ng kahon ng mensahe sinasabi nitong ito ay **Naka-encrypt nang end-to-end**. Nakikita pa rin ng server ng iyong komunidad kung sino ang sumulat, kailan, sino ang nabanggit, aling mensahe ang sinasagot ng bawat linya, at ang mga reaksyon ng emoji. Makikita mo lamang ang chat ng isang grupo mula sa araw na sumali ka: walang nakasulat bago noon ang ipinapakita, at hindi kailanman hawak ng iyong telepono ang susi para rito. Ang isang mensaheng hindi mai-lock ay hindi ipinapadala. Ang isang linyang hindi masuri bilang isinulat ng isang miyembro ay mababasang **Hindi ma-verify ang mensaheng ito.**, bilang walang nagmamay-ari. Kung mas luma ang server ng iyong komunidad at hindi pa makapag-lock ng mga group chat, sinasabi ito ng chat, at mababasa ito ng server. Kapag na-update ang server, aalisin ang mga naunang mensaheng iyon, at sinasabi ito ng isang linya sa chat. Tingnan ang "Mga Grupo".
- Sa web app ang chat ng isang grupo ay gumagana sa parehong paraan, ngunit hindi ka maaaring magpadala ng mga larawan dito.
- Ang mga chat sa negosyo at kaganapan ay hindi naka-encrypt. Mababasa ang mga ito ng mga taong nagpapatakbo ng server ng iyong komunidad, at maaaring sumulat ang server sa mga ito sa pangalan ng sinuman.
- Ang isang chat sa pagitan ng dalawang tao ay hindi kailanman maaaring gawing isa sa mga iyon. Kapag nakita na ng iyong app ang isang chat bilang isa sa pagitan ng dalawang tao, o nagtataglay ito ng isang naka-encrypt na mensahe, mananatili itong ganoon, anuman ang sabihin ng server: bumubukas lamang ito bilang chat na iyon, kasama ang lahat ng mga pagsusuri sa itaas, at ang ipinapadala mo rito ay palaging naka-lock. Ang isang telepono o browser na hindi pa nakakita sa chat, at walang ibinigay sa mga naka-encrypt na mensahe nito, ay hindi masasabi: para rito, ang ganoong chat ay mukhang chat ng anumang iba pang grupo, na mababasa ng server. Sa web app nalalapat din iyon para sa isang browser na na-sign out mula noon, isang pribadong window, o isa na na-clear ang site data: kinakalimutan ng web app kung aling mga chat ang nasa pagitan ng dalawang tao. Pinapanatili ng app sa telepono ang listahang iyon.
- Ang pagbura ng isang mensahe ay humihiling sa server ng iyong komunidad na palitan ito. Hindi nito maabot ang isang kopyang nabasa na ng isang tao, o isang screenshot.
- Ang pagbura sa iyong account ay gumagawa ng pareho sa bawat mensaheng isinulat mo, sa bawat uri ng chat, at binubura ang mga larawang ipinadala mo. Tingnan ang "Pag-alis o pagbura ng account".
- Ang chat ng isang kaganapan ay mababasa rin ng host at ng bawat pupunta (kung saan nagpapasok ang host ng mga tao, ang mga pinapasok ng host).
- Ang chat ng isang negosyo ay mababasa ng sinumang miyembro ng iyong komunidad. Ito ang pampublikong talakayan ng negosyo, ang parehong ipinapakita ng pahina nito, at sinuman sa komunidad ay makakasulat din dito. Hindi ito pribadong chat para sa mga tagapangalaga nito.

## Pag-block sa isang tao mula sa chat

I-tap ang kanilang pangalan sa itaas ng chat. Bubukas ang kanilang profile. I-tap ang **I-block**, pagkatapos ay **I-block ang User**. Sa web app, i-tap ang **I-block** sa itaas ng chat, pagkatapos ay **OK**. Tingnan ang "Pag-block ng sinuman".
