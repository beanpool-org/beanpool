# Security Policy

## Reporting a Vulnerability

We take the security of BeanPool seriously. If you discover any security vulnerability, please do **NOT** open a public GitHub issue or disclose it publicly. Instead, report it privately to the maintainers.

Please report it through GitHub's private form: **[Report a vulnerability](https://github.com/beanpool-org/beanpool/security/advisories/new)**. Only the maintainers can see it, and we can work on a fix together there before anything is public. If you can't use GitHub, email **security@beanpool.org**.

Include as much detail as possible in your report, such as:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue.
- Any proof-of-concept code or screenshots.

We aim to acknowledge a report within a few days and to work on a fix with you. BeanPool is a small project, so please be patient, and please don't disclose the problem publicly until it is fixed.
