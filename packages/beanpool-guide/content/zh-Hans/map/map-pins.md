## 图钉

在标签页栏中点按**地图**。地图会显示你所在社区的刊登：

- **绿色图钉：**提供。
- **橙色图钉：**需求。
- **带有日历的紫色图钉：**尚未结束的活动。

图钉会显示刊登的分类图标。当许多“提供”和“需求”彼此紧靠时，它们会汇聚为一个带有数字的圆圈。在手机上该圆圈为蓝色，在 Web 应用中为深灰色。放大地图即可逐一查看它们。活动始终单独显示。

人员和群组不会显示在地图上。在 Web 应用中，设置了地点的企业会显示为带有其图片的方形图钉。点按它即可打开该企业。

投票也不会显示在地图上。唯一的例外是在手机上的全球社区中，投票可以显示为发布者所在区域的图钉。它看起来像橙色的“需求”图钉，且仅显示在**全部**下方。

## 点按图钉

- **提供或需求：**卡片会显示标题和发布者。点按**查看详情**即可将其打开。在手机上，点按对方的姓名可查看其个人资料。点按地图或 **✕** 可关闭卡片。
- **活动：**卡片会显示时间和地点，以及有多少人参加。点按**查看活动**。在 Web 应用中该按钮为**查看详情**，你也可以在卡片上点按**确定参加**或**感兴趣**。

## 筛选条件

在手机上，位于地图顶部：

- **全部**、**提供**、**需求**或**活动**。点按 **✕** 可清除。
- **全部分类**可用于显示单一分类。
- 针对活动：**全部**、**今天**、**本周末**或**未来 7 天**。地图会移动以容纳它们。

在 Web 应用中，地图仅提供活动日期标签：**今天**、**本周末**、**未来 7 天**和**全部活动**。它们仅在你所在社区有即将举行的活动时才会显示。

## 左侧按钮

- 在手机上，月亮或太阳图标：切换深色或浅色地图。
- 准星图标：显示你的所在位置。首次使用时，应用会请求使用你位置信息的权限。
- **+** 和 **−**：缩放。

琥珀色圆圈表示你所在社区服务的区域。

## 从地图添加刊登

点按 **+ 发布内容**。在 Web 应用中，点按右下角的圆形 **+**。参见“发布提供或需求”。
