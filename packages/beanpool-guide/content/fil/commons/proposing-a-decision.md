## Bago ka magsimula

- Ang Desisyon ay para sa mga bagay na kayang isagawa ng server ng komunidad: pagsuspinde o pagbabalik ng miyembro, pag-freeze o pag-unfreeze ng credit ng isang tao, o pagbabayad ng beans mula sa Commons. Para sa iba pa, magsimula ng Botohan.
- Hindi maaaring alisin o suspindihin ng isang Desisyon ang isang may-ari o admin ng server ng iyong komunidad. Tingnan ang "Mga tuntunin at mga desisyon".
- Maaari kang magpanukala kapag nakakumpleto ka na ng kalakalan, o binigyan ka ng isang admin ng trust badge. Palaging maaaring magpanukala ang mga admin ng iyong komunidad. Ang vouch lamang ay hindi sapat.
- Maaari kang magpanukala kapag nakatapos ka na ng isang palitan. Ang mga admin ng iyong komunidad ay laging maaaring magpanukala. Hindi sapat ang trust badge.
- Walang mga Desisyon ang pandaigdigang komunidad, kaya walang maipapanukala roon. Tingnan ang "Pagboto sa Desisyon".

## Pagpanukala

- I-tap ang **Komun**, pagkatapos ay **Magpasya**, pagkatapos ay **+ Magmungkahi ng Desisyon**.
- Piliin kung tungkol saan ito: **Miyembro** o **Commons Pool**.
- **Pamagat:** isang linya, tulad ng "Grant 200 beans to the Tool Library".
- **Deskripsyon at Dahilan:** ipaliwanag kung bakit, sa hindi bababa sa 10 character. Sabihin ito nang malinaw. Bumaboto ang mga tao batay sa nababasa nila rito.
- Mula sa listahan sa ibaba nito, piliin nang eksakto kung ano ang dapat mangyari. Halimbawa, para sa isang miyembro: Alisin ang Miyembro, Isuspinde ang Miyembro o I-freeze ang Kredito. Para sa Komun: Magbigay ng munggo sa isang proyekto o negosyo, Tulong sa Kagipitan, o Bayaran ang utang ng isang proyekto o negosyo.
- Punan kung para kanino ito, at gaano karaming munggo kung mayroon man. Para sa isang grant sa isang proyekto o negosyo, itina-type mo ang key nito, isang mahabang code: walang listahan ang alinmang app upang pagpilian ito. Upang bayaran ang isang utang o palitan ang isang pinuno, i-tap ang proyekto o negosyo sa listahan, o i-type ang key nito.
- I-tap ang **Isumite ang Desisyon ng Komunidad**.

Sa web app ang mga button ay mababasang **+ Magmungkahi ng Desisyon** (o **+ Magmungkahi** sa itaas ng Komun, habang nakabukas ang **Magpasya**) at **Isumite ang Desisyon**, at ang kahon ay **Paglalarawan at Batayan**.

Magbubukas agad ang pagboto at tatakbo nang 7 araw.

## Gaano kalaki ang maaaring maging grant

Ang isang grant sa isang negosyo o isang hardship grant ay hindi maaaring mas malaki kaysa sa kayang bayaran ng Komun. Ang pinakamalaki na maaari mong hilingin ay:

- kung ano ang hawak ng Komun ngayon,
- kasama ang bawat munggo na pumasok dito sa nakalipas na 30 araw: ang bayad sa merkado, ang circulation fee, at anumang iba pang munggo na ibinayad dito.

Ang mga munggo na ibinayad mula sa Komun sa loob ng 30 araw na iyon ay hindi ibinabawas. Kung hihingi ka ng higit pa, tatanggi ang app bago pa man bumoto ang sinuman, at sasabihin sa iyo ang pinakamalaking maaari mong hilingin ngayon. Ang halagang iyon ay tumataas habang pumapasok ang mga munggo sa Komun.

Pinapanatili nitong libre ang pila. Kung pumasa ang isang grant kapag kulang ang Komun, maghihintay ito sa mga munggo, at isang grant lamang ang maaaring maghintay sa bawat pagkakataon. Tingnan ang "Mga tuntunin at mga desisyon".

## Kung tatanggi ang app

- **Kumpletuhin Muna ang Isang Palitan** (sa telepono): hindi ka pa maaaring magpanukala. Sa web app ang button na **+ Magmungkahi ng Desisyon** ay naka-grey out, at isang linya sa itaas nito ang nagsasabi kung bakit.
- **Naabot ang Limitasyon** (sa telepono): mayroon ka nang bukas na Desisyon. Hintayin itong magsara. Sa web app ang button ay naka-grey out din dito, na may linyang nagsasabi kung bakit.
- **Hindi maaaring alisin o suspindihin ng boto ng komunidad ang isang may-ari o admin ng server ng komunidad na ito:** ang taong pinili mo ang nagpapatakbo ng server. Maaaring alisin muna ng isang may-ari ang kanilang tungkulin.
- **Ang grant na ito ay mas malaki kaysa sa kayang bayaran ng Komun:** humiling nang hindi hihigit sa halagang pinangalanan nito, o maghintay para sa higit pang mga munggo na pumasok.
- **Di-wastong Halaga** (sa web app, "Mangyaring maglagay ng wastong positibong halaga ng kaloob sa munggo"): punan kung gaano karaming munggo.
- **Error:** suriin na ang iyong paglalarawan ay hindi bababa sa 10 character ang haba.
