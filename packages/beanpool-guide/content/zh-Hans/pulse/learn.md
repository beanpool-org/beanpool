## 包含的内容

在手机上，打开**脉搏**并点按**学习**。在 Web 应用中，打开脉搏并点按顶部的**运作方式**。它包含：

- BeanPool 制作的关于其运作机制的视频；
- **Daily Reflection**，每天早晨更新的一小段简短心得。点击即可打开当天的感悟。

成员也可以将自己的教学频道添加到“学习”板块中，只需在添加频道时选择主题**运作方式**即可。这些视频属于成员个人，而非 BeanPool 官方：在遵循其建议前，请核实视频的发布者。

## 视频属于附加内容

你所需了解的一切均已写入本指南中。如果你更喜欢看视频，可以查看这些视频。

在手机上的“学习”栏目中，点按视频封面即可直接在卡片内播放。在点按之前，不会从 YouTube 加载任何内容。在 Web 应用中，点按视频会在新标签页中打开 YouTube。参见“社区动态”。

当 BeanPool 为某个指南页面制作了视频，且该视频收录于你所在社区的“学习”栏目中时，该页面顶部会显示 **Watch:** 以及视频名称。点按它即可在 YouTube 上打开该视频。如果该页面没有视频，或者你处于离线状态，该链接则根本不会显示。

只有 BeanPool 官方制作的视频才会出现在指南页面上。无论标题为何，成员自行添加到“学习”中的视频绝不会显示在指南页面中。

## 视频可能不显示的原因

- 你的手机处于离线状态，或无法连接到你所在社区的服务器。
- 全新的 BeanPool 视频只有在你所在社区的服务器完成更新后，才会显示在指南页面上。
- 该页面目前尚无对应视频。
