## 屏蔽操作

- 在对方的个人资料中：点按**屏蔽**，或点按靠下位置的**屏蔽**和其姓名。
- 在对方发布的刊登中（手机应用）：点按**屏蔽用户**。Web 应用中的刊登没有屏蔽按钮。
- 从聊天中：点按顶部的对方姓名打开其个人资料，然后点按**屏蔽**。在 Web 应用中，单人私聊的顶部也设有**屏蔽**按钮。

在手机应用中，点按**屏蔽用户**进行确认。在 Web 应用中，浏览器会弹出确认提示：点按**确定**。

## 屏蔽的效果

- 对方在市集中的刊登会对你隐藏。
- 对方会从你的聊天列表和“成员”列表中消失，且你们无法互发消息。在手机应用中，你之前添加过的成员仍会显示在你的**好友**标签页中：参见下文“屏蔽不产生的影响”。Web 应用则会从所有列表中将其隐藏。
- 对方在动态中发布的内容仍会显示。在手机上，对方在地图上的图钉仍会显示。Web 应用的地图则会将其隐藏。
- 在你的账本中，来自对方的豆子会显示“来自被你屏蔽成员的豆子”，而非对方发送的任何备注。
- 系统会向你所在社区的版主发送举报，以便版主进行核查。

## 社区服务器层面的处理

你所在社区会对其为你保存的屏蔽记录执行这些操作。目前该机制适用于在 Web 应用中进行的屏蔽。在手机应用中进行的屏蔽保留在当前手机上，你所在的社区对此并不知情。

- 对方的私信绝不会送达给你。你所在的社区不会在任何手机或电脑上向你递送这些消息，你也不会收到任何相关通知或未读计数。
- 如果对方与你发起新聊天，该聊天不会出现在你的聊天列表中。
- 如果你解除对其屏蔽，对方在被屏蔽期间发送的任何内容都不会送达。只有在解除屏蔽后发送的消息才会送达给你。
- 如果对方对你的一条消息作出表情回应，或修改其旧消息，你均无法看到。
- 对方在群聊中发言时你不会收到通知，即使对方使用 @ 提及你也不会收到通知。
- 如果对方对你的某项刊登发起交易申请，该申请会在你的交易中等待且不发出任何通知。如果你置之不理，它将在 7 天后自动终止，同样不发出通知。
- 如果对方直接接受你的某项“提供”，你不会收到通知；如果对方随后取消该交易，你也不会收到通知。该交易仍会正常显示在你的交易中，其相关消息也会正常显示在你们的聊天中。对方的豆子会照常暂管并原路退还。
- 对方无法创建仅指定发给你的刊登。
- 你无法添加对方。如果对方添加你，你不会收到通知。如果对方之前添加过你，你“成员”标签页上的“已添加你”提示行会消失。在被屏蔽者的个人资料中，你的好友不会再看到你与对方有共同关联。
- 如果对方附带备注向你赠送豆子，豆子会全额到账，但备注不会显示。你会看到“来自被你屏蔽成员的豆子”，并且在取消屏蔽后依然如此显示。

## 屏蔽不产生的影响

- 对方不会收到被屏蔽的通知。在对方看来，其消息看似已正常发送，转账豆子时附带的备注也是如此。
- 这不会终止好友关系：如果你之前添加过对方，对方仍是你的好友；如果你的联系方式设置为仅好友可见，对方仍可看到。若要同时解除好友关系，请打开**管理已屏蔽的用户**（在网页端为**管理已屏蔽成员**；参见下文“取消屏蔽”），并点按其姓名下方的**同时从好友中删除**。该选项仅对你添加过的人显示。对方仍保持被屏蔽状态。对方可能会察觉到被删除好友。
- 群聊、活动聊天以及项目和企业聊天属于公开共享空间：其中的每个人都能看到相同的消息。对方在这些聊天中发送的消息仍会显示，对你以及其他所有人均可见。
- 你与对方已在进行中的交易仍照常继续，包括其相关的提示和通知。
- 如果你之前与对方进行过交易，对方仍可以向你发送豆子。每颗豆子均会到账，但不发送通知。
- 来自你社区的系统通知仍会正常送达，即使是由对方发起的通知。例如，当有人发起投票提议撤换你作为某个群组的负责召集人时，你会收到通知；你也会收到社区运营人员发来的消息。
- 对方仍可查看你的刊登。
- 在手机应用中，屏蔽记录仅保存在本机上，且仅针对你的当前账户有效。本机上的其他账户不会继承你的屏蔽记录。
- 在手机应用中，如果你退出登录，或在本机上将账户切换为另一个账户，你的屏蔽记录仍会保留在手机上。重新登录相同账户后，这些记录依然存在。
- 在手机应用中，如果你重新安装应用或换用另一部手机，需要重新进行屏蔽。
- 在 Web 应用中，你所在的社区会将屏蔽记录与你的账户一并保存。在任何浏览器上登录均可恢复。退出登录后，该电脑上不会残留任何关于屏蔽的信息。参见“在网页浏览器中使用 BeanPool”。
- 运营你社区服务器的人员可以在 Web 应用中看到你屏蔽了谁，就像他们能够查看举报一样。
- 手机应用和 Web 应用维护各自独立的列表。在一端进行的屏蔽不会同步显示在另一端。

## 取消屏蔽

- 打开**设置**。在 **法律与隐私** 下，点按**管理已屏蔽的用户**。
- 点按姓名旁边的**取消屏蔽**，或点按**全部取消屏蔽**。
- 在手机应用中，你也可以从对方的个人资料中取消屏蔽。其姓名下方会显示“你已屏蔽”及其姓名。点按那里的**取消屏蔽**。

在 Web 应用中，屏蔽和取消屏蔽都需要连接到你所在的社区。在没有网络连接时，应用会予以说明且不会更改任何内容。请在恢复网络连接后重试。
